## Port modifications (2026-11-16)

- Import paths beginning `StacksCore` or `StacksFrontier` are remapped beneath
  `ZInQKernel.Contrib.OneProof.EGAProperLimit` (or `ZInQKernel.Contrib.CloudW01Spread` for the 13 shared
  modules); declaration namespaces are unchanged. Each file carries a modification notice.
- Each file sets `set_option maxSynthPendingDepth 3` after its imports: the upstream `lakefile.toml` sets
  `maxSynthPendingDepth = 3` for the whole library, and without it two files
  (`SegreEmbedding/SegreRing.lean`, `Limits/AffineIntoProjective.lean`) fail instance synthesis.
- Four declaration names that clash with `ZInQKernel/Contrib/CloudW07JacobiansCurves/` are renamed in the
  vendored copies, with every use renamed to match (`scratch/ega-limit/vendor.py`, `RENAMES`; import lines are
  untouched): `ProjectiveSpace` -> `StacksProjectiveSpace` (every file);

  (`StacksFrontier/AlgebraicGeometry/LimitMorphismAt/Dominant.lean`); `HomogeneousLocalization.val_algebraMap`
  -> `val_algebraMap_stacks` and `HomogeneousLocalization.val_fromZeroRingHom` -> `val_fromZeroRingHom_stacks`
  (`StacksFrontier/RingTheory/HomogeneousLocalization/BaseAlgebra.lean`).
- Each file's header carries the line "Modified for the Z-in-Q kernel (ega-limit, 2026-11-16)".
- Statements and proofs are otherwise unchanged.
