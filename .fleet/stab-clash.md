# stab-clash (final)

**Main result.** Every module of `ZInQKernel/Contrib/` now imports in one Lean environment. The new file
`ZInQKernel/Contrib/AllContrib.lean` imports all 2064 Contrib modules (the list is generated by
`git ls-files 'ZInQKernel/Contrib/*.lean'`). `lake build ZInQKernel.Contrib.AllContrib` succeeds
(11974 jobs, 0 errors, VERIFIED 2026-11-13). That build also covers every Contrib module that imports a changed file.

**Clashes fixed.** There were 8 file pairs with 71 duplicate names in total. In each pair, a 5a01f5fe vendored file
is superseded by its later Tau Ceti version:
- Stabilizer vs Stabilizer/Basic: `Subgroup.stabilizerInclusion` and 20 more names.
- FDRep vs FDRep/Basic.
- UnitFiltration/Pow vs Pow/Basic.
- FinitePlace vs FinitePlace/Basic.
- Global/PrescribedInvariant, Global/Kummer/Norm and Global/Kummer/AuxiliaryPlaces vs their Backport/ copies.
- `IsCyclic.mem_range_powMonoidHom_iff` in Cyclic/Basic vs Cyclic/PowMonoidHom.

**How.** The fix is the t40-clash pattern: keep one declaration and drop the other.
- Seven older files now just `public import` their superseding module. For four of them the later module states every name verbatim. The other three were imported by nothing.
- `IsCyclic.mem_range_powMonoidHom_iff` was dropped from Cyclic/Basic, as Tau Ceti did. Its one user, EulerCriterion, now uses the 97a5b235 version; its statement is unchanged.

Nine vendored files were edited, each with a Modified line and a NOTICE entry. No other existing file was touched.

**Checks.** diffcheck2 gave MOD-UNNOTED 0 and NOTE-ONLY 0 on the first run's host. The resumed host lacks diffcheck2 and the Tau Ceti
checkouts, so a substitute Modified-line/NOTICE check was run instead and passed.

**Declarations proved.** None. This is a consolidation task, and no statement used by any Lean file changed.

**Remaining.** Nothing for this task. Caveat: upstream hash-pins existing .lean files. If any of the nine edited vendored files is
already pinned upstream, this fix needs the maintainers' path there.
