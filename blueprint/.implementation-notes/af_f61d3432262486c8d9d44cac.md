# Implementation note: Semantics of the pole template

- Lean name: `ZInQ.Syntax.pole_rel_iff`.
- Draft:
  ```lean
  theorem pole_rel_iff (B : ℚ) :
      Rel poleTemplate.poly 1 11 ![B] ↔ ZInQ.PoleSoluble B
  ```
  `ZInQ.PoleSoluble` and `ZInQ.polePoly` are in ZInQKernel/Hypotheses/Pole.lean; the proof
  shows `eval (Fin.cons B y) poleTemplate.poly = (polePoly B (y ∘ ...) ...)^2` by
  `simp`/`ring` after unfolding the denotation, then `pow_eq_zero_iff`.
- Mathlib: `pow_eq_zero_iff`, `Fin.sum_univ_six`.
- Upstream reuse: `ZInQ.PolePolynomial.polePolynomial` and `compiledPolePolynomial`
  (lean/ZInQ/PolePolynomial.lean) use the same variable order (`X 0 = B`, bits at 1..6,
  `e z r₁ r₂ w` at 7..11) and the same outer square; proving
  `poleTemplate.poly = rename Fin.val compiledPolePolynomial` first lets later proofs reuse
  upstream lemmas about it.
- Finite computation: no.
- Difficulty: low (~40 lines).
