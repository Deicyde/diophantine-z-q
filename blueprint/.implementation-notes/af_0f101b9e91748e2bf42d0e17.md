# Implementation note: Relational form of a model-evaluation recipe

- Lean name: `ZInQ.Translation.modelRecipe_rel_iff`.
- Draft:
  ```lean
  theorem modelRecipe_rel_iff (r : Syntax.ModelRecord) (hr : r = (Syntax.translate ..).1)
      (a : Fin r.parameterCount → ℚ) :
      Syntax.Rel r.denote r.parameterCount r.witnessCount a ↔
        ∃ x : ℕ → ℚ, (∀ i (h : i < r.parameterCount), x i = a ⟨i, h⟩) ∧ r.Holds x
  ```
  where `ModelRecord.Holds x` is the conjunction of conditions 1-5 (generator equations, natural
  relations, constant relations, operation relations, root equality) stated with
  `Syntax.pointRef r x`.
- Proof: `Syntax.eval_sumSq_eq_zero_iff`, the witness-scope theorem for model recipes
  (`Syntax.translate_wellScoped`), call evaluation (`Syntax.exists_call_witness_iff`), and the
  point-reference values lemma. Gluing block witnesses: `Function.update` over disjoint
  intervals, or a single `piecewise` on the block partition.
- Mathlib: `MvPolynomial.eval₂Hom_bind₁`, `Finset.sum_eq_zero_iff_of_nonneg`, `sq_nonneg`.
- Upstream reuse: `ZInQ.EquationCompression.eval_conjoin_eq_zero_iff` (proof pattern; it is
  over `Fin n`).
- FINITE COMPUTATION: no.
- Difficulty: medium (~200 lines; the bookkeeping of disjoint blocks is the main work).

Shared design (translation notes): namespace `ZInQ.Translation`, files under
`ZInQKernel/Compiler/Translation/`. Reuse the syntax chapter's `ZInQ.Syntax.NatCircuit`,
`ZInQ.Syntax.translate`, `ZInQ.Syntax.Rel`, `ZInQ.Syntax.pointRef` and the model chapter's
`ZInQ.iota`. The multiplication statement is taken as a hypothesis
`hM : ZInQ.MultiplicationExact`, where
`def MultiplicationExact : Prop := ∀ p q r : Fin 5 → ℚ, Syntax.Rel multiplyPoly 15 35134 (p ++ q ++ r) ↔ ∃ a b : ℤ, p = iota a ∧ q = iota b ∧ r = iota (a * b)`
(to be shared with the multiplication chapter; if that chapter instead proves the statement
from H, PC, MW, 22P, CAT, the assembly instantiates `hM` with that theorem). `iota` is never
evaluated; constants `c_3`, `A_ht` stay symbolic.
