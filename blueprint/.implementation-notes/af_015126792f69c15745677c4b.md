# Explicit height constants (height-constants)

- Lean name: `ZInQ.Mult.B0_lt_ten`, `ZInQ.Mult.log41_sub_gt_one`.
- Decidable cores:
  ```lean
  theorem height_constants_int :
      3^24 * 2^9 * 39202 * 676^2 * 1000^60 < 2718^60 ∧ 392 * 27183^3 < 41^3 * 10^12 ∧
      2 * 13860^2 < 19601^2 := by decide
  ```
  Real statements:
  ```lean
  theorem B0_lt_ten : 4 * Real.log 3 + 3/2 * Real.log 2 + 2 * Real.log (1 + √2) + Real.log 676 / 3 < 10
  theorem log41_sub_gt_one : 1 < Real.log 41 - Real.log 392 / 3
  ```
  via `Real.exp_one_gt_d9`, `Real.exp_one_lt_d9`, `Real.add_pow_le_pow_mul_pow_of_sq_le_sq` not
  needed: `(1+√2)^12 = 19601 + 13860 √2` by `ring_nf` + `Real.sq_sqrt`, then
  `13860 √2 < 19601` from `Real.sqrt_lt'` and the integer fact; `Real.log_lt_log`, `Real.exp_log`,
  `Real.log_rpow`/`Real.log_pow`, `Real.exp_nat_mul`/`Real.exp_one_pow`.
- FINITE COMPUTATION: yes. Size: integers of about 207 decimal digits. Method: kernel `decide`
  (GMP-backed `Nat.ble`) for the integer cores, then real-analysis glue. No `native_decide`.
- Difficulty: easy-medium (~100 lines of real-number glue).

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
