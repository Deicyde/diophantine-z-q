# Implementation note: The outer composition recipes

- Lean names: `ZInQ.Syntax.closeRecipe`, `mainRecipe`, `valueUnionRecipe`, `valueRecipe`,
  `integersRecipe`.
- Draft: transcriptions of the `composition(...)` calls in construction/ordinary-integer-polynomial.js
  using a small allocation monad (`fresh n`, `call kind target params witnessCount`), e.g.
  ```lean
  def integersRecipe : Recipe := Recipe.comp .sumSquares 1 <| do
    let N ← fresh 5
    call (.recipe valueRecipe) (vars N 5 ++ [0])
  ```
- Mathlib: none.
- Upstream reuse: none.
- Finite computation: no.
- Difficulty: low (~80 lines).
