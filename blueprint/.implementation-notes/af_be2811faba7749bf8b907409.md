# Implementation note: Acceptance by the precision polynomial is the precision predicate

- Lean names: `ZInQ.Assembly.accepts_iff_Prec`, `ZInQ.Assembly.heightD_ge`,
  `ZInQ.Assembly.precisionHeightConstant_eq_A0`.
- Draft (the compiler chapter's names `ZInQ.Compiler.acceptsNaturals` and
  `ZInQ.Compiler.precisionHeightConstant` are placeholders; use the names from the
  compiler-natural notes):
  ```lean
  theorem heightD_ge : 10 ^ 12 ≤ heightD          -- never evaluates heightD
  theorem precisionHeightConstant_eq_A0 : ZInQ.Compiler.precisionHeightConstant = A0
  theorem accepts_iff_Prec (c : Fin 5 → ℕ) :
      ZInQ.Compiler.acceptsNaturals c ↔
        Prec (dec (c 0)) (dec (c 1)) (dec (c 2)) (dec (c 3)) (dec (c 4))
  ```
- `heightD_ge`: `heightD = heightF0 * 3 ^ _ ≥ heightF0` (`Nat.le_mul_of_pos_right`,
  `Nat.one_le_pow`/`pow_pos`), `heightF0 = 324! ≥ 15!` (`Nat.factorial_le`), and
  `10 ^ 12 < 15!` by `decide`/`norm_num [Nat.factorial]` on a 13-digit number. Do not unfold
  `heightD` or `Nat.factorial 324` any further. Then `max (max heightD 317) (10^12) = heightD`
  (`max_eq_left`), which turns upstream `HeightConstantAlgorithm.heightBody` (with `r = max …`)
  into the compiler's form with `r = D`.
- Admissibility from `zsmul_genP0_affine` (nonzero-multiples note) and `n ≠ 0` from
  `(0:ℚ) ∈ contactSet` (`decide`/`simp [contactSet]`). The two `z` functions agree on affine
  points with `y ≠ 0` by unfolding (`if_pos`).
- Mathlib: `Nat.factorial_le` (Mathlib/Data/Nat/Factorial/Basic.lean), `max_eq_left`.
- FINITE COMPUTATION: only `10^12 < 15!` (kernel `decide` or `norm_num`, 13-digit literals).
  `heightD`, `A0` and `324!` are never evaluated. Difficulty: easy (~80 lines).

Shared conventions (assembly notes): namespace `ZInQ.Assembly`, files under
`ZInQKernel/Assembly/`. `RelT τ a` abbreviates `ZInQ.Syntax.Rel τ.poly τ.parameterCount
τ.witnessCount a` (syntax note for template semantics); codes are `ZInQ.iota : ℤ → Fin 5 → ℚ`
and `ZInQ.pointCode` (point-codes note); `genP0 : genCurve.toAffine.Point`. The hypothesis
quadruple `(hH : SixContactEstimate) (hPC : PoleCompleteness) (hMW : MordellWeilE)
(h22 : FixedPrimePattern)` is written `hyps`. The constants `A0`, `Bnk n κ`, `heightD` and
every power `4 ^ Bnk n κ` must stay symbolic: mark them `@[irreducible]`/`noncomputable` and
never use `decide`, `norm_num` evaluation or `#eval` on them.
