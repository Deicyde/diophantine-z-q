# The height of an accepted slope (contact-support)

- Lean name: `ZInQ.Mult.slope_height_le`.
- Draft:
  ```lean
  theorem slope_height_le (hH : SixContactEstimate) (hMW : MordellWeilE) (n : Fin 3 → ℤ)
      (hf : n 0 * n 1 - n 2 ≠ 0) (t : ℚ) (ht : SlopePred t ell (shifts n)) :
      (contactSupport S_mul t : ℤ) ^ 25 ∣ n 0 * n 1 - n 2 ∧
      ratHeight t ≤ (Aht : ℝ) * |((n 0 * n 1 - n 2 : ℤ) : ℝ)| ^ ((24 : ℝ) / 25)
  ```
