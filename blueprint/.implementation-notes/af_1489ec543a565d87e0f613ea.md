# Implementation note: Sizes under quadratic-field operations

- Lean names: `ZInQ.Size.QRep` (structure `a b c : ℤ`, `c ≠ 0`), `QRep.size`, `QRep.val`,
  `QRep.add`, `QRep.sub`, `QRep.mul`, `QRep.two_mul`, `QRep.div`, `QRep.size_*_le`,
  `QRep.coord_bounds`.
- Draft:
  ```lean
  structure QRep where (a b c : ℤ) (hc : c ≠ 0)
  def QRep.val (r : QRep) : K₀ := ⟨r.a / r.c, r.b / r.c⟩
  def QRep.size (r : QRep) : ℕ := max r.a.natAbs (max r.b.natAbs r.c.natAbs)
  theorem QRep.size_div_le (r r' : QRep) (H : ℕ) (hH : 2 ≤ H) (h : r.size ≤ H) (h' : r'.size ≤ H)
      (h0 : r'.val ≠ 0) : ∃ q : QRep, q.val = r.val / r'.val ∧ q.size ≤ 3 * H ^ 4
  theorem QRep.coord_bounds (r : QRep) : ((r.val).re.num.natAbs ≤ r.size ∧ (r.val).re.den ≤ r.size) ∧ ...
  ```
- Proof: explicit formulas; `a'^2 - 2 b'^2 ≠ 0` from `ZInQ.not_isSquare_two_rat`
  (ZInQKernel/Hypotheses/MordellWeil.lean) or `irrational_sqrt_two`; reduced fractions via
  `Rat.num_dvd` and `Rat.den_dvd` (Mathlib/Data/Rat/Lemmas.lean:26,34: the reduced numerator and
  denominator of `a /. b` divide `a` and `b`) and `Int.le_of_dvd` / `Int.natAbs_le_of_dvd_ne_zero`
  (for `a = 0` the numerator is `0`). Products in `K₀`: `QuadraticAlgebra.re_mul`, `im_mul`
  (Mathlib/Algebra/QuadraticAlgebra/Defs.lean:205,208).
- Finite computation: no.
- Upstream reuse: `ZInQ.ModelDuplicationBounds` (lean/ZInQ/ModelDuplicationBounds.lean) has height
  estimates for the model's duplication formulas; check whether its triple-size lemmas fit before
  writing new ones.
- Difficulty: low-medium (~120 lines).

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
