# The Kummer map is a homomorphism (kummer-homomorphism)

- Lean name: `ZInQ.Descent.kummerHom (b) (hb) : (curveB b).toAffine.Point →+ Additive (SqClass K)`
  with `kummerHom_apply = kummer`.
- Proof plan: reduce to `kummer (P + Q) = kummer P * kummer Q` by cases on `Point.add`
  (`Point.add_some`, `add_of_Y_eq`, `add_self_of_Y_ne`); the key identity is the constant term of
  `WeierstrassCurve.Affine.addPolynomial_slope` (Formula.lean): `x₁ x₂ x₃ = (y₁ - ℓ x₁)²`, read off
  the factorization `addPolynomial x₁ y₁ ℓ = -((X - x₁)(X - x₂)(X - addX x₁ x₂ ℓ))`. Separate the
  cases where one point is `(0,0)` (then `x₃ = b / x₂`).
- Mathlib: `WeierstrassCurve.Affine.addPolynomial`, `addPolynomial_slope`, `addX`, `addY`, `slope`,
  `Polynomial.coeff` lemmas or evaluation at 0.
