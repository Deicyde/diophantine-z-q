# Implementation note: The filtration by abscissa valuation

- Lean name: `ZInQ.Size.filtrationSubgroup`, `ZInQ.Size.t_add_congr`, `ZInQ.Size.smul_mem_filtration`.
- Draft:
  ```lean
  variable {K : Type*} [Field K] (v : Valuation K ℤᵐ⁰) [v.IsRankOneDiscrete] (a : K) (ha : v a ≤ 1)
  def filtrationSubgroup (r : ℕ) (hr : 1 ≤ r) : AddSubgroup (shortCurve a).toAffine.Point
    -- carrier {O} ∪ {some x y _ | v x ≤ exp (-2r)}  (multiplicative notation)
  theorem t_add_congr (Q₁ Q₂ ∈ filtrationSubgroup r) :
      v (tCoord (Q₁ + Q₂) - tCoord Q₁ - tCoord Q₂) ≤ exp (-(5 * r))
  theorem smul_mem_filtration (hp : v (p : K) ≥ exp (-4)) -- i.e. additive v(p) ≤ 4
      (Q ∈ filtrationSubgroup r) (n : ℤ) (hn : n ≠ 0) :
      n • Q ∈ filtrationSubgroup (r + addVal v n)
  ```
  An additive `ℤ∪{∞}` wrapper (`addVal v x = -log (v x)` via `WithZero.unzero`/`Multiplicative.toAdd`)
  makes the statements readable; Mathlib's `Valuation.IsRankOneDiscrete`
  (Mathlib/RingTheory/Valuation/Discrete/Basic.lean) or simply using
  `IsDedekindDomain.HeightOneSpectrum.valuation` (always discrete) are both fine. For the size
  chapter only `K = K₀` with the adic valuation at a prime of `Zs` is needed; stating it for a
  general valued field costs nothing extra.
- Mathlib gap: no formal groups of elliptic curves and no filtration `E_n(K)` in Mathlib
  v4.35.0. The elementary proof (coordinates `t = x/y`, `w = 1/y`, curve `w = t³ + a t w²`, slope
  formula with unit denominator, sum of roots of the cubic) avoids power series entirely; it is
  the proof in Washington's *Elliptic Curves* §8.1 for `ℚ_p`, which carries over verbatim to any
  discrete valuation (completeness is not used). Work with Mathlib's affine formulas
  (`WeierstrassCurve.Affine.slope`, `addX`, `addY`, `negY`) and translate to `(t, w)`.
- Finite computation: no.
- Upstream reuse: none (`ZInQ.ModelDuplicationBounds` concerns heights, not valuations).
- Difficulty: medium-hard (~300 lines). If too long, split (2)-(3) (subgroup and the
  congruence) from (4) (multiplication).
