# Implementation note: Uniform bounds for the finite constructors

- Lean names: `ZInQ.Size.psi_uniform`, `ZInQ.Size.guard_uniform`, `ZInQ.Size.const_uniform`.
- Draft:
  ```lean
  theorem psi_uniform (B : ℕ) (hB : 2 ^ 20 ≤ B) (n : ℤ) (hn : n.natAbs + 1 ≤ B) (c : Fin 2) :
      (Syntax.psiComponent n c).totalDegree ≤ B ^ 4 ∧ l1 (Syntax.psiComponent n c) ≤ 2 ^ B ^ 8
  theorem guard_uniform (B T : ℕ) (hB : 2 ^ 20 ≤ B) (hT : T + 1 ≤ B) :
      (Syntax.guardPoly T).totalDegree ≤ B ^ 4 ∧ l1 (Syntax.guardPoly T) ≤ 2 ^ B ^ 8
  ```
- Proof: monotonicity (`Nat.pow_le_pow_left`) and `2 B^3 ≤ B^4`, `101 B^3 ≤ B^8`,
  `16 B^3 ≤ B^4`, `2^39 B^6 ≤ B^8` from `B ≥ 2^20` (`nlinarith` or explicit `calc`).
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: low.

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
