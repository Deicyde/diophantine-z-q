# The formal logarithm of E is a binomial series (logarithm-series)

- Lean names: `ZInQ.Mult.invX_series`, `ZInQ.Mult.invariantDifferential_series`,
  `ZInQ.Mult.formalLog_eq_binomial`.
- Draft:
  ```lean
  theorem formalLog_eq_binomial :
      formalLog (-(genD ^ 2)) = PowerSeries.mk fun n =>
        if n % 4 = 1 then ((-1) ^ (n / 4) * (Nat.centralBinom (n / 4) : K0) * genD ^ (2 * (n / 4)) / n)
        else 0
  ```
- Mathlib: `PowerSeries`, `PowerSeries.binomialSeries` (Mathlib/RingTheory/PowerSeries/Binomial.lean)
  with `Ring.choose (-1/2) j`; `Nat.centralBinom`; `PowerSeries.derivative`. The identity
  `Ring.choose (-1/2 : ℚ) j * 4^j = (-1)^j * centralBinom j` must be proved (induction; there is
  `Nat.succ_mul_centralBinom_succ`).
- Proof: power-series algebra in `K0[[z]]`: uniqueness of the root `u` of `A z² u² - u + z² = 0`
  with `u(0) = 0` (Hensel/recursion on coefficients), the square-root identity, then derivative
  comparison. ~300-500 lines.
- FINITE COMPUTATION: no. Difficulty: medium-hard.

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
