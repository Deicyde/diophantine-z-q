# Implementation note: Normalized division polynomials and their components

- Lean names: `ZInQ.Syntax.normDiv` (the `f_n`), `ZInQ.Syntax.divPsi` (the `ψ_n`),
  `ZInQ.Syntax.psiComponent : ℤ → Fin 2 → MvPolynomial (Fin 4) ℤ`.
- Draft:
  ```lean
  noncomputable def normDiv {R : Type*} [CommRing R] (A : R) : ℕ → R[X]
    | 0 => 0 | 1 => 1 | 2 => 1 | 3 => 3*X^4 + 6*C A*X^2 - C A^2
    | 4 => 2*(X^6 + 5*C A*X^4 - 5*C A^2*X^2 - C A^3)
    | n+5 => ... -- even/odd recurrences, decreasing_by omega
  ```
  Components: `R := QuadraticAlgebra (MvPolynomial (Fin 4) ℤ) 2 0`, `A := ⟨-11243, 7950⟩`,
  evaluate `divPsi A n` at `x = ⟨X 0, X 1⟩`, `y = ⟨X 2, X 3⟩` (`Polynomial.eval₂`/`aeval` for the
  bivariate `R[X][Y]`) and take `.re`/`.im`. Alternatively define `normDiv` directly on the
  quadratic algebra elements (a function `R → ℕ → R`), which avoids bivariate polynomials;
  the classical-agreement article then compares after evaluation.
- Mathlib: `QuadraticAlgebra` (Mathlib/Algebra/QuadraticAlgebra/Defs.lean), `Polynomial`,
  `Polynomial.Bivariate` (`R[X][Y]`) as used in Mathlib/AlgebraicGeometry/EllipticCurve/DivisionPolynomial/Basic.lean.
- Upstream reuse: none. Mirrors construction/elliptic-division-polynomials.js `divisionPolynomials`.
- Finite computation: no. Never unfold `normDiv` at the index `c_*`; only the recurrence
  lemmas are used.
- Difficulty: low-medium (~120 lines; termination proof for the recursion).
