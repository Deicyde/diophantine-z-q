# The truncated logarithm is 16575z times a unit (truncation-unit)

- Lean name: `ZInQ.Mult.log25_eq_mul_unit`.
- Draft:
  ```lean
  theorem log25_eq_mul_unit (𝔭 : HeightOneSpectrum Zs) (z : K0) (hz : 1 ≤ vP 𝔭 z) :
      ∃ η : K0, 2 ≤ vP 𝔭 η ∧ L z = 16575 * z * (1 + η)
  theorem log25_ne_zero (𝔭) (z : K0) (hz0 : z ≠ 0) (hz : 1 ≤ vP 𝔭 z) : L z ≠ 0
  ```

  `vP 𝔭 16575 ≤ 2` from the factorization and `vP_ratCast` (primes-above-p) / special-primes at (s).

`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
