# Division polynomials form an elliptic sequence (division-polynomial-elliptic-sequence)

- Lean names: `ZInQ.normEDS_rel` (general law for Mathlib's `normEDS b c d`), and its
  specialization `ZInQ.psi_rel (A : K) (m n : ℤ)` in the coordinate ring
  `(shortCurve A).toAffine.CoordinateRing`, or directly for values at a point.
- Draft:
  ```lean
  theorem normEDS_rel {R : Type*} [CommRing R] (b c d : R) (m n : ℤ) :
      normEDS b c d (m + n) * normEDS b c d (m - n) =
        normEDS b c d (m + 1) * normEDS b c d (m - 1) * normEDS b c d n ^ 2 -
        normEDS b c d (n + 1) * normEDS b c d (n - 1) * normEDS b c d m ^ 2
  ```
  Mathlib v4.35.0 `Mathlib/NumberTheory/EllipticDivisibilitySequence.lean` defines `normEDS`,
  `IsEllipticSequence`, `IsEllipticDvdSequence`, `rel`, `atomRel` and lists as TODO
  "prove that `normEDS` satisfies `IsEllipticDvdSequence`" (line 68). So the law is a Mathlib
  gap; the statement above is exactly the missing `IsEllipticSequence (normEDS b c d)` and is a
  natural upstream contribution. Over a domain one may divide by `b`; the universal ring
  `ℤ[b,c,d]` is a domain, so prove it there (`MvPolynomial (Fin 3) ℤ`) and transport with
  `map_normEDS`.
- Bridge to the manuscript's ψ: `syntax/division-polynomials-classical.md` identifies the
  manuscript's `f_n` with Mathlib's `preΨ` (`preΨ_even`, `preΨ_odd` in
  `Mathlib/AlgebraicGeometry/EllipticCurve/DivisionPolynomial/Basic.lean`), and `Ψ n` is
  `normEDS ψ₂ Ψ₃ preΨ₄` up to the documented normalization; use `Affine.CoordinateRing.mk_Ψ_sq`
  to replace `ψ₂²` by `Ψ₂Sq` modulo the curve.
- References for the induction: M. Ward, "Memoir on elliptic divisibility sequences",
  Amer. J. Math. 70 (1948); the strong induction over halved indices is the standard route.
  Before formalizing, check Mathlib master and Zulip for an existing proof of the TODO.
