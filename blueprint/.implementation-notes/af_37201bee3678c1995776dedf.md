# The twelve local tests (twelve-tests)

- Lean name: `ZInQ.Mult.testValues (h : ℤ) (z : Fin 3 → ℤ) (c : Fin 4 → ℤ) : Fin 12 → K0`.
- Draft:
  ```lean
  noncomputable def invX (Q : genCurve.toAffine.Point) : K0 := match Q with
    | .zero => 0 | .some x _ _ => x⁻¹
  noncomputable def Lam (Q) : K0 := L (zOf Q)          -- zOf O = 0, zOf (x,y) = -x/y
  noncomputable def testValues (h z c) : Fin 12 → K0 :=
    let H := h • genP0; let U i := z i • genP0
    let V0 := (h - c 0) • genP0; let V i := (z i - c i.succ) • genP0
    let A i := Lam (U i) / Lam H; let B i := Lam (V i) / Lam V0
    ![invX H, invX (U 0), invX (U 1), invX (U 2), star (invX V0), star (invX (V 0)),
      star (invX (V 1)), star (invX (V 2)), A 0 - star (B 0), A 1 - star (B 1), A 2 - star (B 2),
      A 0 * A 1 - A 2]
  ```
  Lean's `x / 0 = 0` makes the definition total; the nonvanishing lemma is a separate fact.
- Never evaluate (`h`, `c` involve `c_*`).
- FINITE COMPUTATION: no. Difficulty: easy (definition).

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
