# Implementation note: The signed encoding of integers

- Lean names: `ZInQ.Compiler.Precision.enc : ℤ → ℕ`, `ZInQ.Compiler.Precision.dec : ℕ → ℤ`,
  `decode5 : (Fin 5 → ℕ) → Fin 5 → ℤ`.
- Draft:
  ```lean
  def enc (n : ℤ) : ℕ := if 0 ≤ n then 2 * n.toNat else 2 * (-n).toNat - 1
  def dec (c : ℕ) : ℤ := if c % 2 = 0 then (c / 2 : ℕ) else -(((c + 1) / 2 : ℕ) : ℤ)
  ```
  Coordinate with the assembly and translation chapters, which use the same encoding for
  the signed codes (`value.signed_encode`); use one shared definition.
- Mathlib: `Int.toNat`, `Int.natAbs`.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: trivial.
