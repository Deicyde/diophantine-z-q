# Implementation note: Register machines

- Lean names: `ZInQ.Compiler.RM.Instr`, `RM.Machine := ℕ → Instr`, `RM.Config`, `RM.step`,
  `RM.Halts`, `RM.Program := List Instr`, `RM.Program.Valid`, `RM.Program.toMachine`,
  `RM.Program.HaltsOn`, `RM.Program.Accepts`, `RM.Program.subCount`, `addCount`.
- Draft:
  ```lean
  inductive Instr | inc (j x : ℕ) | dec (j x y : ℕ) | halt
  structure Config where (state : ℕ) (regs : ℕ → ℕ)
  def step (μ : Machine) (c : Config) : Option Config := match μ c.state with
    | .inc j x => some ⟨x, Function.update c.regs j (c.regs j + 1)⟩
    | .dec j x y => if c.regs j = 0 then some ⟨y, c.regs⟩ else some ⟨x, Function.update c.regs j (c.regs j - 1)⟩
    | .halt => none
  def Halts (μ : Machine) (ρ : ℕ → ℕ) : Prop := ∃ t c, stepN μ t ⟨0, ρ⟩ = some c ∧ μ c.state = .halt
  def Program.Accepts (p : Program) (k : ℕ) (a : Fin k → ℕ) : Prop :=
    ∃ t c, stepN p.toMachine t ⟨0, init a⟩ = some c ∧ c.state = p.length - 1 ∧ ∀ j, c.regs j = 0
  ```
  Use `ℕ → ℕ` register files (finitely supported implicitly); validity bounds registers by
  `r` so only `Fin r` matters for the packed compiler.
- Mathlib: `Function.update`, `Option.bind`. Mathlib has Turing machines
  (`Mathlib/Computability/TuringMachine.lean`) and `Nat.Partrec.Code`, but no register
  machines; nothing to reuse.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: easy.
