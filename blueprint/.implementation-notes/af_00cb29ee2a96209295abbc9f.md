# Implementation note: A bound for L(σ,χ) near 1

- Owner: pp-lseries (plan step 1). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: `ZInQ.Progressions.norm_LFunction_le`.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  theorem norm_LFunction_le {χ : DirichletCharacter ℂ q} (hχ : χ ≠ 1) {σ : ℝ}
      (h1 : 1 ≤ σ) (h2 : σ ≤ 2) :
      ‖χ.LFunction σ‖ ≤ Real.log q + 3
  ```
- Mathlib: `DirichletCharacter.LFunction_eq_LSeries`, `DirichletCharacter.differentiable_LFunction` (continuity at `σ = 1`), `le_of_tendsto` along `𝓝[>] 1`, `harmonic_le_one_add_log`. Upstream helper `norm_LFunction_sub_sum_le` (`LSeries/Tail.lean`) gives `‖L(σ,χ) - ∑_{n≤N} χ(n)/n^σ‖ ≤ q (N+1)^(-σ)` for `σ > 1`; take `N = q`.
- The upper limit `σ ≤ 2` is not needed by the proof; keep it to match the article (or drop it in both).
