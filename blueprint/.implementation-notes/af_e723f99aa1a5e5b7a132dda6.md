# Sum and quotient bounds for rational heights (rational-height-bounds)

- Lean name: `ZInQ.Mult.ratHeight_add3_le`, `ZInQ.Mult.ratHeight_div_le`.
- Draft:
  ```lean
  theorem ratHeight_add3_le (x y z : ℚ) : ratHeight (x + y + z) ≤ ratHeight x + ratHeight y + ratHeight z + Real.log 3
  theorem ratHeight_div_le (x y : ℚ) : ratHeight (x / y) ≤ ratHeight x + ratHeight y
  ```
- Mathlib HAS these (background, in Mathlib v4.35.0): `Height.logHeight₁_sum_le` (with
  `totalWeight ℚ = 1`), `Height.logHeight₁_mul_le`, `Height.logHeight₁_inv`, and the bridge
  `Rat.logHeight₁_eq_log_max : logHeight₁ q = log (max |num| den)`
  (Mathlib/NumberTheory/Height/NumberField.lean). `ZInQ.ratHeight` (Hypotheses/Height.lean) uses
  real `|num|` and `den`; prove `ratHeight q = Height.logHeight₁ q` by `Rat.logHeight₁_eq_log_max` and
  a cast lemma. `totalWeight ℚ = 1` follows from `NumberField.totalWeight_eq_finrank` (verified in Mathlib/NumberTheory/Height/NumberField.lean) and `Module.finrank_self`.
- Upstream: `ZInQ.rationalLogHeight` (lean/ZInQ/RationalSeparation.lean) is the same function.
- FINITE COMPUTATION: no. Difficulty: easy (~50 lines).

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
