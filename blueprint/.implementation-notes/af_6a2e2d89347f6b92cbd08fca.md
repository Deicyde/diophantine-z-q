- Method: `native_decide` first (it evaluates the compiler chapter's construction). Kernel

  functions of the program (preferred: the compiler's node emission is structural, so

  `c_3 > 1399` from its definition (no need to compute its digits); if `c_3` is pinned as a
  literal, `Nat.decEq` on GMP naturals decides it at once.

- Upstream reuse: none.
- Difficulty: low with `native_decide`; medium for the kernel route (a) or (b).
