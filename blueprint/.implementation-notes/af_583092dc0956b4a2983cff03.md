# Implementation note: The finite false-triple product

- Lean name: `ZInQ.Syntax.guardPoly : ℕ → MvPolynomial (Fin 15) ℤ`.
- Draft:
  ```lean
  noncomputable def guardPoly (T : ℕ) : MvPolynomial (Fin 15) ℤ :=
    ∏ abc ∈ (box T).filter (fun abc => abc.1 * abc.2.1 ≠ abc.2.2),
      let q : Fin 15 → ℚ := tripleCode abc        -- coordinates of ι a, ι b, ι c
      let D : ℕ := ∏ j, (q j).den
      ∑ j, (C (D : ℤ) * X j - C ((D / (q j).den : ℕ) * (q j).num)) ^ 2
  where box T := Finset.Icc (-(T:ℤ)) T ×ˢ Finset.Icc (-(T:ℤ)) T ×ˢ Finset.Icc (-(T:ℤ)) T
  ```
  `ι` is the model chapter's code map (`ZInQ.iota`, name to be matched).
- Mathlib: `Finset.Icc` on `ℤ` (Mathlib/Data/Int/Interval.lean), `Finset.prod`, `Rat.num`,
  `Rat.den`, `Finset.dvd_prod_of_mem`.
- Upstream reuse: none. Mirrors `integerGuardPolynomial` in construction/rational-model-assembly.js
  (which computes codes by the group law, as here; the JSON text describes them via ψ).
- Finite computation: no. Never expanded (it has about `8(T+1)^3` factors).
- Difficulty: low (~50 lines).
