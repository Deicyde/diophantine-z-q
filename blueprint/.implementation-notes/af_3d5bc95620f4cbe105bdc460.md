# Positivity and smallness of the pole input (pole-input-positivity)

- Lean name: `ZInQ.Mult.pole_input_small`.
- Draft:
  ```lean
  theorem pole_input_small (R0 ℓ : ℚ) (hR0 : 0 < R0) (hℓ : ℓ ≠ 0) (C : Fin 6 → Fin 12 → K0) :
      ∃ ε > 0, ∀ a : ℚ, 0 < |a| → |a| < ε →
        let R := ℓ^2 * a^2 * R0; let W g := ∏ j, (1 + (R : K0) * C g j ^ 2)
        let Θ : ℚ := 2 * (∑ g, (W g)⁻¹).re
        (∀ g, W g ≠ 0) ∧ 0 < Θ ∧ Θ ≤ 12 ∧ 0 < R / Θ^2 ∧ R / Θ^2 < 1/2
  ```
