# Implementation note: The twisted sum and L(1,χ)

- Owner: pp-mertens (plan step 4.2). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.norm_LFunction_one_mul_twistedSum_le`.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  open ArithmeticFunction in
  theorem norm_LFunction_one_mul_twistedSum_le {χ : DirichletCharacter ℂ q} (hχ : χ ≠ 1)
      {x : ℝ} (hx : 1 ≤ x) :
      ‖χ.LFunction 1‖ * ‖∑ n ∈ Finset.Ioc 0 ⌊x⌋₊, χ n * Λ n / n‖ ≤
        (Real.log q + 3) ^ 2 + 12 * q
  ```
- Mathlib: `ArithmeticFunction.vonMangoldt_sum`, `Nat.sum_divisorsAntidiagonal` / `Finset.sum_sigma'` to exchange `n = d m`, `Nat.floor_div_eq_div` (`⌊⌊x⌋/d⌋ = ⌊x/d⌋`), `Chebyshev.psi_le_const_mul_self`, `Chebyshev.psi_eq_sum_Icc`; the L-series inputs `norm_partialSum_sub_LFunction_one_le` and `norm_partialSum_log_le`.
- Stated as a product to avoid dividing by `L(1,χ)`; the division happens in the uniform bound, where `L(1,χ) ≠ 0` comes from the lower bounds.
