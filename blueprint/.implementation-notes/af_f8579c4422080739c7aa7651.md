# The search box (search-box)

- Lean name: `ZInQ.mem_searchBox_of_hK0_lt (x : K0) (hx : hK0 x < Real.log 9) :
  (x.im = 0 ∧ ∃ p q, ...) ∨ (x.im ≠ 0 ∧ ∃ a b c k, boxCond a b c k ∧ (x = ⟨-b/(2a), k/(2a)⟩ ∨ x = ⟨-b/(2a), -k/(2a)⟩))`.
- Mathlib: `Rat.num`, `Rat.den`, `Int.gcd`, `Real.sqrt`; for the content division `Polynomial.content`
  is optional (do it by hand with `Int.gcd` of three integers). Mathlib's
  `Polynomial.mahlerMeasure` (`Mathlib/NumberTheory/MahlerMeasure.lean`) is not needed for degree 2.
- FINITE COMPUTATION: no. Difficulty: medium (inequalities with two embeddings and an integrality step).
