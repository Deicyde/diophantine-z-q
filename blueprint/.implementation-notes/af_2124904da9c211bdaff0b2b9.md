# Implementation note: Private witness blocks

- Lean name: `ZInQ.Syntax.Formula.exists_blocks_iff`.
- Draft:
  ```lean
  theorem Formula.exists_blocks_iff (φ : Formula) (calls : CallTable)
      (hdisj : calls.BlocksDisjoint) (hfree : φ.AtomVarsAvoid calls.blocks)
      (hparams : calls.ParamsAvoidBlocks) (x : ℕ → ℚ) :
      (∃ y : ℕ → ℚ, (∀ i ∉ calls.blocks, y i = x i) ∧ φ.Holds y) ↔ φ.liftRel calls x
  ```
  Represent a call atom as `.atom (callPoly P p w g)` tagged with its `(P,p,m,w,g)` (a
  `Formula` variant `call` carrying this data, compiled to `callPoly`), so that `liftRel` can
  replace it by `Rel`.
- Proof: induction on the formula; for `and`, glue witnesses with `fun i => if i ∈ blockSet φ_j then y_j i else ...`.
- Mathlib: `Finset.Ico`, `Set.piecewise`, `Disjoint`.
- Upstream reuse: `ZInQ.EquationCompression.exists_conjunction_fresh_iff` and
  `exists_disjunction_fresh_iff` prove the binary `Sum`-typed case; this is the `ℕ`-indexed
  n-ary generalization. Use them as proof templates.
- Finite computation: no.
- Difficulty: medium (~250 lines).
