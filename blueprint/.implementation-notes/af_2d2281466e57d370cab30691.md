# Canonical height (canonical-height)

- Lean name: `ZInQ.canonHeight (T : curveC.toAffine.Point) : ℝ :=
  (limUnder Filter.atTop fun m : ℕ => hx ((2 ^ m) • T) / 4 ^ m) / 2`.
- Mathlib: `limUnder`, `Filter.Tendsto`, `cauchySeq_of_le_geometric` (or
  `cauchySeq_of_summable_dist`). Mathlib v4.35.0 has no canonical height on elliptic curves
  (only `naiveHeight` and the approximate parallelogram law).
- FINITE COMPUTATION: no. Difficulty: easy (definition).
