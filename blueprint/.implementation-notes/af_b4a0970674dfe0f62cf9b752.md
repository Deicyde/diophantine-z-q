# Implementation note: The parameter R equals D

- Lean name: `ZInQ.Size.R_eq_D`.
- Draft:
  ```lean
  theorem R_eq_D (hCAT : CatalogueBound) : Syntax.R = Syntax.D
  ```
  `R` is `max D (max Hmax (max cstar (10^12)))` (or the `FixedExpr.max` list fold, as defined by
  the syntax chapter): `max_eq_left` after `Hmax ≤ D`, `cstar ≤ D`, `10^12 ≤ D`.
- Proof ingredients: `Hmax < 2^(W^3) < 2^(2^1536) < 2^(2^8008) < D` with `W^3 < 2^1536` from
  `W < 2^512`; `cstar < 2^(2^2059) < D`; `10^12 < 2^40 ≤ D`.
- Mathlib: `max_eq_left`, `Nat.pow_lt_pow_right`, `Nat.pow_lt_pow_left`.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: low.

Shared design (size notes): namespace `ZInQ.Size`, files under `ZInQKernel/Size/`. Constants are
the syntax chapter's abbreviations `ZInQ.Syntax.Ps`, `W`, `Hcat`, `Hmax`, `Ns`, `M0`, `cstar`,
`ell`, `F`, `D`, `G0`, `E0`, `R`, `Q`, `Bcm`, `Ccm`, `Aht`, `T` (natural numbers or `toNat` of
`FixedExpr.val`; prove unfolding lemmas `T_def : T = (48 * Aht)^13` etc. by `rfl`/`simp
[FixedExpr.val]`). None of them is ever evaluated: never `decide`, `norm_num` or `rfl`-reduce a
goal containing `D`, `T`, `Hcat`, `M0`, `cstar`, `ell` or `c_3`; mark them `@[irreducible]`
after the unfolding lemmas, and work with `Nat.pow_lt_pow_left/right`, `Nat.pow_le_pow_left/right`,
`Nat.lt_two_pow_self`, `Nat.mul_lt_mul_of_lt_of_lt` as in upstream
`ZInQ.ExplicitCutoffBounds` (lean/ZInQ/ExplicitCutoffBounds.lean).
