# Implementation note: Substitution and renaming bounds

- Lean names: `ZInQ.Size.totalDegree_bind₁_le`, `ZInQ.Size.l1_bind₁_le`,
  `ZInQ.Size.l1_rename_le`.
- Draft:
  ```lean
  theorem totalDegree_bind₁_le (P : MvPolynomial σ ℤ) (Q : σ → MvPolynomial τ ℤ) (d : ℕ) (hd : 1 ≤ d)
      (hQ : ∀ i ∈ P.vars, (Q i).totalDegree ≤ d) : (bind₁ Q P).totalDegree ≤ d * P.totalDegree
  theorem l1_bind₁_le (P : MvPolynomial σ ℤ) (Q : σ → MvPolynomial τ ℤ) (M : ℕ) (hM : 1 ≤ M)
      (hQ : ∀ i ∈ P.vars, l1 (Q i) ≤ M) : l1 (bind₁ Q P) ≤ l1 P * M ^ P.totalDegree
  theorem l1_rename_le (f : σ → τ) (P : MvPolynomial σ ℤ) : l1 (rename f P) ≤ l1 P
  ```
  The syntax chapter's `callPoly` is `bind₁`, so these apply directly to calls.
- Proof: `MvPolynomial.as_sum`, `bind₁_monomial` (Mathlib/Algebra/MvPolynomial/Monad.lean:276),
  `Finsupp.prod` estimates with `l1_pow_le`/`l1_prod_le`; degree via `totalDegree_finsetProd` and
  `totalDegree_pow`. Mathlib has `MvPolynomial.totalDegree_rename_le`
  (Mathlib/Algebra/MvPolynomial/Degrees.lean:597) but no degree bound for `bind₁`/`aeval` and no
  norm bound (small gaps). For `l1_rename_le`: `rename f (monomial m c) = monomial (m.mapDomain f) c`
  and subadditivity.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: medium (~150 lines).

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
