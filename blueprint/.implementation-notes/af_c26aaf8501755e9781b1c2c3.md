# Implementation note: The least formal multiple

- Lean names: `ZInQ.Syntax.normalizedRep`, `ZInQ.Syntax.leastFormalMultiple`.
- Draft:
  ```lean
  noncomputable def normalizedRep (u : K₀) : ℤ × ℤ × ℕ   -- (a, b, c), c > 0, gcd = 1
  noncomputable def leastFormalMultiple (N : ℕ) : ℕ :=
    sInf {m : ℕ | 1 ≤ m ∧ let r := normalizedRep (xi (m • P₀)); (N:ℤ)^4 ∣ r.1 ∧ (N:ℤ)^4 ∣ r.2.1 ∧ Nat.Coprime r.2.2 N}
  ```
  (`sInf ∅ = 0` gives the stated convention.) `xi Q = (x Q)⁻¹` for affine `Q`, `0` at `O`;
  Lean's `0⁻¹ = 0` matches the convention at points with `x = 0`.
- Mathlib: `Nat.sInf_def`, `Nat.sInf_mem`; `WeierstrassCurve.Affine.Point` and its
  `AddCommGroup` instance (Mathlib/AlgebraicGeometry/EllipticCurve/Affine/Point.lean) for
  `m • P₀`, through the model chapter's `E`.
- Upstream reuse: none. Mirrors `localMultiplier`/`localDepthCondition` in
  construction/fixed-certificate-constants.js and construction/rational-field-arithmetic.js.
- Finite computation: no (never evaluated).
- Difficulty: low-medium (normalized representation needs a small gcd lemma).
