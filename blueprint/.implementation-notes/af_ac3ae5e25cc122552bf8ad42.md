# Implementation note: The prime catalogue

- Lean names: `ZInQ.Syntax.cataloguePrime`, `ZInQ.Syntax.catalogueProduct`,
  `ZInQ.Syntax.catalogueMax`.
- Draft:
  ```lean
  noncomputable def cataloguePrime (W B r j : ℕ) : ℕ :=
    Nat.nth (fun p => p.Prime ∧ B < p ∧ p % W = r % W) j
  noncomputable def catalogueProduct (W k B : ℕ) : ℕ :=
    ∏ r ∈ (Finset.range W).filter (fun r => 1 ≤ r ∧ Nat.Coprime r W), ∏ j ∈ Finset.range k, cataloguePrime W B r j
  noncomputable def catalogueMax (W k B : ℕ) : ℕ :=
    ((Finset.range W).filter (fun r => 1 ≤ r ∧ Nat.Coprime r W)).sup fun r =>
      (Finset.range k).sup fun j => cataloguePrime W B r j
  ```
