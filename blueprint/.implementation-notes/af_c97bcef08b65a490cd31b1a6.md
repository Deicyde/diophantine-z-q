# Implementation note: Closure rules for the height majorant

- Lean names: `ZInQ.Size.Maj.mono`, `Maj.X`, `Maj.C`, `Maj.add`, `Maj.mul`, `Maj.bind₁`,
  `Maj.constructor`, `Maj.rename`, `Maj.sum_sq`, `Maj.prod`.
- Draft:
  ```lean
  theorem Maj.bind₁ {B H k : ℕ} (hB : 2 ^ 20 ≤ B) {P : MvPolynomial ℕ ℤ} {Q : ℕ → MvPolynomial ℕ ℤ}
      (hP : Maj B H P) (hQ : ∀ i ∈ P.vars, Maj B k (Q i)) : Maj B (H + k + 1) (bind₁ Q P)
  theorem Maj.sum_sq {B h : ℕ} (hB : 2 ^ 20 ≤ B) (cs : List (MvPolynomial ℕ ℤ)) (hlen : cs.length ≤ B)
      (hc : ∀ c ∈ cs, Maj B h c) : Maj B (h + 2) (cs.map (· ^ 2)).sum
  ```
  `Maj.constructor` is stated for `bind₁ Q C` with `C : MvPolynomial (Fin m) ℤ` (or ℕ-indexed)
  satisfying `C.totalDegree ≤ B^4 ∧ l1 C ≤ 2^(B^8)`.
- Proof: the substitution bounds and elementary estimates; exponent inequalities such as
  `B^(8H) + B^(8H) * B^(8k) ≤ B^(8(H+k+1))` from `B ≥ 2` (`pow_add`, `Nat.pow_le_pow_right`,
  `nlinarith`). Case split `k = 0` for `bind₁` and `constructor`.
- Mathlib: `Nat.pow_le_pow_right`, `Nat.pow_le_pow_left`, `pow_add`, `pow_mul`.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: medium (~200 lines of exponent arithmetic).

Shared design (majorant notes): `Maj B h P : Prop := if h = 0 then P.totalDegree ≤ 1 ∧ l1 P ≤ 1
else P.totalDegree ≤ B ^ (8 * h) ∧ l1 P ≤ 2 ^ B ^ (8 * h)` (helper def in `ZInQKernel/Size/Majorant.lean`).
Heights are computed on the syntax chapter's node lists (`ZInQ.Syntax.Template.nodes`, produced by
`Prog.dag`), so they depend only on syntax, never on the values of fixed expressions.
