# Implementation note: Rational coordinates at odd primes

- Lean name: `ZInQ.Size.padicValRat_coords_ge`.
- Draft:
  ```lean
  theorem padicValRat_coords_ge {p : ℕ} [Fact p.Prime] (hodd : p ≠ 2) (k : ℤ) (u : K₀)
      (hu : ∀ 𝔭 ∈ primesAbove p, (k : WithTop ℤ) ≤ vP 𝔭 u) :
      (u.re ≠ 0 → k ≤ padicValRat p u.re) ∧ (u.im ≠ 0 → k ≤ padicValRat p u.im)
  ```
- Proof: `u.re = (u + star u) / 2`, `u.im = (u - star u) / (2 * s)` in `QuadraticAlgebra`
  (`QuadraticAlgebra.star` / conjugation lemmas, Mathlib/Algebra/QuadraticAlgebra/Basic.lean),
  `vP 𝔭 (star u) = vP (conj 𝔭) u`, ultrametric inequality (`Valuation.map_add`), and
  `vP 𝔭 (c : ℚ) = padicValRat p c` for `𝔭 ∋ p` with `vP 𝔭 p = 1`.
- Mathlib: `Valuation.map_add`, `Valuation.map_mul`, `padicValRat`, `QuadraticAlgebra.re/im`.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: medium (~100 lines; the comparison of the adic valuation on `ℚ ⊂ K₀` with
  `padicValRat` is the main bookkeeping).

Shared design (formal-multiple notes): work on `K₀ = QuadraticAlgebra ℚ 2 0` and the model
chapter's integer ring `Zs` (`QuadraticAlgebra ℤ 2 0`, a PID by the model chapter). Valuations at

values in `ℤᵐ⁰`), or an additive wrapper `vP 𝔭 : K₀ → WithTop ℤ`; at `(s)` reuse the model

about valuations on `K₀` itself.
