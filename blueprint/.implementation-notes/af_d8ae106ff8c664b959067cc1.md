# Implementation note: The precision program

- Lean name: `ZInQ.Compiler.IR.precisionProgram : IR.Program` (5 inputs).
- Draft: a `def` assembled with a register allocator monad (`StateM ℕ` handing out fresh
  register blocks) from the routines, in the order of `decide5`; the register bound is the
  allocator's final counter (an explicit numeral once the program is fixed; compute it with
  `decide`/`rfl`, it is small).
- Size target: the lowered machine (with the wrapper prefix) must keep the program literal
  within the wrapper size check (at most 200,000 instructions in the whole wrapper, every
  register index and target below 2^18), as the manuscript's does (146,780 instructions,
  23,633 registers).
- Mathlib: none.
- Upstream reuse: none (S22 is not in this repository).
- FINITE COMPUTATION: no. Difficulty: medium (≈300 lines of program text).
