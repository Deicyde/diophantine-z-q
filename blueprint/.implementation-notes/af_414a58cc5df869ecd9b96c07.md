# Implementation note: Soundness of the packed-history construction

- Lean name: `ZInQ.Compiler.Packed.sound`.
- Draft:
  ```lean
  theorem sound (p : RM.Program) (r k : ℕ) (hp : p.Valid r) (hk : 1 ≤ k ∧ k ≤ r)
      (a : Fin k → ℕ) (h : PackedConditions p r k a) : p.Accepts r a
  ```
  where `PackedConditions` is the conjunction with macros replaced by relations (the
  right-hand side of `dag_natRel_iff` + `macro_sem`, stated directly on natural values).
- Proof: build `RM.Run` from the digits; induction on `t ≤ q` with the transition lemmas.
- Mathlib: none beyond arithmetic.
- Upstream reuse: `PackedHistory.packed_register_decode`.
- FINITE COMPUTATION: no. Difficulty: hard (≈300 lines; the run reconstruction and the
  bookkeeping of indicator digits).
