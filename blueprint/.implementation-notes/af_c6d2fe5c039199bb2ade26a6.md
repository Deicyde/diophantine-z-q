- Lean name: `ZInQ.iota_eq_psi`.
- Draft:

  theorem iota_eq_psi (n : ℕ) (hn : 1 ≤ n) :
      psiEval (n:ℤ) genP0x genP0y ≠ 0 ∧
      iota n = ![0, (xn n).re, (xn n).im, (yn n).re, (yn n).im]
