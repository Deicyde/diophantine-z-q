# Implementation note: Correctness of the lowering

- Lean names: `ZInQ.Compiler.IR.block_spec` (one per block), `IR.code_sim` (item 0),
  `IR.lower_accepts_of_accepts`, `IR.accepts_of_lower_halts`, `IR.lower_halts_iff`.
- Draft:
  ```lean
  theorem lower_halts_iff (P : IR.Program) (a : Fin P.inputs → ℕ) :
      (IR.lower P).HaltsOn a ↔ IR.Accepts P a
  theorem lower_accepts_iff (P) (a) : (IR.lower P).Accepts P.inputs a ↔ IR.Accepts P a
  ```
- Proof: simulation relation `Sim (ρ : ℕ → ℕ) (σ : ℕ → ℕ) := ∀ i < ρS, σ i = ρ i ∧ σ J = 0 ∧
  ∀ i ≥ J+1, σ i = 0`; forward by induction on `BigStep`; backward by strong induction on the
  number of machine steps, using determinism of `RM.step` and a "run decomposes at block
  boundaries" lemma.
- Mathlib: `Nat.strong_induction_on`, `Relation.ReflTransGen`.
- Upstream reuse: none.
