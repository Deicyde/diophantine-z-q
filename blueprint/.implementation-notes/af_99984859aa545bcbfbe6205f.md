  `orthogonal_sem`, `mask_sem`, `bitAnd_sem` (one lemma per macro, each a `HoldsSome ↔ rel`).
- Draft:
  ```lean
  theorem mask_sem (mode) (a b : MvPolynomial ℕ ℤ) (s) (h : ArgsBelow a b s.next) (x : ℕ → ℕ) :
      ((mask mode a b).run' s).HoldsSome x ↔
        Nat.land (evalNat x a) (evalNat x b) = evalNat x a
  ```
