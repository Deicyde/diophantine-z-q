# Implementation note: Exact node statistics of the halting circuit

- Statement: `ZInQ.Compiler.NodeCheck.HaltingAddMulCheck` (the two exact counts) and
  `ZInQ.Compiler.Universal.HaltingNodeCheck`, with `haltingNodeCheck_of_addMul` in the kernel
  (`Compiler/NodeCheck/Reduced.lean`).
- Checked by native evaluation of the verified fast builder in the separate library
  `ZInQFinite` (`haltingAddMulCheck_native`, `haltingNodeCheck_native`). No theorem of
  `ZInQKernel` uses the equality: the main theorem needs only the bounds of halting-node-check,
  which are kernel proofs.
- Open: a kernel proof. The bounds are the upper half (the presence-only judgment `Up` of
  `Compiler/NodeBound/`). The lower half needs every request not counted as a repeat to create
  a new node: a twin judgment using distinct handle codes and the injectivity of node keys
  (`NodeCheck.key_inj`), or a kernel run split across many declarations. One declaration
  running the whole builder needs about 70 GB.
