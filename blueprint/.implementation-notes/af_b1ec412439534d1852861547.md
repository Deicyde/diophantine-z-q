# Implementation note: Semantics of the natural-code template

- Lean name: `ZInQ.Syntax.natural_rel_iff`.
- Draft:
  ```lean
  /-- Input M as a proposition about the constructed template (the multiplication
  chapter proves it from the hypotheses). -/
  def MultiplyCorrect : Prop :=
    ∀ P Q R : Fin 5 → ℚ,
      Rel multiplyTemplate.poly 15 35134 (Fin.append (Fin.append P Q) R) ↔
        ∃ a b : ℤ, P = iota a ∧ Q = iota b ∧ R = iota (a * b)

  theorem natural_rel_iff (hM : MultiplyCorrect) (A : Fin 5 → ℚ) :
      Rel naturalTemplate.poly 5 140604 A ↔ ∃ n : ℕ, A = iota n
  ```
  `iota` is the model chapter's code map; `MultiplyCorrect` should be the very proposition
  the multiplication chapter exports for input M (agree the name with that chapter; if it
  exports a differently packaged statement, prove the conversion once).
