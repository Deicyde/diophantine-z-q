# Implementation note: The universal program numbering

- Lean names: `ZInQ.Compiler.Universal.decodeMachine (e : ℕ) : RM.Machine`,
  `Universal.halts (e n : ℕ) : Prop := RM.Halts (decodeMachine e) (Function.update 0 0 n)`,
  `Universal.width`, `Universal.fieldsOf`, `Universal.code (p : RM.Program) : ℕ`.
- Draft:
  ```lean
  def split2 (e : ℕ) : ℕ × ℕ := (padicValNat 2 (e+1), ((e+1) / 2^padicValNat 2 (e+1)) / 2)
  def decodeMachine (e : ℕ) : RM.Machine := fun i =>
    let (w, D) := split2 e
    if w = 0 then .halt else
    let d t := D / 2^(w*t) % 2^w
    match d (4*i) with | 1 => .inc (d (4*i+1)) (d (4*i+2)) | 2 => .dec (d (4*i+1)) (d (4*i+2)) (d (4*i+3)) | _ => .halt
  def code (p : RM.Program) : ℕ := 2^(width p) * (2 * D p + 1) - 1
  ```
  `width p = Nat.find` of the least `w ≥ 2` bounding all fields (or an explicit
  `max 2 (Nat.log 2 (maxField p) + 1)`).
