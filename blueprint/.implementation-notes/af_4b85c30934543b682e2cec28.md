# Implementation note: Degree and coefficient bounds for the specified polynomial

- Lean name: `ZInQ.Size.Pstar_degree_coeff`.
- Draft:
  ```lean
  theorem Pstar_degree_coeff (hCAT : CatalogueBound) :
      Syntax.Pstar.totalDegree ≤ (Syntax.T + 1) ^ 2048 ∧
      ∀ m, (Syntax.Pstar.coeff m).natAbs ≤ 2 ^ (Syntax.T + 1) ^ 2048
  ```
- Proof: `recipe_heights (admissible_T hCAT)` gives `Maj (T+1) 256 PstarNat`; transfer along
  `Pstar = killCompl _ PstarNat`: since `vars PstarNat ⊆ range Fin.val` (witness accounting,
  `vars_PstarNat_lt`), `PstarNat = rename Fin.val Pstar` (`MvPolynomial.mem_supported`,
  `supported_eq_range_rename`, `killCompl_rename_app`, Mathlib/Algebra/MvPolynomial/Rename.lean:143),
  so degrees and coefficients agree (`totalDegree_rename_le` one way, injective rename keeps
  coefficients: `MvPolynomial.coeff_rename_mapDomain`). `natAbs_coeff_le_l1`.
- Mathlib: `MvPolynomial.killCompl`, `killCompl_rename_app`, `coeff_rename_mapDomain`,
  `totalDegree_rename_le`.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: low-medium (~60 lines).

Shared design (majorant notes): `Maj B h P : Prop := if h = 0 then P.totalDegree ≤ 1 ∧ l1 P ≤ 1
else P.totalDegree ≤ B ^ (8 * h) ∧ l1 P ≤ 2 ^ B ^ (8 * h)` (helper def in `ZInQKernel/Size/Majorant.lean`).
Heights are computed on the syntax chapter's node lists (`ZInQ.Syntax.Template.nodes`, produced by
`Prog.dag`), so they depend only on syntax, never on the values of fixed expressions.
