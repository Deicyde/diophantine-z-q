# The formal group of y^2=x^3+Ax (formal-group)

- Lean names: `ZInQ.Mult.FormalNbhd` (the subgroup `W₁(K)`), `ZInQ.Mult.formal_val_x_y`,
  `ZInQ.Mult.formalGroupLaw`, `ZInQ.Mult.z_add`, `ZInQ.Mult.filtration_subgroup`,
  `ZInQ.Mult.val_z_nsmul_ge`.
- Draft (general complete DVF):
  ```lean
  variable {K : Type*} [Field K] [CharZero K] [Valued K ℤᵐ⁰] [CompleteSpace K]
    [IsDiscreteValuationRing (Valued.v.valuationSubring : Subring K)]  -- or use 𝔭.adicCompletion
  def W (A : K) : WeierstrassCurve K := ⟨0, 0, 0, A, 0⟩
  def formalNbhd (A : K) (hA : Valued.v A ≤ 1) : AddSubgroup (W A).toAffine.Point
  theorem val_z_zsmul_ge (P ∈ formalNbhd A hA) (n : ℤ) : vz P ≤ vz (n • P)   -- additive valuation
  ```
  Specialize only to `K = 𝔭.adicCompletion K0`, `A = -d²`; generality is optional.
- Mathlib: `FormalGroup` (Mathlib/RingTheory/FormalGroup/Basic.lean: structure, assoc, comm, `𝔾ₐ`,
  `𝔾ₘ`; no formal group of an elliptic curve, no formal logarithm), `PowerSeries.subst`,
  `MvPowerSeries.subst`, `PowerSeries.HasSubst`, `IsDedekindDomain.HeightOneSpectrum.adicCompletion`,

  GAP: the formal group of an elliptic curve (Silverman IV.1-2, VII.2.2) is not in Mathlib.
- Cheaper alternative, sufficient for this chapter: avoid the formal group law entirely for parts
  1, 3, 4 by direct valuation arguments on the chord-tangent formulas: show that
  `{O} ∪ {v(x) ≤ -2k}` is closed under addition and negation and that `v(z(P+Q)) ≥ min(v z(P), v z(Q))`
  using `z(P+Q)` as an explicit rational function of `z(P), z(Q), w̃(P), w̃(Q)` (Silverman IV.1 proof,
  but with exact field elements instead of series). The formal group law is then only needed for
  the logarithm article.

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
