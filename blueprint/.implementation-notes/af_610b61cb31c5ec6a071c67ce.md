# Implementation note: Twenty-two primes from a twisted sum bound

- Owner: pp-mertens (plan step 4.4). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: `ZInQ.Progressions.twentytwo_primes_of_twisted_bound`.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  open ArithmeticFunction in
  theorem twentytwo_primes_of_twisted_bound {B : ℝ} (hB0 : 0 ≤ B)
      (hB : ∀ χ : DirichletCharacter ℂ q, χ ≠ 1 → ∀ t : ℝ, 1 ≤ t →
        ‖∑ n ∈ Finset.Ioc 0 ⌊t⌋₊, χ n * Λ n / n‖ ≤ B)
      {a : ℕ} (ha : a.Coprime q) {x y : ℝ} (hy : 1 ≤ y) (hyx : y ≤ x)
      (hxy : q * (2 * B + 11) + 12 + Real.log q ≤ Real.log (x / y)) :
      22 ≤ ({p ∈ Finset.Ioc ⌊y⌋₊ ⌊x⌋₊ | p.Prime ∧ p % q = a % q}).card
  ```
- Mathlib: `Real.log_le_sub_one_of_pos` (at `p/e`) for `log p / p ≤ 1/e` (or the cruder `log p / p ≤ 1/2`, which also works: `21/2 + 3 < 14` needs the `11` raised to `14`), `Nat.totient_le`, `Finset.card_le_card`, `Finset.sum_le_card_nsmul`; inputs: orthogonality, the principal character, the prime-power bound.
- For `0 ≤ y ≤ x`, `Finset.Ioc ⌊y⌋₊ ⌊x⌋₊` is exactly the set of integers in `(y, x]` (an integer exceeds `y` iff it exceeds `⌊y⌋`). If `log p/p ≤ 1/2` is used, replace `11` by `14` in the article and in the effective theorem (the margin is ample).
