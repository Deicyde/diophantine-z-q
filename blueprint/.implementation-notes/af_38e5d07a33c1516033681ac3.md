# Implementation note: The catalogue below the progression cutoff

- Lean name: `ZInQ.Size.cataloguePrime_lt`, `ZInQ.Size.Hmax_lt`, `ZInQ.Size.Hcat_le`.
- Draft:
  ```lean
  theorem cataloguePrime_lt (hCAT : CatalogueBound) {r j : ℕ} (hr : r < W) (hr1 : 1 ≤ r)
      (hcop : Nat.Coprime r W) (hj : j < 22) :
      324 < Syntax.cataloguePrime W 324 r j ∧ Syntax.cataloguePrime W 324 r j < 2 ^ W ^ 3
  theorem Hmax_lt (hCAT : CatalogueBound) : Syntax.Hmax < 2 ^ W ^ 3
  theorem Hcat_le (hCAT : CatalogueBound) : 1 ≤ Syntax.Hcat ∧ Syntax.Hcat ≤ (2 ^ W ^ 3) ^ (22 * W)
  ```
  (`j` counted from 0 as in the syntax note's `Nat.nth`.)
- Bridge: `ZInQ.catalogueModulus = 4 * primorial 324 = Syntax.W` (rfl or `simp`), and
  `CatalogueBound`'s filter `p.Prime ∧ p % W = r` on `Finset.Ioo 324 (2^(W^3))` versus the
  catalogue predicate `p.Prime ∧ 324 < p ∧ p % W = r % W`. Show
  `22 ≤ Nat.count pred (2 ^ W ^ 3)` from the hypothesis (`Nat.count_eq_card_filter_range`) and
  conclude with `Nat.nth_lt_of_lt_count` (Mathlib/Data/Nat/Nth.lean:463). `324 < nth` from
  `Nat.nth_mem_of_infinite` (infinitude by Dirichlet, see the prime-catalogue note) or from
  `Nat.nth_mem` with the count bound (no Dirichlet needed: `Nat.nth_mem_of_lt_card`-style
  lemma via the finite count).
- Product bound: `Finset.prod_le_pow_card` (Mathlib/Algebra/Order/BigOperators/Group/Finset.lean:293)
  twice, then card of the unit residues `≤ W` (`Finset.card_filter_le`, `Finset.card_range`).
  Max: `Finset.sup_lt_iff` (Mathlib/Data/Finset/Lattice/Fold.lean:487) with `⊥ = 0 < 2^…`.
- Uses hypothesis CAT (`ZInQ.CatalogueBound`, ZInQKernel/Hypotheses/PrimePattern.lean).
- Finite computation: no. `W^3` and `2^(W^3)` are never evaluated (keep `W` folded after the
  bridge; `decide` must not see `2 ^ W ^ 3`).
- Upstream reuse: none.
- Difficulty: low-medium (~80 lines, mostly the `Nat.nth`/`Nat.count` bridge).
