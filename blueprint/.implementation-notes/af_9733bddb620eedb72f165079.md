# Implementation note: Tails of the twisted harmonic sums

- Owner: pp-lseries (plan step 1). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: `ZInQ.Progressions.norm_tail_le`; the two halves are pushed as `norm_sum_Ioc_char_div_cpow_le_two_mul` and `norm_sum_Ioc_char_log_div_cpow_le_two_mul` (`LSeries/Tail.lean`), so `norm_tail_le` may simply be their conjunction or an alias of the first.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  theorem norm_tail_le {χ : DirichletCharacter ℂ q} (hχ : χ ≠ 1) {σ : ℝ} (hσ : 1 ≤ σ)
      {N : ℕ} (hN : 1 ≤ N) (K : ℕ) :
      ‖∑ n ∈ Finset.Ioc N K, χ n / (n : ℂ) ^ (σ : ℂ)‖ ≤ 2 * q / N ∧
        (3 ≤ N → ‖∑ n ∈ Finset.Ioc N K, χ n * (Real.log n : ℂ) / (n : ℂ) ^ (σ : ℂ)‖ ≤
          2 * q * Real.log N / N)
  ```
- Mathlib: summation by parts is proved by hand upstream (`norm_sum_mul_antitone_le`); `Real.log_div_self_antitoneOn`, `Real.rpow_le_rpow_of_exponent_le`. Mathlib's `NumberTheory/AbelSummation.lean` is an alternative but the discrete form is simpler.
