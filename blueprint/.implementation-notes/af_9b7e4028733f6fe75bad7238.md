# Implementation note: The capped precision test

- Lean names: `ZInQ.Compiler.Precision.NExpr` (expressions: `lit`, `add`, `mul`, `max`,
  `pow`, `fact`), `NExpr.eval : NExpr → ℕ`, `NExpr.capped (L : ℕ) : NExpr → ℕ`,
  `cappedFact`, `eA : NExpr` (with `eA.eval = A0` by `rfl` after unfolding, never by
  evaluation), `cappedBound (L M : ℕ) : ℕ`, `divFourLoop (L β : ℕ) : ℕ`; theorems
  `NExpr.capped_eq`, `cappedBound_eq`, `divFourLoop_eq`, `precision_test_iff`.
- Draft:
  ```lean
  def cappedFact (L : ℕ) : ℕ → ℕ | 0 => 1 | n+1 => cappedMul L (cappedFact L n) (saturate L (n+1))
  theorem NExpr.capped_eq (L : ℕ) (hL : 1 ≤ L) (e : NExpr) : e.capped L = saturate L e.eval
  theorem divFourLoop_eq (L β : ℕ) : divFourLoop L β = L / 4 ^ β
  theorem precision_test_iff (L M : ℕ) (hL : 1 ≤ L) :
      1 ≤ divFourLoop L (cappedBound L M) ↔ 4 ^ (A0 * M ^ 24) ≤ L
  ```
- Proof: `capped_eq` by induction on `e` with `saturate_add`, `saturate_max`,
  `cappedMul_eq_saturate` + `saturate_mul`, `cappedPower_eq_saturate` +
  `saturate_pow_saturate` (needs `1 ≤ L`), and for `fact` an induction giving
  `cappedFact L n = saturate L n.factorial` plus `cappedFact L (saturate L n) = saturate L n.factorial`
  (`Nat.self_le_factorial`). `eA.eval = A0` must be proved by unfolding definitions
  symbolically (`simp only [NExpr.eval, A0, Q0, ...]`), never by `decide`/`norm_num`.
  `divFourLoop_eq` by induction on `β` with `Nat.div_div_eq_div_mul`; the case split
  `A0 * M^24 ≤ L` uses `Nat.lt_pow_self`.
- Mathlib: `Nat.div_div_eq_div_mul`, `Nat.one_le_div_iff`, `Nat.lt_pow_self`,
  `Nat.self_le_factorial`, `Nat.factorial_succ`.
- Upstream reuse: `PrecisionArithmetic` (`saturate_*`), `PrecisionAlgorithms`
  (`cappedMul_eq_saturate`, `cappedPower_eq_saturate`).
