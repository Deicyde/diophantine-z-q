# Implementation note: The wrapper program

- Lean names: `ZInQ.Compiler.IR.unpairProgram` (prefix program in the ideal language),
  `ZInQ.Compiler.Universal.relocate (d : ℕ) : RM.Program → List RM.Instr`,
  `ZInQ.Compiler.Universal.wrapper : RM.Program`.
- Draft:
  ```lean
  def wrapper : RM.Program :=
    let pre := (IR.code unpairProgram.body 0 (precisionRegs + 1)).1   -- open code, scratch ≥ r_prec
    pre ++ relocate pre.length precisionMachine
  ```
  The prefix uses the same lowering blocks, so its correctness is the open-code item of
  the lowering statement.
- Mathlib: `List.map`.
- Upstream reuse: `CantorDecoder.loop` is the functional target of the prefix loop.
- FINITE COMPUTATION: no. Difficulty: easy.
