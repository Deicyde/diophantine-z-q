# Implementation note: A lower bound for |L(1,χ)| at complex characters

- Owner: pp-lseries (plan step 2). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: `ZInQ.Progressions.norm_LFunction_one_ge_of_sq_ne_one`.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  theorem norm_LFunction_one_ge_of_sq_ne_one {χ : DirichletCharacter ℂ q} (hχ : χ ^ 2 ≠ 1) :
      1 / (256 * (Real.log q + 3) ^ 7) ≤ ‖χ.LFunction 1‖
  ```
- Mathlib: `DirichletCharacter.norm_LSeries_product_ge_one` at `y = 0` (its `L` is the `LSeries`; convert with `LFunction_eq_LSeries` at real part `1 + x > 1`), `norm_mul`, `norm_pow`; `χ ≠ 1` follows from `χ ^ 2 ≠ 1`.
- Constant check: with `x = 1/(256 M^9)`, `(2/x)^3 (2 x M^2)^4 M = 128 x M^9 = 1/2 < 1`.
