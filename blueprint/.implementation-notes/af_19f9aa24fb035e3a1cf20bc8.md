# Implementation note: The five-input natural precision circuit

- Lean name: `ZInQ.Compiler.Universal.precisionCircuit : Syntax.NatCircuit`.
- Draft:
  ```lean
  def specialize (H : Syntax.NatCircuit) (code : ℤ) : Syntax.NatCircuit :=
    { inputCount := 5
      explicitVars := (List.range 9).map (fun i => (i, i < 5)) ++
        (H.explicitVars.drop 2).map (fun (i, k) => (i + 7, k))
      nodes := H.nodes.map (renameNode code) ++ pairingNodes
      root := H.nodes.length + 51
      blocks := H.blocks.map (· + 7) }
  def precisionCircuit := specialize haltingCircuit c3
  ```
  `renameNode` maps `var 0 ↦ const code`, `var 1 ↦ var 5`, `var i ↦ var (i+7)` and shifts
  call block starts by `7`; `pairingNodes` is the literal list of the 52 appended nodes in
  the saved order (vars 0-4, 6, 7, 8; consts 1, 2, -1; four 8-node pairing equations;
  9-node final sum of squares).
- Mathlib: `List.map`, `List.range`.
- Upstream reuse: none.
