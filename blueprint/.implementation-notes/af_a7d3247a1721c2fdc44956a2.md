- Owner: not yet assigned (plan step 3.4, after 3.1–3.3); natural continuation of pp-idealcount. Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.dedekindZeta_quadField_eq`.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  theorem dedekindZeta_quadField_eq {χ : DirichletCharacter ℂ q} {d : ℤ}
      [Fact (¬ IsSquare (d : ℚ))]
      (hdiv : ∀ p : ℕ, p.Prime → (p : ℤ) ∣ d → p ∣ 2 * q)
      (hχ : ∀ p : ℕ, p.Prime → ¬ p ∣ 2 * q → χ p = (jacobiSym d p : ℂ)) {s : ℝ} (hs : 1 < s) :
      NumberField.dedekindZeta (QuadField d) s =
        riemannZeta s * χ.LFunction s *
          ∏ p ∈ (2 * q).primeFactors,
            (1 - χ p * (p : ℂ) ^ (-(s : ℂ))) /
              (1 - ((idealCount (QuadField d) p : ℤ) - 1 : ℂ) * (p : ℂ) ^ (-(s : ℂ)))
  ```
- Mathlib: `EulerProduct.eulerProduct_hasProd` / `eulerProduct_tprod` (multiplicative coefficients), `DirichletCharacter.LSeries_eulerProduct_hasProd`, `riemannZeta_eulerProduct_hasProd` (or `zeta` as the trivial character's L-series), `DirichletCharacter.LFunction_eq_LSeries`, `HasProd.mul`, `tprod` over `Nat.Primes` split along the finite set `(2q).primeFactors`.
- The squarefree hypothesis on `d` is not needed once the field exists; `hdiv` gives `p ∤ 2q → p ∤ d`.
