# Implementation note: Size of the guard polynomial

- Lean name: `ZInQ.Size.guardPoly_size`.
- Draft:
  ```lean
  theorem guardPoly_size (T : ℕ) :
      (Syntax.guardPoly T).totalDegree ≤ 16 * (T + 1) ^ 3 ∧
      l1 (Syntax.guardPoly T) ≤ 2 ^ (2 ^ 39 * (T + 1) ^ 6)
  ```
- Proof: unfold `guardPoly` (a `Finset.prod` over the filtered box); card of the box
  `((2T+1)^3)` via `Finset.card_product`, `Int.card_Icc`; per-factor bounds from
  `iota_coord_height`, `l1_add_le`, `l1_pow_le`, `l1_C`, `l1_X`; product by `l1_prod_le` and
  `Finset.prod_le_pow_card`; degree by `totalDegree_finsetProd`. Exponent arithmetic
  (`8 (T+1)^3 (30 K + 6) ≤ 2^39 (T+1)^6`) by `nlinarith`.
- Mathlib: `Finset.card_product`, `Int.card_Icc`, `Finset.prod_le_pow_card`,
  `MvPolynomial.totalDegree_finsetProd`, `Finset.card_filter_le`.
- Finite computation: no (never expanded; `guardPoly T` for the actual `T` has about `8 T^3`
  factors).
- Upstream reuse: none.
- Difficulty: medium (~120 lines).

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
