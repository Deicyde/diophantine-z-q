# Implementation note: The precision quantities and the precision predicate

- Lean names: `ZInQ.Assembly.zCoord`, `wCoord`, `zIdx`, `epsWin`, `rWin`, `contactPoly`, `A0`,
  `Bnk`, `enc`, `dec`, `Prec`, `sigmaPlus`, `sigmaMinus`.
- Draft:
  ```lean
  noncomputable def zCoord : genCurve.toAffine.Point → K0
    | .zero => 0
    | .some x y _ => if x ≠ 0 ∧ y ≠ 0 then -x / y else 0
  noncomputable def wCoord : genCurve.toAffine.Point → K0
    | .zero => 0
    | .some x y _ => if x ≠ 0 ∧ y ≠ 0 then x⁻¹ else 0
  noncomputable def zIdx (m : ℤ) : K0 := zCoord (m • genP0)
  noncomputable def epsWin (l : ℤ) : ℚ := |(zIdx l).re| + |(zIdx l).im|
  noncomputable def rWin (a j : ℤ) : ℚ := (zIdx j / zIdx a).re      -- = ½ Tr
  def contactPoly (u : ℚ) : ℚ := u * (u + 15) * (u + 20) * (u + 24) * (u + 30) * (u + 60)
  @[irreducible] noncomputable def A0 : ℕ := ZInQ.HeightConstantAlgorithm.heightConstant
  @[irreducible] noncomputable def Bnk (n κ : ℤ) : ℕ := A0 * (κ * contactPolyZ n).natAbs ^ 24
  def enc (m : ℤ) : ℕ := if 0 ≤ m then 2 * m.toNat else 2 * (-m).toNat - 1
  def dec (c : ℕ) : ℤ := if c % 2 = 0 then c / 2 else -((c + 1) / 2 : ℕ)
  def Prec (n κ a l j : ℤ) : Prop :=
    (n : ℚ) ∉ ZInQ.contactSet ∧ κ ≠ 0 ∧ 1 ≤ a ∧ 1 ≤ l ∧ j = n * a ∧
      |rWin a j - n| < epsWin l ∧ 4 * epsWin l * 4 ^ Bnk n κ < 1
  ```

  with `u = ±√2`.
- Upstream reuse: `ZInQ.HeightConstantAlgorithm.heightConstant` (lean/ZInQ/HeightConstantAlgorithm.lean)

  (Hypotheses/Height.lean uses real `rpow`; use `Real.rpow_natCast`, `Nat.cast_max`).
- The compiler chapter's natural-polynomial semantics must be stated for exactly this `Prec`

- FINITE COMPUTATION: no; `A0`, `Bnk` are never evaluated. Difficulty: easy (definitions + the

Shared conventions (assembly notes): namespace `ZInQ.Assembly`, files under
`ZInQKernel/Assembly/`. `RelT τ a` abbreviates `ZInQ.Syntax.Rel τ.poly τ.parameterCount
τ.witnessCount a` (syntax note for template semantics); codes are `ZInQ.iota : ℤ → Fin 5 → ℚ`
and `ZInQ.pointCode` (point-codes note); `genP0 : genCurve.toAffine.Point`. The hypothesis
quadruple `(hH : SixContactEstimate) (hPC : PoleCompleteness) (hMW : MordellWeilE)
(h22 : FixedPrimePattern)` is written `hyps`. The constants `A0`, `Bnk n κ`, `heightD` and
every power `4 ^ Bnk n κ` must stay symbolic: mark them `@[irreducible]`/`noncomputable` and
never use `decide`, `norm_num` evaluation or `#eval` on them.
