# Implementation note: Semantics of the rational translation

- Lean name: `ZInQ.Translation.precision_rel_iff` (and `powerValue_rel_iff` for item 2).
- Draft:
  ```lean
  theorem precision_rel_iff (hMW : MordellWeilE) (hM : MultiplicationExact)
      (E : Fin 5 → Fin 5 → ℚ) :
      Syntax.Rel precisionRecipe.denote 25 292889492836 (fun k => E (k / 5) (k % 5)) ↔
        ∃ c : Fin 5 → ℕ, (∀ i, E i = iota (c i)) ∧
          ∃ z : Fin 1305806 → ℕ, MvPolynomial.eval (Fin.append (fun i => (c i : ℤ)) (fun i => (z i : ℤ)) ∘ finCast)
            naturalPrecisionPoly = 0
  ```
  (state the polynomial evaluation through `NatCircuit.value` if that is how the natural chapter
  states (C.4); the two forms are equal by `value_eq_eval_poly`).
- Proof: `translate_rel_iff_zero` with `precisionCircuit_wellFormed` and
  `powerValue_rel_iff`; the `θ ↔ (c, z)` correspondence uses the bound 1305811.
- Mathlib: `Fin.append`, `MvPolynomial.eval`.
- Upstream reuse: none.
- FINITE COMPUTATION: no (it uses the scope check).
- Difficulty: low (~80 lines) given the generic theorem.
- Interface for the assembly chapter: also export `precision_rel_iff_accepts` (the corollary
  article) so that the assembly never touches `C`.

Shared design (translation notes): namespace `ZInQ.Translation`, files under
`ZInQKernel/Compiler/Translation/`. Reuse the syntax chapter's `ZInQ.Syntax.NatCircuit`,
`ZInQ.Syntax.translate`, `ZInQ.Syntax.Rel`, `ZInQ.Syntax.pointRef` and the model chapter's
`ZInQ.iota`. The multiplication statement is taken as a hypothesis
`hM : ZInQ.MultiplicationExact`, where
`def MultiplicationExact : Prop := ∀ p q r : Fin 5 → ℚ, Syntax.Rel multiplyPoly 15 35134 (p ++ q ++ r) ↔ ∃ a b : ℤ, p = iota a ∧ q = iota b ∧ r = iota (a * b)`
(to be shared with the multiplication chapter; if that chapter instead proves the statement
from H, PC, MW, 22P, CAT, the assembly instantiates `hM` with that theorem). `iota` is never
evaluated; constants `c_3`, `A_ht` stay symbolic.
