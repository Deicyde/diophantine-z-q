# The x-height (x-height)

- Lean names: `ZInQ.hK0 (x : K0) : ℝ := Height.logHeight₁ x / 2`, `ZInQ.hx (T : curveC.toAffine.Point) : ℝ
  := T.naiveHeight / 2`.
- Requires `instance : NumberField K0` so that `Height.AdmissibleAbsValues K0` comes from
  `NumberField.instAdmissibleAbsValues` (`Mathlib/NumberTheory/Height/NumberField.lean`); there
  `logHeight₁` is the relative height (sum over places with multiplicities), hence the `/ 2`
  (`totalWeight_eq_finrank`). `Point.naiveHeight_eq_logHeight₁` gives `naiveHeight (some x y _) =
  logHeight₁ x` and `naiveHeight 0 = 0`. Mathlib's `NumberField.absLogHeight₁` exists but goes
  through `ℚ⟮x⟯`; avoid it.
- FINITE COMPUTATION: no. Difficulty: easy.
