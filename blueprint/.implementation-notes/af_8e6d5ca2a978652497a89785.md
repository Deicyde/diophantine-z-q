# Implementation note: Templates satisfy the height majorant

- Lean name: `ZInQ.Size.template_maj`.
- Draft:
  ```lean
  structure Admissible (B : ℕ) (L : List Syntax.Template) : Prop where
    two_pow : 2 ^ 20 ≤ B
    const : ∀ τ ∈ L, ∀ c, Syntax.Node.const c ∈ τ.nodes → c.natAbs + 1 ≤ B
    fixed : ∀ τ ∈ L, ∀ e, Syntax.Node.fixed e ∈ τ.nodes → (e.val).natAbs + 1 ≤ B
    psi : ∀ τ ∈ L, ∀ e a c, Syntax.Node.psi e a c ∈ τ.nodes → (e.val).natAbs + 1 ≤ B
    guard : ∀ τ ∈ L, ∀ e a, Syntax.Node.guard e a ∈ τ.nodes → 0 ≤ e.val ∧ e.val + 1 ≤ B
  theorem template_maj {B : ℕ} {L : List Syntax.Template} (hL : Syntax.WellOrdered L) (hB : Admissible B L)
      (i : ℕ) (hi : i < L.length) :
      Maj B ((libraryHeights L).getD i 0) ((Syntax.libraryPolys L).getD i 0)
  ```
  (`Syntax.libraryPolys` is the syntax chapter's fold computing `[[τ]]` in library order;
  `WellOrdered`: every call refers to an earlier template and every node only to earlier nodes,
  which the syntax chapter's builder guarantees.)
- Proof: double induction mirroring the two folds (`List.foldl` induction with an invariant
  relating the height list and the polynomial list pointwise), using the closure rules and the
  uniform constructor bounds; the `val` of fixed expressions appears only in `Admissible`.
- Mathlib: `List.foldl` induction (`List.foldl_append`, `List.getD_append`).
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: medium (~200 lines; the fold invariant is the main work).

Shared design (majorant notes): `Maj B h P : Prop := if h = 0 then P.totalDegree ≤ 1 ∧ l1 P ≤ 1
else P.totalDegree ≤ B ^ (8 * h) ∧ l1 P ≤ 2 ^ B ^ (8 * h)` (helper def in `ZInQKernel/Size/Majorant.lean`).
Heights are computed on the syntax chapter's node lists (`ZInQ.Syntax.Template.nodes`, produced by
`Prog.dag`), so they depend only on syntax, never on the values of fixed expressions.
