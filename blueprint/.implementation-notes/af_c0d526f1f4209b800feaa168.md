# Implementation note: Valuations of the quadratic field

- Lean names: `ZInQ.Assembly.valPi (π : Zs) : K0 → WithTop ℤ`, lemmas `valPi_rat`, `valPi_star`,
  `valPi_p_odd`, `val_trace_ge`.
- Two options: (a) Mathlib's `IsDedekindDomain.HeightOneSpectrum.valuation`
  (Mathlib/RingTheory/DedekindDomain/AdicValuation.lean:322) for `Zs` with `K0` as fraction field
  (needs `IsFractionRing Zs K0`); (b) a concrete `multiplicity`-based definition on the
  Euclidean domain `ZInQ.Zs` (model chapter: `Zs_euclideanDomain`), extended to `K0` by clearing
  a natural denominator. (b) matches the model chapter's `ZInQ.val_s_formula`; coordinate with
  the model-field worktree.
- Mathlib: `padicValRat`, `multiplicity`, `emultiplicity`, `Int.emultiplicity_natAbs`.
- Gap: no ready-made decomposition of rational primes in `ℤ[√2]` in Mathlib; (1) needs the
  quadratic-residue split/inert dichotomy (`ZMod.exists_sq_eq_two_iff` exists for the residue
  symbol).
- FINITE COMPUTATION: no. Difficulty: medium (~300 lines; shared infrastructure with the model chapter).

`ZInQKernel/Assembly/`. `RelT τ a` abbreviates `ZInQ.Syntax.Rel τ.poly τ.parameterCount
τ.witnessCount a` (syntax note for template semantics); codes are `ZInQ.iota : ℤ → Fin 5 → ℚ`
and `ZInQ.pointCode` (point-codes note); `genP0 : genCurve.toAffine.Point`. The hypothesis
quadruple `(hH : SixContactEstimate) (hPC : PoleCompleteness) (hMW : MordellWeilE)
(h22 : FixedPrimePattern)` is written `hyps`. The constants `A0`, `Bnk n κ`, `heightD` and
every power `4 ^ Bnk n κ` must stay symbolic: mark them `@[irreducible]`/`noncomputable` and
never use `decide`, `norm_num` evaluation or `#eval` on them.
