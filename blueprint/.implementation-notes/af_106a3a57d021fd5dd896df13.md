# Implementation note: Node statistics of the halting circuit and the power template

- Lean names: `ZInQ.Compiler.Universal.haltingCircuit_nodeStats`,
  `ZInQ.Compiler.Formula.powerTemplate_nodeStats` (share the latter with the syntax chapter's
  power-template shape lemma).
- FINITE COMPUTATION. Decidable form:
  ```lean
  theorem haltingCircuit_nodeStats :
      haltingCircuit.nodes.length = 293568 ∧ countKind .var haltingCircuit = 54049 ∧
      countKind .add haltingCircuit = 125307 ∧ countKind .mul haltingCircuit = 98361 ∧
      countKind .call haltingCircuit = 15845 ∧ constList haltingCircuit = [0, 1, 2, 4, 1399, -1] ∧
      haltingCircuit.nodes[0]? = some (.var 0) ∧ haltingCircuit.nodes[1]? = some (.var 1)
  theorem powerTemplate_nodeStats :
      powerTemplate.nodes.length = 474 ∧ countKind .var powerTemplate = 82 ∧
      countKind .add powerTemplate = 196 ∧ countKind .mul powerTemplate = 190 ∧
      countKind .call powerTemplate = 0 ∧ constList powerTemplate = [0, 1, 4, 2, 3, -1] := by decide
  ```
- Size: 293,568 nodes built by the hash-consing interpreter from the 1,399-instruction
  program; 474 nodes for the power template (cheap by `decide`).
- Method for the halting circuit: running the hash-consing builder in the kernel is likely
  too slow for `decide` (a map lookup per node). Routes: (a) milestone 1 of KERNEL_PLAN.md:
  `native_decide` in the separate unaudited library, cross-checked externally (the JS
  compiler with the hierarchical override reproduces the saved 293,568 nodes from the
  recovered program, as verified by the chapter writer); (b) milestone 2 (kernel): a
  `Nat`-keyed trie for the `dag` interpreter and a Boolean checker proved by `Eq.refl true`;
  (c) symbolic: prove the node counts of the packed construction as a function of the
  program (sharing analysis of the constant subterms such as `K*F`, `Q+4`, `Q^2` at `Q = 2`),
  then evaluate on the shape. These counts are consumed by the variable budget of the
  recipe translation (each addition node costs 6 witnesses, each multiplication node 35,134),
  so they must be exact.
- Mathlib: `List.countP`.
- Upstream reuse: none.
- Difficulty: low with `native_decide`; high for the kernel routes.
