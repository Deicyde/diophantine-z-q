# Implementation note: Compactness and continuity of subtraction on a real curve

- Lean names: `ZInQ.Assembly.RealCurve.TendstoPt`, `RealCurve.exists_subseq_tendstoPt`,
  `RealCurve.tendstoPt_sub_zero`.
- Draft:
  ```lean
  abbrev realCurve (e : ℝ) : WeierstrassCurve ℝ := ⟨0, 0, 0, -e ^ 2, 0⟩
  def TendstoPt {e : ℝ} (P : ℕ → (realCurve e).toAffine.Point) :
      (realCurve e).toAffine.Point → Prop
    | .zero => ∀ M : ℝ, ∀ᶠ m in Filter.atTop, P m = 0 ∨ ∃ x y h, P m = .some x y h ∧ M < x
    | .some x₀ y₀ _ => ∀ᶠ m in Filter.atTop, ∃ x y h, P m = .some x y h ∧ … (x,y) → (x₀,y₀)
  theorem exists_subseq_tendstoPt (he : e ≠ 0) (P : ℕ → _) :
      ∃ φ : ℕ → ℕ, StrictMono φ ∧ ∃ Q, TendstoPt (P ∘ φ) Q
  theorem tendstoPt_sub_zero (he : e ≠ 0) {P P' Q} (h : TendstoPt P Q) (h' : TendstoPt P' Q) :
      TendstoPt (fun m => P' m - P m) 0
  ```
