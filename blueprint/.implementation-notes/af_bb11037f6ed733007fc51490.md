# Implementation note: Size of the wrapper

- Lean name: `ZInQ.Compiler.Universal.wrapper_small`.
- FINITE COMPUTATION. Decidable form:
  ```lean
  theorem wrapper_small : 3 ≤ wrapper.length ∧ wrapper.length ≤ 200000 ∧
      ∀ ins ∈ wrapper, ins.maxField < 2^18
  ```
  (`maxField` = maximum of the register index and the targets; opcodes are 0, 1, 2).
- Size: about 1.5·10^5 instructions if the Lean precision program is as large as the
  manuscript's (146,780 instructions, maximum index 146,779, 23,633 registers).
- Method: evaluating `IR.lower` on the whole precision program in the kernel is too slow for
  `decide`. Prove structural bounds instead: `(IR.code s start aux).1.length = IR.size s`
  and `maxField ≤ max (start + IR.size s) (IR.maxReg s aux)` with `IR.size`, `IR.maxReg`
  small recursive functions on the IR syntax, then evaluate those on the IR term (a few
  hundred statements) by `decide`; add the prefix and cleanup lengths. Milestone 1 may use
  `native_decide` on `wrapper_small` directly.
- Requirement on the precision program: these bounds are a design constraint. If the IR
  program of this formalization is larger than about 200,000 lowered instructions or
  uses registers beyond 2^18, raise the bound here and re-check the consumer bound
  `c3 < 2^(2^24)` (it needs `18*(4*m+1)+1 ≤ 2^24`, that is `m ≤ 233,016` at width 18).
- Mathlib: `List.length_append`, `List.all`.
- Upstream reuse: none.
- Difficulty: medium (the structural size functions).
