# Point codes (point-codes)

- Lean names: `ZInQ.pointCode : genCurve.toAffine.Point → Fin 5 → ℚ`, `ZInQ.iota (n : ℤ) : Fin 5 → ℚ`.
- Draft:
  ```lean
  def pointCode : genCurve.toAffine.Point → Fin 5 → ℚ
    | .zero => ![1, 0, 0, 0, 0]
    | .some x y _ => ![0, x.re, x.im, y.re, y.im]
  noncomputable def iota (n : ℤ) : Fin 5 → ℚ := pointCode (n • genP0)
  ```
- `iota n` must never be evaluated for large `n` (the guard and constants use indices up to
  astronomically large fixed integers); all reasoning is through group-law lemmas. Mathlib's
  `zsmul` on `Point` is `zsmulRec nsmulBinRec`, so `#eval` would even be possible for small n,
  but nothing may depend on that. Marking `iota` `noncomputable` or `@[irreducible]` is advised.
- Other chapters already link this article as "The codes of multiples of the generator".
- FINITE COMPUTATION: no. Difficulty: easy.
