# Implementation note: Size of the division polynomials

- Lean names: `ZInQ.Size.normDiv_size`, `ZInQ.Size.psiComponent_size`.
- Draft:
  ```lean
  -- F n := Syntax.normDiv A n evaluated at x = ⟨X 0, X 1⟩, A = ⟨-11243, 7950⟩ in
  -- QuadraticAlgebra (MvPolynomial (Fin 4) ℤ) 2 0
  theorem normDiv_size (n : ℕ) : pairDeg (F n) ≤ (n + 1) ^ 3 ∧ pairNorm (F n) ≤ 2 ^ (100 * (n + 1) ^ 3)
  theorem psiComponent_size (n : ℤ) (c : Fin 2) :
      (Syntax.psiComponent n c).totalDegree ≤ 2 * (n.natAbs + 1) ^ 3 ∧
      l1 (Syntax.psiComponent n c) ≤ 2 ^ (101 * (n.natAbs + 1) ^ 3)
  ```
- Proof: strong induction (`Nat.strong_induction_on`) following the recursion equations of
  `Syntax.normDiv` (use its equation lemmas, never `decide`/`rfl` at a concrete large index).
  Base cases: closed literal comparisons (`3*3^4 + 6*27143*9 + 27143^2 < 2^30`,
  `2*(3^6 + 5*27143*81 + 5*27143^2*9 + 27143^3) < 2^46`, `16*81456^2 < 2^38`) by `decide`, from
  `pairNorm x = 3`, `pairNorm A = 27143` and the pair estimates. Cubic exponent inequalities
  (`4m^3 - 24m - 27 ≥ 9` for `m ≥ 3`, `4m^3+6m^2-12m-22 ≥ 10` for `m ≥ 2`) by `nlinarith` after
  stating them additively (`(m+1)^3+(m+3)^3+2*m^3 + 9 ≤ (2m+1)^3`).
  If the syntax chapter defines `normDiv` directly on quadratic-algebra elements (its note's
  alternative), the induction is the same with `F n := normDiv x n`.
- Mathlib: `Nat.strong_induction_on`, `nlinarith`, `pow_le_pow_right₀`.
- Finite computation: only the three closed base-case comparisons.
- Upstream reuse: none (construction/elliptic-division-polynomials.js only as a reference for the
  recursion).
- Difficulty: medium (~200 lines; the base cases need explicit expansions of `f₃`, `f₄`).

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
