# Implementation note: Arithmetic blocks of the interpreter

- Lean names: reuse the lowering blocks of `IR.lower` where they coincide (`clearBlock`,
  `copyBlock`, `addBlock`, `divModBlock`); interpreter-specific: `testBlock`, `ifLtBlock`,
  `divmod2Block`, each with a spec `RM.BlockSpec` lemma.
- Exact reproduction: the recovered interpreter shows the block shapes, for example copy
  $x\leftarrow y$ with scratch $t$: `dec x → loop; dec t → loop; dec y (nz: inc x; inc t;
  jump) (z: next); dec t (nz: inc y; jump) (z: next)`, jumps being `dec 2 x x`. The Lean
  blocks must reproduce these instruction sequences exactly for the interpreter literal to
  match (states 0-19 of the recovered program are two clears and a copy).
- Mathlib: none.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: medium.
