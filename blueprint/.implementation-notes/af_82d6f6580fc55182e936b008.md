# The free index of R is odd (odd-free-index)

- Lean name: `ZInQ.odd_free_index (S T m) (hR : pointR = m • S + T) (hT : T ∈ twoTorsionC) : Odd m`.
- Proof: apply `kummerHom` for `curveC`; define `signVec : SqClass K0 → Bool × Bool` (well defined
  since squares are totally positive) and compare.
- Mathlib: `QuotientGroup.lift`, `Real.sqrt` lemmas for `embPlus/embMinus` signs.
- FINITE COMPUTATION: sign facts 3 - √2 > 0, 1 - √2 < 0 (`Real.sqrt_lt'`, `norm_num`).
- Difficulty: easy-medium.
