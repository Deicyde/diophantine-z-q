# Implementation note: The ideal counting function

- Owner: pp-idealcount (plan step 3.3), `ZInQKernel/Progressions/IdealCount/`. Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.idealCount`.
- Draft:
  ```lean
  /-- The number of ideals of `𝓞 K` of absolute norm `n`, the coefficient of `dedekindZeta`. -/
  noncomputable def idealCount (K : Type*) [Field K] [NumberField K] (n : ℕ) : ℕ :=
    Nat.card {I : Ideal (𝓞 K) // Ideal.absNorm I = n}

  theorem dedekindZeta_eq_LSeries_idealCount (K : Type*) [Field K] [NumberField K] (s : ℂ) :
      NumberField.dedekindZeta K s = LSeries (fun n ↦ (idealCount K n : ℂ)) s := rfl
  ```
- Mathlib: `NumberField.dedekindZeta` (defined with exactly this coefficient), `Ideal.finite_setOfPred_absNorm_eq`, `Ideal.absNorm`.
- At `n = 0` the count is `1` (the zero ideal); `LSeries` ignores the term `n = 0`, but multiplicativity statements must exclude it.
