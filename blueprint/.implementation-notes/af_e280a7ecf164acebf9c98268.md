# Implementation note: Higher prime powers contribute little

- Owner: pp-mertens (plan step 4.4). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.sum_vonMangoldt_div_not_prime_le`.
- Draft:
  ```lean
  open ArithmeticFunction in
  theorem sum_vonMangoldt_div_not_prime_le (x : ℝ) :
      ∑ n ∈ Finset.Ioc 0 ⌊x⌋₊ with ¬ n.Prime, Λ n / n ≤ 3
  ```
- Mathlib: `ArithmeticFunction.vonMangoldt_apply`, `Nat.Primes`/`IsPrimePow` with `Nat.Prime.eq_one_of_self_dvd`-style injectivity of `(p, k) ↦ p^k`, `Real.log_le_rpow_div` or `Real.add_one_le_exp`-based `log m ≤ √m`, `Finset.sum_range_sub` (telescoping `2/√(m-1) - 2/√m`), `Real.sqrt_le_sqrt`.
- Any finite form suffices: the count uses it for sums over `y < n ≤ x`. The plan's `O(log y/√y)` is replaced by this absolute constant because each prime already contributes at most `1/e`.
