# Implementation note: The regulator of an imaginary quadratic field

- Owner: pp-quadfield (plan step 3.2). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.regulator_quadField_of_neg`.
- Draft:
  ```lean
  theorem regulator_quadField_of_neg {d : ℤ} [Fact (¬ IsSquare (d : ℚ))] (hd : d < 0) :
      NumberField.Units.regulator (QuadField d) = 1
  ```
- Mathlib: `NumberField.Units.rank` (`= card (InfinitePlace K) - 1`), `NumberField.Units.regulator_eq_det` with `Fin 0` (determinant of the empty matrix, `Matrix.det_isEmpty`).
- A general lemma `regulator_eq_one_of_rank_eq_zero` may be cleaner. The class number formula fixes this convention (for `ℚ` the residue is `1`).
