# Implementation note: Reduction on the nonsingular part

- Lean name: `ZInQ.Size.reductionHom`, `ZInQ.Size.ker_reductionHom`,
  `ZInQ.Size.E0_eq_top_of_good`.
- Draft:
  ```lean
  variable (𝔭 : Ideal Zs) [𝔭.IsMaximal] (h2 : (2 : Zs) ∉ 𝔭) (A : Zs)
  def E0sub : AddSubgroup (shortCurve (A : K₀)).toAffine.Point
  def reductionHom : E0sub 𝔭 A →+ (shortCurve (residue 𝔭 A)).toAffine.Point
  theorem ker_reductionHom : (reductionHom 𝔭 A).ker = E1sub 𝔭 A   -- {O} ∪ {v(x) < 0}
  theorem E0_eq_top_of_good (hA : residue 𝔭 A ≠ 0) : E0sub 𝔭 A = ⊤
  ```
  Target group: Mathlib's `WeierstrassCurve.Affine.Point` over the residue field `Zs ⧸ 𝔭`; its
  `AddCommGroup` instance (Mathlib/AlgebraicGeometry/EllipticCurve/Affine/Point.lean:805) holds for
  any Weierstrass curve over a field and consists exactly of the nonsingular points, so it is
  `W̃_ns(k)` including the cuspidal case at `(d)`.
- Mathlib gap: Mathlib v4.35.0 has `WeierstrassCurve.reduction`, `IsIntegral`, `IsMinimal`,
  `HasGoodReduction` (Mathlib/AlgebraicGeometry/EllipticCurve/Reduction.lean) at curve level only;
  there is no reduction map on points and no homomorphism theorem. This article is a genuine
  background gap (Silverman VII.2.1). The model chapter's `ZInQ.reductionHom` (note of
  reduction-torsion, split primes of good reduction into `ZMod p`) is the special case; formalize
  this general version once and derive the model chapter's from it.
- Proof route: explicit addition formulas in affine coordinates
  (`WeierstrassCurve.Affine.slope`, `addX`, `addY`, Mathlib/AlgebraicGeometry/EllipticCurve/Affine/Formula.lean):
  for integral points with nonsingular reductions show the slope is integral or both sides
  reduce to `O`, case split on `x₁ ≡ x₂`; alternatively prove it in Jacobian coordinates
  (`Mathlib/AlgebraicGeometry/EllipticCurve/Jacobian/*`), where addition is polynomial and
  reduction of coordinates commutes with the formulas when the result is nonsingular. Expect
  several hundred lines either way.
- Finite computation: no.
- Difficulty: hard (classical, but long). Candidate for splitting into (a) subgroup and
  well-definedness, (b) homomorphism, (c) kernel, if the PR exceeds a few hundred lines.
