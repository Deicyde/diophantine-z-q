# Implementation note: The regulator of a real quadratic field

- Owner: pp-quadfield (plan step 3.2). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.log_goldenRatio_le_regulator`.
- Draft:
  ```lean
  theorem log_goldenRatio_le_regulator {d : ℤ} [Fact (¬ IsSquare (d : ℚ))] (hd : 1 < d) :
      Real.log goldenRatio ≤ NumberField.Units.regulator (QuadField d)
  ```
- Mathlib: `goldenRatio` (`Mathlib/NumberTheory/Real/GoldenRatio.lean`, value `(1 + √5)/2`), `NumberField.Units.regulator_eq_det`, `NumberField.Units.fundSystem`, `NumberField.InfinitePlace.mult` (`= 1` at a real place), `Algebra.trace` and `Algebra.norm` of a unit of `𝓞 K` (`NumberField.isUnit_iff_norm`), `Algebra.isIntegral_trace`.
- The proof uses only that `ε + ε'` is an integer and `εε' = ±1`; no description of `𝓞 K` is needed.
