# Implementation note: Well-formed natural circuits

- Lean name: `ZInQ.Translation.NatCircuit.WellFormed (P N : NatCircuit) (V : ℕ) : Prop`, with a
  `Decidable` instance (all quantifiers bounded by list lengths).
- Draft: a structure with fields `inputs_first`, `vars_nodup`, `args_lt`, `root_lt`,
  `var_explicit`, `const_ge_two : ∀ c ∈ N.consts, c ∉ ({0, 1, -1} : Finset ℤ) → 2 ≤ c`,
  `blocks_disjoint`, `blocks_avoid_vars`, `bound`, `power_wf`. Lemma
  `value_congr : WellFormed P N V → (∀ i < V, θ i = θ' i) → N.value P θ = N.value P θ'` and
  the locality lemma for call blocks used by the soundness induction.
- Mathlib: `List.Nodup`, `List.Disjoint`, `Finset` decidability.
- Upstream reuse: none.
- FINITE COMPUTATION: no (a predicate; its instance is checked in the scope article).
- Difficulty: low (~100 lines with the two lemmas).

Shared design (translation notes): namespace `ZInQ.Translation`, files under
`ZInQKernel/Compiler/Translation/`. Reuse the syntax chapter's `ZInQ.Syntax.NatCircuit`,
`ZInQ.Syntax.translate`, `ZInQ.Syntax.Rel`, `ZInQ.Syntax.pointRef` and the model chapter's
`ZInQ.iota`. The multiplication statement is taken as a hypothesis
`hM : ZInQ.MultiplicationExact`, where
`def MultiplicationExact : Prop := ∀ p q r : Fin 5 → ℚ, Syntax.Rel multiplyPoly 15 35134 (p ++ q ++ r) ↔ ∃ a b : ℤ, p = iota a ∧ q = iota b ∧ r = iota (a * b)`
(to be shared with the multiplication chapter; if that chapter instead proves the statement
from H, PC, MW, 22P, CAT, the assembly instantiates `hM` with that theorem). `iota` is never
evaluated; constants `c_3`, `A_ht` stay symbolic.
