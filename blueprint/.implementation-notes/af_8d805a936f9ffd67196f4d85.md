# Implementation note: Ideal counts at prime powers in a quadratic field

- Owner: pp-idealcount (plan step 3.3). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.idealCount_prime_pow`.
- Draft:
  ```lean
  theorem idealCount_prime_pow (K : Type*) [Field K] [NumberField K]
      (hK : Module.finrank ℚ K = 2) {p : ℕ} (hp : p.Prime) :
      ((idealCount K p : ℤ) - 1 = -1 ∨ (idealCount K p : ℤ) - 1 = 0 ∨
          (idealCount K p : ℤ) - 1 = 1) ∧
        ∀ k : ℕ, (idealCount K (p ^ k) : ℤ) =
          ∑ j ∈ Finset.range (k + 1), ((idealCount K p : ℤ) - 1) ^ j
  ```
- Mathlib: `Ideal.sum_ramification_inertia` (`∑ e_i f_i = [K:ℚ]`), `Ideal.primesOver`, `Ideal.absNorm_eq_pow_inertiaDeg`, `Ideal.ramificationIdx`, `Ideal.inertiaDeg`; factorization of an ideal of norm `p^k` into primes above `p`.
