# Implementation note: Scalar multiplication by halving

- Lean names: `ZInQ.Compiler.Precision.jaddB` (branching addition), `jdblB`, `jmulNat`,
  `jmul`, `jmul_represents`.
- Draft:
  ```lean
  def jmulNat (P : Fin 3 → ZSqrt2) : ℕ → (Fin 3 → ZSqrt2) → (Fin 3 → ZSqrt2)   -- loop, wf on e
  theorem jmul_represents (k : ℤ) :
      Represents (jmul k) (k • P0pt) ∧ ((jmul k) 2 = 0 ↔ k • P0pt = 0)
  ```
  `ZSqrt2` = `ℤ√2` (Mathlib `Zsqrtd 2`), with the ring map to `K0`; `Represents T Q` says
  `T 2 = 0 → Q = 0` and `T 2 ≠ 0 → Q = some (T 0 / T 2^2) (T 1 / T 2^3)`.
- Mathlib: `Zsqrtd`, `Zsqrtd.norm`, `zsmul` on `Affine.Point`, `Nat.div_lt_self` for the
  well-founded loop, `two_nsmul`, `add_nsmul`.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: medium (≈150 lines; the branch cases of `jaddB`).
