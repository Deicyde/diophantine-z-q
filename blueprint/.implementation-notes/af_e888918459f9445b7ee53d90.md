# Implementation note: Natural semantics of a natural circuit

- Lean names: `ZInQ.Syntax.NatCircuit.poly` (if the syntax chapter defines the denotation;
  otherwise `ZInQ.Compiler.NatCircuit.poly`), `natRel`, `WellScoped`.
- Draft:
  ```lean
  def NatCircuit.poly (C : Syntax.NatCircuit) (P : Syntax.Template) : MvPolynomial ℕ ℤ :=
    C.denote P C.root        -- one pass over the node list
  def NatCircuit.natRel (C) (P) (c : Fin C.inputCount → ℕ) : Prop :=
    ∃ x : ℕ → ℕ, (∀ i : Fin C.inputCount, x i = c i) ∧
      MvPolynomial.eval (fun i => (x i : ℤ)) (C.poly P) = 0
  ```
  Use `x : ℕ → ℕ` (values beyond the variable count are irrelevant since `poly` only
  mentions variables below it; prove `vars_subset`).
- Mathlib: `MvPolynomial.bind₁` / `aeval` for call substitution, `MvPolynomial.vars`.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: easy (definition), coordinate with the syntax chapter.
