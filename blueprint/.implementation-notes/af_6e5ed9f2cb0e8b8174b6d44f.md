# The finite search (small-height-search)

- Lean name: `ZInQ.smallHeight_search`.
- Decidable statement (closed, no separate enumeration-completeness lemma needed): quantify
  over `a, b, k` and derive `c`, so the box itself is the bounded quantifier.
  ```lean
  def survivors : List K0 := [0, ⟨3,-1⟩, ⟨-3,1⟩, ⟨1,1⟩, ⟨23,-17⟩, ⟨2,4⟩, ⟨5/2,-2⟩]
  def fC (x : K0) : K0 := x ^ 3 - ⟨11, -6⟩ * x
  def quadOK (a : ℕ) (b k : ℤ) : Bool :=      -- a ∈ [1,81], b ∈ [-162,162], k ∈ [1,162]
    let n := b ^ 2 - 2 * k ^ 2
    n % (4 * a) == 0 && (n / (4 * a)).natAbs ≤ 81 && Int.gcd (Int.gcd a b) (n / (4 * a)) == 1
  theorem smallHeight_search :
      (∀ a ∈ Finset.Icc 1 81, ∀ b ∈ Finset.Icc (-162 : ℤ) 162, ∀ k ∈ Finset.Icc (1 : ℤ) 162,
        quadOK a b k → ∀ η ∈ ({1, -1} : Finset ℤ),
          sqTest (fC ⟨-b / (2 * a), η * k / (2 * a)⟩).re (fC ⟨-b / (2 * a), η * k / (2 * a)⟩).im
            = true → (⟨-b / (2 * a), η * k / (2 * a)⟩ : K0) ∈ survivors) ∧
      (∀ p ∈ Finset.Icc (-9 : ℤ) 9, ∀ q ∈ Finset.Icc (1 : ℕ) 9, Int.gcd p q = 1 →
        sqTest (fC (p / q : ℚ)).re (fC (p / q : ℚ)).im = true → ((p / q : ℚ) : K0) ∈ survivors) ∧
      (∀ x ∈ survivors, sqTest (fC x).re (fC x).im = true)
  ```
  The counts 7,004 / 14,008 / 111 are reported by the manuscript but are not used by the
  proof; state them as a separate decidable fact `(box filter).card = 7004 ∧ ... = 111` only if
  the lead wants the manuscript's numbers pinned.
- Replay (this session, Python with exact rationals): 7004 triples, 14008 roots, 111 rationals,
  survivors exactly {0, 3-s, -3+s, 1+s, 23-17s, 2+4s, 5/2-2s}.
  Independently re-replayed in the adversarial review by enumerating `(a, b, k)` with `c` derived:
  same counts and survivors; the rational and quadratic candidate sets are disjoint.
- FINITE COMPUTATION: yes. Size: the naive `(a,b,c)` box has 81·325·163 ≈ 4.3·10^6 triples;
  14,008 + 111 square tests on rationals with numerators of a few dozen digits.
  Method 1: `native_decide` (fast; 81·325·162 ≈ 4.3·10^6 `(a,b,k)` triples, each a few integer
  operations, then 14,119 square tests). Method 2 (kernel certificate, CFSG style): enumerate (a, b)
  pairs (26,325) and for each derive the admissible k-interval from |c| ≤ 81
  (2k² ∈ [b² − 324a, b² + 324a]), with the interval endpoints pinned as Nat literals and checked
  by multiplication; pin the 7,004 tuples; for each square test pin either the rational square
  roots (checked by squaring) or a non-square witness r with r² < n < (r+1)² for numerator or
  denominator; the Boolean checker is proved by `Eq.refl true` and a soundness lemma links it to
  `IsSquare` via `sqTest_iff`. Expected kernel work ~10^5–10^6 GMP operations.
- Difficulty: medium (checker + soundness), the certificate generator is an external script.
