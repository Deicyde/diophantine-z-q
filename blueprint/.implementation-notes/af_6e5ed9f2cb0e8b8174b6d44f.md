# The finite search (small-height-search)

- Lean name: `ZInQ.smallHeight_search`.
- Decidable statement (draft):
  ```lean
  def boxTriples : List (ℤ × ℤ × ℤ × ℕ) := -- all (a,b,c,k) with the box conditions, enumerated
  def survivors : List K0 := [0, delta, -delta, ⟨1,1⟩, ⟨23,-17⟩, ⟨2,4⟩, ⟨5/2,-2⟩]
  theorem smallHeight_search :
      boxTriples.length = 7004 ∧ ratCandidates.length = 111 ∧
      (∀ t ∈ boxTriples, ∀ η ∈ [1, -1], sqTestK0 (fC (root t η)) = true → root t η ∈ survivors) ∧
      (∀ x ∈ ratCandidates, sqTestK0 (fC x) = true → x ∈ survivors) ∧
      (∀ x ∈ survivors, sqTestK0 (fC x) = true)
  ```
  together with a lemma that `boxTriples` lists exactly the integer tuples in the box (proved from
  the enumeration code, not by evaluation).
- Replay (this session, Python with exact rationals): 7004 triples, 14008 roots, 111 rationals,
  survivors exactly {0, 3-s, -3+s, 1+s, 23-17s, 2+4s, 5/2-2s}.
- FINITE COMPUTATION: yes. Size: the naive box has 81·325·163 ≈ 4.3·10^6 integer triples;
  14,008 + 111 square tests on rationals with numerators of a few dozen digits.
  Method 1: `native_decide` (fast). Method 2 (kernel certificate, CFSG style): enumerate (a, b)
  pairs (26,325) and for each derive the admissible k-interval from |c| ≤ 81
  (2k² ∈ [b² − 324a, b² + 324a]), with the interval endpoints pinned as Nat literals and checked
  by multiplication; pin the 7,004 tuples; for each square test pin either the rational square
  roots (checked by squaring) or a non-square witness r with r² < n < (r+1)² for numerator or
  denominator; the Boolean checker is proved by `Eq.refl true` and a soundness lemma links it to
  `IsSquare` via `sqTest_iff`. Expected kernel work ~10^5–10^6 GMP operations.
- Difficulty: medium (checker + soundness), the certificate generator is an external script.
