# Implementation note: The weighted pair norm

- Lean names: `ZInQ.Size.pairNorm_add_le`, `pairNorm_sub_le`, `pairNorm_mul_le`,
  `pairNorm_pow_le`, `pairDeg_add_le`, `pairDeg_mul_le`, `l1_re_le_pairNorm`, `l1_im_le_pairNorm`,
  `pairNorm_const`, `pairNorm_var`.
- Draft: `theorem pairNorm_mul_le (u v : QuadraticAlgebra (MvPolynomial σ ℤ) 2 0) :
  pairNorm (u * v) ≤ pairNorm u * pairNorm v`.
- Proof: `QuadraticAlgebra.re_mul`, `im_mul` (for `QuadraticAlgebra R a b` with `a = 2`, `b = 0`:
  `(u*v).re = u.re*v.re + 2*u.im*v.im`, `(u*v).im = u.re*v.im + u.im*v.re`; check the exact simp
  lemma names in Mathlib/Algebra/QuadraticAlgebra/Defs.lean), the scalar estimates, `nlinarith`.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: low (~60 lines).

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
