# Implementation note: Coefficient norms and degrees

- Lean names: `ZInQ.Size.l1`, `ZInQ.Size.pairNorm`, `ZInQ.Size.pairDeg`.
- Draft:
  ```lean
  def l1 {σ : Type*} (p : MvPolynomial σ ℤ) : ℕ := ∑ m ∈ p.support, (p.coeff m).natAbs
  def pairNorm {σ : Type*} (u : QuadraticAlgebra (MvPolynomial σ ℤ) 2 0) : ℕ := l1 u.re + 2 * l1 u.im
  def pairDeg {σ : Type*} (u : QuadraticAlgebra (MvPolynomial σ ℤ) 2 0) : ℕ :=
    max u.re.totalDegree u.im.totalDegree
  ```
- Mathlib: `MvPolynomial.support`, `MvPolynomial.coeff`, `MvPolynomial.totalDegree`,
  `QuadraticAlgebra` (Mathlib/Algebra/QuadraticAlgebra/Defs.lean:44). Mathlib has no ℓ¹ norm of
  multivariate polynomials (gap, trivial to define).
- Finite computation: no.
- Upstream reuse: none (`ZInQ.CoefficientAllocation` is about `ZMod 2` multilinear products and
  does not apply).
- Difficulty: low.

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
