# The trace forces one common group and place (common-group)

- Lean name: `ZInQ.Mult.common_group`.
- Draft:
  ```lean
  theorem common_group (data : SlopeData) (hW : ∀ g, W g ≠ 0) (hΘ : Θ ≠ 0) (hΦ : PoleSoluble (R / Θ^2))
      (p : ℕ) (hp : p.Prime) (hpSb : p ∉ S_b) (hcontact : IsOddContactPrime t p) :
      ∃ g 𝔭, (p : Zs) ∈ 𝔭.asIdeal ∧ (∀ j : Fin 12, (prec j : WithTop ℤ) ≤ vP 𝔭 (D g j))
  ```
  where `SlopeData` bundles `t η q D` (`D : Fin 6 → Fin 12 → K0` arbitrary).
- Reuse: `pole_obstruction`, `contact_valuations`, `vP_conj`, `vP_trace_ge`.
- Mathlib: `Valuation.map_add_eq_of_lt_left` (ultrametric equality when valuations differ),
  `Finset.prod`, `Finset.sum` valuation bounds (`Valuation.map_sum_le`).
- FINITE COMPUTATION: no. Difficulty: medium (~250 lines: the odd-valuation factor computation and
  the `(3r-1)/4` integer arithmetic, `omega` handles the latter).

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
