# Implementation note: The precision circuit is a specialization

- Lean names: `ZInQ.Compiler.Universal.precisionCircuit_poly`,
  `precisionCircuit_natRel_iff`.
- Draft:
  ```lean
  theorem precisionCircuit_poly :
      precisionCircuit.poly P = (MvPolynomial.bind₁ θ (haltingCircuit.poly P))^2 + ∑ i : Fin 4, pairPoly i ^ 2
  theorem precisionCircuit_natRel_iff (c : Fin 5 → ℕ) :
      precisionCircuit.natRel P c ↔ haltingCircuit.natRel P ![c3, encode5 (c 0) (c 1) (c 2) (c 3) (c 4)]
  ```
- Proof: node-by-node induction for the polynomial identity (`renameNode` commutes with
  denotation; for calls, `bind₁` commutes with the witness shift); then sum-of-squares
  vanishing over `ℤ` and `CantorDecoder.pairing_equation_iff`.
- Well-scopedness: `precisionCircuit_wellScoped` from `haltingCircuit_counts` (WellScoped)
  and injectivity of `· + 7`; the appended nodes mention only variables `0..8` (`decide` on the
  52-node literal).
- Mathlib: `MvPolynomial.bind₁`, `MvPolynomial.aeval_bind₁` (or `eval₂Hom_bind₁`), `MvPolynomial.rename`.
- Upstream reuse: `CantorDecoder.pairing_equation_iff`.
- FINITE COMPUTATION: no. Difficulty: medium.
