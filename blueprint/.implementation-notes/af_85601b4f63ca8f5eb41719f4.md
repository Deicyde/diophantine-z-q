# Implementation note: An effective Dirichlet theorem

- Owner: pp-final. Namespace `ZInQ.Progressions`; modules under `ZInQKernel/Progressions/`, importing Mathlib and the delivered `Progressions` modules only.
- Lean name: proposed `ZInQ.Progressions.effective_dirichlet`.
- Draft:
  ```lean
  theorem effective_dirichlet {q : ℕ} (hq : 2 ^ 16 ≤ q) {a : ℕ} (ha : a.Coprime q) :
      22 ≤ ({p ∈ Finset.Ioo (q ^ 2) (2 ^ q ^ 8) | p.Prime ∧ p % q = a % q}).card
  ```
  The delivered count actually gives primes above `q ^ 8`; stating the stronger
  `Finset.Ioo (q ^ 8) (2 ^ q ^ 8)` is fine and then also implies the `q ^ 2` form.
- Inputs: `twentytwo_primes_of_LFunction_lower_bound` (delivered, Mertens/Unconditional:
  `3 ≤ q`, `a.Coprime q`, `0 < c`, `∀ χ ≠ 1, c ≤ ‖L(1,χ)‖`; conclusion
  `22 ≤ #{p ∈ Ioc (q ^ 8) ⌊(q : ℝ) ^ 8 * exp (5 * q * (((log q + 3) ^ 2 + 6 * q) / c))⌋₊ | p.Prime ∧ p ≡ a [MOD q]}`)
  with `c := min (1 / (256 * M ^ 7)) (1 / (40 * q ^ (3/2)))` from `norm_LFunction_one_ge_min`
  (pp-final). Then show `⌊q^8 · exp(5qB)⌋₊ < 2 ^ q ^ 8` by comparing logarithms
  (`Nat.floor_lt`, `Real.log_lt_log_iff`, `Real.log_pow`, `Real.log_two_gt_d9`), and convert
  `p ≡ a [MOD q]` to `p % q = a % q` (`Nat.ModEq` is definitionally that).
- Arithmetic (article): `log q ≤ 2√q − 2` (`Real.log_le_sub_one_of_pos` at `√q`), `M ≤ 3√q`,
  `M² + 6q ≤ 15q`, `1/c ≤ 2^20 q^(7/2)`, `8 log q + 5qB ≤ 2^28 q^(11/2) < 2^39 q^(11/2) ≤ q^8 log 2`
  for `q ≥ 2^16`. Working with `√q` and natural powers of it avoids `rpow` exponents.
- Never evaluate `2 ^ q ^ 8`: cast to ℝ with `Nat.cast_pow` and take `Real.log`. The plan asks for
  `q₀ ≤ 2^64`; `q₀ = 2^16` suffices with large margin, and `W > 10^5 > 2^16`.
