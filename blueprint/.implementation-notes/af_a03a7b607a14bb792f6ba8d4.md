# Doubling and adding division-polynomial triples (division-polynomial-jacobian)

- Lean names: `ZInQ.omegaPoly (A : K) (n : ℤ)`, `ZInQ.psiTriple (A) (n) : Fin 3 → CoordinateRing`,
  `ZInQ.dblXYZ_psiTriple (k : ℤ) (hk : 1 ≤ k)`, `ZInQ.addXYZ_psiTriple`.
- Draft (W := `shortCurve A`, as a `WeierstrassCurve.Jacobian`; work in
  `W.toAffine.CoordinateRing` or, simpler, with `mk W` applied to `K[X][Y]` polynomials):
  ```lean
  theorem dblXYZ_psiTriple (k : ℤ) (hk : 1 ≤ k) :
      W.dblXYZ (psiTriple A k) = psiTriple A (2 * k)
  theorem addXYZ_psiTriple (k : ℤ) (hk : 1 ≤ k) :
      W.addXYZ (psiTriple A (k + 1)) (psiTriple A k) = (-1 : _) • psiTriple A (2 * k + 1)
  ```
  where `•` is Mathlib's weighted Jacobian scaling (`smul_fin3`: `u • P = ![u^2 P x, u^3 P y, u P z]`).
- Mathlib v4.35.0 (`Mathlib/AlgebraicGeometry/EllipticCurve/Jacobian/Formula.lean`, read):
  `dblX`, `dblY`, `dblZ`, `dblXYZ`, `addX`, `negAddY`, `addY`, `addZ`, `addXYZ` (the article's
  formulas are these with `a₁ = a₂ = a₃ = a₆ = 0`, `a₄ = A`), `dblXYZ_smul`, `addXYZ_smul`.
  Mathlib defines ω only as a TODO in `DivisionPolynomial/Basic.lean` (line 71), so `omegaPoly` is new.
- Review check (not a proof): both identities were evaluated in exact rational arithmetic, with
  Mathlib's formulas, at five points (including two-torsion points with `y = 0`) on four curves
  `y² = x³ + Ax`, for `1 ≤ k ≤ 7`; all hold, and `addXYZ(J_{k+1}, J_k) ≠ J_{2k+1}` (the sign
  `(-1)•` is needed).
- Proof plan: Z-components are one line each from `psi_rel` (elliptic-sequence note). For the X
  and Y components, expand with `linear_combination` whose coefficients are instances of
  `psi_rel` at index pairs among `k-2..k+3` and the curve equation; finding the coefficient
  combination is the real work (a computer-algebra search with symbolic ψ's, e.g. treating
  ψ_{k-2..k+3} and x, y as indeterminates modulo the law, can produce the certificate once).
