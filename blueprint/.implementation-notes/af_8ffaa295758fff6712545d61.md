# Implementation note: The natural-code predicate

- Lean name: `ZInQ.Translation.natural_rel_iff`.
- Draft:
  ```lean
  theorem natural_rel_iff (hMW : MordellWeilE) (hM : MultiplicationExact) (A : Fin 5 → ℚ) :
      Syntax.Rel naturalPoly 5 140604 A ↔ ∃ n : ℕ, A = iota n
  ```
- Proof plan: unfold `naturalPoly` with the builder theorem (`= κ(φ)^2`), apply the
  private-block theorem to get the seven callee relations on the fresh points, then the two
  directions as in the article. Injectivity of `iota` from the generator certificate
  (`iota_injective hMW`); raw addition from the model chapter (`rawAdd_rel_iota`).
- Mathlib: `Nat.sum_four_squares`; `Int.natCast` coercions for `n : ℕ ↦ (n : ℤ)`.
- Upstream reuse: none (`lean/ZInQ/RationalPositiveGuard.lean` is a different four-squares use).
- FINITE COMPUTATION: no.
- Difficulty: medium (~120 lines, mostly unfolding the template's formula and witness layout).

Shared design (translation notes): namespace `ZInQ.Translation`, files under
`ZInQKernel/Compiler/Translation/`. Reuse the syntax chapter's `ZInQ.Syntax.NatCircuit`,
`ZInQ.Syntax.translate`, `ZInQ.Syntax.Rel`, `ZInQ.Syntax.pointRef` and the model chapter's
`ZInQ.iota`. The multiplication statement is taken as a hypothesis
`hM : ZInQ.MultiplicationExact`, where
`def MultiplicationExact : Prop := ∀ p q r : Fin 5 → ℚ, Syntax.Rel multiplyPoly 15 35134 (p ++ q ++ r) ↔ ∃ a b : ℤ, p = iota a ∧ q = iota b ∧ r = iota (a * b)`
(to be shared with the multiplication chapter; if that chapter instead proves the statement
from H, PC, MW, 22P, CAT, the assembly instantiates `hM` with that theorem). `iota` is never
evaluated; constants `c_3`, `A_ht` stay symbolic.
