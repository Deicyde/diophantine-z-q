# Implementation note: Double-and-add chains

- Lean name: `ZInQ.Assembly.chain_value`, `ZInQ.Assembly.chain_satisfiable`.
- Draft: with the syntax chapter's chain builder `Syntax.doubleAddChain p k` (fresh points and
  `raw_add` calls; name to be matched with the exceptional-values template note),
  ```lean
  theorem chain_value (m : ℤ) (k : ℕ) (x : ℕ → ℚ) (hx : (chainFormula (iota m) k).liftHolds x) :
      chainValue (iota m) k x = iota (k * m)
  theorem chain_satisfiable (m : ℤ) (k : ℕ) : ∃ x, (chainFormula (iota m) k).liftHolds x
  ```
  Induction on `k` by `Nat.binaryRec`, invariant `base = iota (2^i * m)`, `out = iota ((k % 2^i) * m)`.
- Mathlib: `Nat.binaryRec`, `Nat.bit`, `Nat.testBit`.
- FINITE COMPUTATION: no (the counts 0,7,6,6,8,9 are `decide` on the bit expansions).
  Difficulty: medium (~150 lines).
