# The primes of Z[sqrt2] above an odd prime (primes-above-p)

- Lean names: `ZInQ.Mult.primeAbove_split`, `ZInQ.Mult.primeAbove_inert`, `ZInQ.Mult.vP_ratCast`,
  `ZInQ.Mult.vP_conj`, `ZInQ.Mult.vP_trace_ge`.
- Draft:
  ```lean
  theorem vP_ratCast {p : ℕ} (hp : p.Prime) (hp2 : p ≠ 2) (𝔭 : HeightOneSpectrum Zs)
      (h𝔭 : (p : Zs) ∈ 𝔭.asIdeal) (q : ℚ) : vP 𝔭 (q : K0) = padicValRat p q  -- for q ≠ 0
  theorem vP_conj (𝔭) (y : K0) : vP (conjPrime 𝔭) y = vP 𝔭 (star y)
  theorem vP_trace_ge (𝔭) (h𝔭 : (p : Zs) ∈ 𝔭.asIdeal) (y : K0) (m : ℤ)
      (h1 : m ≤ vP 𝔭 y) (h2 : m ≤ vP (conjPrime 𝔭) y) : m ≤ padicValRat p (2 * y.re)
  ```
  Conjugation is the `star` instance of `QuadraticAlgebra` (verified: `QuadraticAlgebra.star_mk`).
- Mathlib: `IsDedekindDomain.HeightOneSpectrum.valuation`, `Ideal.primesOver`, Kummer-Dedekind
  (`Mathlib/NumberTheory/KummerDedekind.lean`: `KummerDedekind.normalizedFactorsMapEquivNormalizedFactorsMinPolyMk`)
  — heavy; an elementary route is preferable: since `Zs` is a PID (model chapter `integers-pid`),
  primes are generated by `p` (inert) or by `a+bs` with norm `±p`; the residue map `a+bs ↦ a+br mod p`
  can be built by hand. Ramification index 1 follows from `p ∥ N(p) = p²` splitting into two norms.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: medium (~250 lines; the Dedekind-domain plumbing for `Zs` is
  shared with the model chapter's reduction article, coordinate with it).

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
