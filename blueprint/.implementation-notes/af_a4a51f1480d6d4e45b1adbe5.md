# Implementation note: Every node point is the code of the node's value

- Lean name: `ZInQ.Translation.translate_sound`.
- Draft:
  ```lean
  def PowerValueSpec (π : Syntax.ModelRecord) (P : NatCircuit) : Prop :=
    ∀ (a b c : ℤ) (r : Fin 5 → ℚ), Syntax.Rel π.denote 20 π.witnessCount
      (iota a ++ iota b ++ iota c ++ r) ↔
      ∃ w : Fin (P.variableCount - 3) → ℕ, r = iota (P.value P (extend a b c w))
  theorem translate_sound (hMW : MordellWeilE) (hM : MultiplicationExact)
      (hwf : NatCircuit.WellFormed P N V) (hπ : N.hasCalls → PowerValueSpec π P)
      (x : ℕ → ℚ) (hx : (Syntax.translate .. N ..).1.HoldsExceptRoot x)
      (hin : naturalInputs = false → ∀ i < N.inputCount, ∃ c : ℤ, pointRef x (5 * i) = iota c) :
      ∃ θ : ℕ → ℤ, N.Admissible P θ ∧ (∀ i < N.inputCount, pointRef x (5 * i) = iota (θ i) ∧
        (naturalInputs → 0 ≤ θ i)) ∧ ∀ j < N.nodes.length,
        pointRef x (nodePoint j) = iota (N.nodeVal P θ j)
  ```
- Proof: induction on the node list (prefix), carrying the partially defined `θ`
  (explicit variables fixed first, call blocks filled in node order with `Function.update`
  on the block interval). Cases as in the article; uses `natural_rel_iff`, the fixed-scalar
  semantics (`Syntax.fixedScalar_rel_iota` with `n = c ≥ 1`, base `iota 1`), raw addition,
  `hM`, `hπ`, `iota_injective`.
- Mathlib: `Function.update`, `Set.indicator`-free interval updates via `if`.
- Upstream reuse: the invariant mirrors `ZInQ.CircuitEncoding.Circuit.satisfies_iff_eq_eval`
  (lean/ZInQ/CircuitEncoding.lean); a direct reuse would need converting the node list into
  that `Fin`-indexed circuit with relational gates, which is not simpler.
- FINITE COMPUTATION: no.
- Difficulty: medium-high (~300 lines; the call-block bookkeeping is the delicate part).

Shared design (translation notes): namespace `ZInQ.Translation`, files under
`ZInQKernel/Compiler/Translation/`. Reuse the syntax chapter's `ZInQ.Syntax.NatCircuit`,
`ZInQ.Syntax.translate`, `ZInQ.Syntax.Rel`, `ZInQ.Syntax.pointRef` and the model chapter's
`ZInQ.iota`. The multiplication statement is taken as a hypothesis
`hM : ZInQ.MultiplicationExact`, where
`def MultiplicationExact : Prop := ∀ p q r : Fin 5 → ℚ, Syntax.Rel multiplyPoly 15 35134 (p ++ q ++ r) ↔ ∃ a b : ℤ, p = iota a ∧ q = iota b ∧ r = iota (a * b)`
(to be shared with the multiplication chapter; if that chapter instead proves the statement
from H, PC, MW, 22P, CAT, the assembly instantiates `hM` with that theorem). `iota` is never
evaluated; constants `c_3`, `A_ht` stay symbolic.
