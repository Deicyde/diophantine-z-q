- Lean name: `ZInQ.Compiler.Packed.counts`.
- Draft:
  ```lean
  theorem explicit_count (p) (r k) : (compiled p r k).explicitVars.length =
      2*k + 9 + 41*r + 10*p.length + 31*p.subCount
  theorem call_count (p) (r k) : (compiled p r k).callCount = 2 + 3*p.length + 12*r + 9*p.subCount

      (2*k + 9 + 41*r + 10*p.length + 31*p.subCount) + 79*(2 + 3*p.length + 12*r + 9*p.subCount)
  ```

  shared.
