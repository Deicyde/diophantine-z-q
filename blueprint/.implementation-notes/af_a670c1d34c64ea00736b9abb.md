# Implementation note: Natural solutions give rational witnesses

- Lean name: `ZInQ.Translation.translate_complete`.
- Draft:
  ```lean
  theorem translate_complete (hMW : MordellWeilE) (hM : MultiplicationExact)
      (hwf : NatCircuit.WellFormed P N V) (hπ : N.hasCalls → PowerValueSpec π P)
      (θ : ℕ → ℤ) (hθ : N.Admissible P θ)
      (hin : naturalInputs → ∀ i < N.inputCount, 0 ≤ θ i)
      (hroot : mode = .zero → N.value P θ = 0) :
      (Syntax.translate .. N ..).1.Holds (witnessAssignment θ)
  ```
  with `witnessAssignment θ` the explicit assignment of the article (defined by a lookup from
  each allocated point to the code of its value).
- Proof: well-definedness of the assignment (points are distinct allocations; equal constants
  share a point) is a lemma about `Syntax.translate` (its allocation counter and constant map);
  then each condition by the completeness halves.
- Mathlib: none special.
- Upstream reuse: none.
- FINITE COMPUTATION: no.
- Difficulty: medium (~200 lines).

Shared design (translation notes): namespace `ZInQ.Translation`, files under
`ZInQKernel/Compiler/Translation/`. Reuse the syntax chapter's `ZInQ.Syntax.NatCircuit`,
`ZInQ.Syntax.translate`, `ZInQ.Syntax.Rel`, `ZInQ.Syntax.pointRef` and the model chapter's
`ZInQ.iota`. The multiplication statement is taken as a hypothesis
`hM : ZInQ.MultiplicationExact`, where
`def MultiplicationExact : Prop := ∀ p q r : Fin 5 → ℚ, Syntax.Rel multiplyPoly 15 35134 (p ++ q ++ r) ↔ ∃ a b : ℤ, p = iota a ∧ q = iota b ∧ r = iota (a * b)`
(to be shared with the multiplication chapter; if that chapter instead proves the statement
from H, PC, MW, 22P, CAT, the assembly instantiates `hM` with that theorem). `iota` is never
evaluated; constants `c_3`, `A_ht` stay symbolic.
