- Lean name: proposed `ZInQ.Progressions.sum_filter_modEq_eq_avg`.

  ```lean
  variable {q : ℕ} [NeZero q]
  theorem sum_filter_modEq_eq_avg {a : ZMod q} (ha : IsUnit a) (f : ℕ → ℂ) (S : Finset ℕ) :
  ```
