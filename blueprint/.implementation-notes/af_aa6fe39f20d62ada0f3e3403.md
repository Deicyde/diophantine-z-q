# Implementation note: Absolute value by four squares

- Lean name: `ZInQ.Syntax.eq_abs_iff_four_squares`.
- Draft:
  ```lean
  theorem eq_abs_iff_four_squares (a x : ℚ) :
      a = |x| ↔ ∃ z : Fin 4 → ℚ, a = ∑ i, z i ^ 2 ∧ a ^ 2 = x ^ 2
  theorem valueAbs_rel_iff (x a : ℚ) :
      Rel valueAbsTemplate.poly 2 4 ![x, a] ↔ a = |x|
  ```
  The corollary `ZInQ.Syntax.valueAbs_rel_iff` unfolds the template by builder soundness
  (its polynomial is `((a - Σ z_i^2)^2 + (a^2 - x^2)^2)^2`) and applies the first theorem.
- Mathlib: `Nat.sum_four_squares`, `sq_eq_sq'`, `abs_eq_self`, `Rat.num_div_den`,
  `Finset.sum_nonneg`.
- Upstream reuse: adapt the proof of `ZInQ.RationalGuards.rational_pos_iff_four_squares_inverse`
  (it already writes a positive rational as a four-square sum after clearing the denominator).
