# Implementation note: Rational constants by global equations

- Lean names: `ZInQ.Syntax.eval_globals_eq_zero_iff`, `ZInQ.Syntax.generator_values`.
- Draft:
  ```lean
  theorem eval_globals_eq_zero_iff (eqs : List (ℕ × ℤ × ℤ)) (hq : ∀ e ∈ eqs, e.2.2 ≠ 0)
      (φ : Formula) (x : ℕ → ℚ) :
      eval₂ _ x (Formula.compile (.and (eqs.map globalEq ++ [φ]))) = 0 ↔
        (∀ e ∈ eqs, x e.1 = e.2.1 / e.2.2) ∧ φ.Holds x
  theorem generator_values (g0 g1 g2 : ℚ) :
      (8 * g0 = 1641 ∧ 4 * g1 = -15465 ∧ 32 * g2 = 87483) ↔
        (g0 = 1641/8 ∧ g1 = -15465/4 ∧ g2 = 87483/32)
  ```
- Mathlib: `eq_div_iff`, `norm_num`.
- Upstream reuse: `ZInQ.ModelCoordinates.scale_back` (lean/ZInQ/ModelCoordinateIdentities.lean,
  namespace `ZInQ.ModelCoordinates`) shows, in any field with `s^2 = 2`, that rescaling the
  coordinates `((57-28s)/8, (-660+417s)/32)` by `(1+s)^4` and `(1+s)^6` gives
  `((1641 - 1160 s)/8, (-123720 + 87483 s)/32)`, the coordinates of `P₀`; it is useful for the
  identification with the curve point, not for the three rational equations themselves.
- Finite computation: no (the three equalities are `norm_num` facts inside the proof).
- Difficulty: low (~50 lines).
