# Implementation note: Real characters are Legendre symbols away from 2q

- Owner: pp-realchar (plan step 3.1), `ZInQKernel/Progressions/RealChar/`. Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: `ZInQ.Progressions.exists_legendre_of_real_char`.
- Draft:
  ```lean
  variable {q : ℕ} [NeZero q]
  theorem exists_legendre_of_real_char {χ : DirichletCharacter ℂ q} (hχ2 : χ ^ 2 = 1)
      (hχ : χ ≠ 1) :
      ∃ d : ℤ, Squarefree d ∧ d ≠ 1 ∧ d.natAbs ≤ q ∧
        (∀ p : ℕ, p.Prime → (p : ℤ) ∣ d → p ∣ 2 * q) ∧
        ∀ p : ℕ, p.Prime → ¬ p ∣ 2 * q → χ p = (jacobiSym d p : ℂ)
  ```
- Mathlib: `ZMod.chineseRemainder` / `ZMod.prodEquivPi`, `DirichletCharacter.changeLevel`, `MulChar.IsQuadratic`, `quadraticChar` and `legendreSym` (`legendreSym.eq_pow`, Euler's criterion), `ZMod.isCyclic_units_of_prime_pow` / `ZMod.units` structure modulo `2^e`, `ZMod.χ₄`, `ZMod.χ₈`, `ZMod.χ₈'`, `legendreSym.at_neg_one`, `legendreSym.at_two`, `legendreSym.quadratic_reciprocity'`, `jacobiSym.mul_left`, `legendreSym.to_jacobiSym`.
- Only primes `p ∤ 2q` are covered, which keeps the 2-adic splitting law out of the ideal counts. The bound `|d| ≤ q` uses `2 ∣ d → 8 ∣ q` and `d₂ = -1 → 4 ∣ q`; those may be proved inside.
