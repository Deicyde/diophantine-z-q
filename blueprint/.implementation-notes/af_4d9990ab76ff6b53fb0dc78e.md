# Implementation note: Elementary estimates for the coefficient norm

- Lean names: `ZInQ.Size.natAbs_coeff_le_l1`, `l1_C`, `l1_X`, `l1_neg`, `l1_smul`, `l1_add_le`,
  `l1_mul_le`, `l1_pow_le`, `l1_sum_le`, `l1_prod_le`.
- Draft: `theorem l1_mul_le (p q : MvPolynomial σ ℤ) : l1 (p * q) ≤ l1 p * l1 q`.
- Proof of `l1_mul_le`: `p * q = ∑_{a ∈ p.support} ∑_{b ∈ q.support} monomial (a + b) (p a * q b)`
  (`MvPolynomial.as_sum`, Mathlib/Algebra/MvPolynomial/Basic.lean:963, and `Finset.sum_mul_sum`),
  then `l1_add_le` repeatedly and `l1 (monomial m c) = c.natAbs`. Alternatively use
  `MvPolynomial.coeff_mul` (Mathlib/Algebra/MvPolynomial/Basic.lean:648) and swap sums over the
  antidiagonal. `l1` is the `Finsupp` ℓ¹ sum, so `Finsupp.sum_add_index'`-style lemmas apply.
- Degrees: `MvPolynomial.totalDegree_add`, `totalDegree_mul`, `totalDegree_pow`,
  `totalDegree_finsetSum_le`, `totalDegree_finsetProd` (Mathlib/Algebra/MvPolynomial/Degrees.lean:474-557),
  `totalDegree_C`, `totalDegree_X`.
- Finite computation: no.
- Upstream reuse: none.
- Difficulty: low-medium (~120 lines).

Shared design (norm notes): polynomials are `MvPolynomial σ ℤ` (σ = ℕ for templates, `Fin 4`
for components, `Fin 15` for the guard). `l1 p := ∑ m ∈ p.support, (p.coeff m).natAbs : ℕ`;
pairs are `QuadraticAlgebra (MvPolynomial σ ℤ) 2 0` with `pairNorm u := l1 u.re + 2 * l1 u.im`
and `pairDeg u := max u.re.totalDegree u.im.totalDegree`. All bounds are natural-number
inequalities; logarithms appear only as exponents of 2.
