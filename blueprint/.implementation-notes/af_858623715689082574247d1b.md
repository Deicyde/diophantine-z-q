# Implementation note: Shape of the natural precision circuit

- Lean name: `ZInQ.Compiler.Universal.precisionCircuit_shape` (the syntax chapter's
  `natural-circuit-statistics` article states items 2-4; both should resolve to this one
  declaration).
- Draft:
  ```lean
  theorem precisionCircuit_shape :
      precisionCircuit.explicitVars.length = 54056 ∧ precisionCircuit.callCount = 15845 ∧
      precisionCircuit.varCount = 1305811 ∧ precisionCircuit.nodes.length = 293620 ∧
      countKind .var precisionCircuit = 54056 ∧ countKind .add precisionCircuit = 125327 ∧
      countKind .mul precisionCircuit = 98382 ∧ countKind .call precisionCircuit = 15845 ∧
      constList precisionCircuit = [c3, 0, 1, 2, 4, 1399, -1, 1, 2, -1]
  ```
- Proof: unfold `specialize`; `List.length_map`, `List.countP_append`, `List.countP_map`
  with `renameNode` preserving the kind of every node except `var 0 ↦ const c3`;
  `haltingCircuit_counts`, `haltingCircuit_nodeStats`; the 52 appended nodes by `decide`
  on the literal list (it mentions `c3` only as an opaque constant node; never unfold `c3`).
  Distinctness of `c3, 2, 4, 1399` from `c3_gt : 1399 < c3`.
- Mathlib: `List.countP_append`, `List.countP_map`, `List.length_append`.
- Upstream reuse: none.
- FINITE COMPUTATION: no (the finite parts are the two checks it uses). Difficulty: easy.

## From the deleted duplicate `syntax/recipes/natural-circuit-statistics.md`

- The specification chapter's witness accounting, recipe heights, admissible cutoff and
  template library now cite this statement directly (with the node statistics of the power
  template for its constants `4, 2, 3`). They need `c₃ ∉ {0, 1, -1, 2, 3, 4, 1399}`: `3` because
  the template library's combined constant table `![4, 2, 3, c₃, 1399]` must have `c₃` as a new
  entry; `c₃ > 1399` suffices.
- Kernel routes for the counts: (a) symbolically, as functions of the program, from the
  compiler's structural node emission (preferred); (b) CFSG style, pinning the node-kind
  histogram and the block starts as `Nat` literals checked by a Boolean checker with a
  soundness lemma. `native_decide` only at milestone 1.
