# Implementation note: Roots of unity in a quadratic field

- Owner: pp-quadfield (plan step 3.2). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.torsionOrder_quadField_le`.
- Draft:
  ```lean
  theorem torsionOrder_le_six_of_finrank_eq_two (K : Type*) [Field K] [NumberField K]
      (hK : Module.finrank ℚ K = 2) : NumberField.Units.torsionOrder K ≤ 6
  ```
- Mathlib: `NumberField.Units.torsionOrder`, the instance `IsCyclic (torsion K)`, `NumberField.Units.dvd_torsionOrder_of_isPrimitiveRoot`, `IsPrimitiveRoot.lcm_totient_le_finrank` (with `p = q = n`: `φ(n) ≤ finrank ℚ K`; needs `Polynomial.cyclotomic.irreducible_rat`), `IsCyclic.exists_generator`, `NumberField.Units.torsion`; then a finite case analysis showing `φ(n) ≤ 2 → n ≤ 6` (for instance `Nat.totient_even` and `φ(n) ≥ √(n/2)`, or `decide` on `n ≤ 12` after a crude bound).
- Stated for any degree-2 number field; the specialization to `QuadField d` is immediate.
