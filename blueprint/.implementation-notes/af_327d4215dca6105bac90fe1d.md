## External cross-check plan (not part of the proof)

Script `scripts/cross_check_construction.py` plus a Lean executable
`lake exe export_construction` (in a separate, non-audited Lean library so the audited root
package carries no I/O):

1. The Lean executable serializes, from the Lean terms themselves: the `FixedExpr` tree of
   every fixed constant, every template's `Prog.dag` output (name, parameterCount,
   variableCount, nodes, root, witnessBlocks, with fixed expressions as trees), and every
   recipe record, as JSON in the saved specification's schema. It never evaluates a fixed
   expression.
2. The script loads construction/ordinary-integer-definition.json (pinned SHA-256
   `4d639d4c44e69ea360d36d4591b8fdc82269d68b9363af0157d1e5c1174c7af6`) and compares:
   - `library.fixedConstants`: tree equality, except `P0`/`W`, which are compared as
     decimal literals with Python's primorial of 324;
   - each of the 23 templates: exact equality of parameterCount, variableCount,
     witnessBlocks, and of `nodes`/`root` (byte-exact if the Lean DAG interpreter mirrors
     JS hash-consing); fallback: Schwartz–Zippel identity test of the root polynomial modulo
     a 61-bit prime at up to 30 random points, sequentially, where each `fixed_integer`,
     `psi_component` and `finite_guard_product` node is replaced by a hash-based random
     oracle of (constructor kind, index expression tree, argument values), identical on
     both sides;
   - each recipe record field by field (generator, sourceVariables, constantDefinitions,
     operations, rootEquality, operationTemplates, calls, explicitWitnessRanges);
   - the five `integer_constant_k` literals, with `integer_constant_3` compared by SHA-256
     of its decimal string (`3888e5bfba37abf29ead0f8a63ab51723e2a118eabb0043b638345ae1ec804c6`).
3. A separate run compares the compiler chapter's natural circuit with
   construction/precision-natural-polynomial.json (that is the compiler chapter's script).
Output: one line per item, nonzero exit on any mismatch. This is a cross-check only: the
proof uses the Lean terms.
