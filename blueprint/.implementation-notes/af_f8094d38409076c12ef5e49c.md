# Implementation note: The multiplication-by-n formulas

- Lean name: `ZInQ.DivisionPolynomialMultiplication : Prop` (a hypothesis proposition, like
  the five in ZInQKernel/Hypotheses/), file `ZInQKernel/Hypotheses/DivisionPolynomial.lean`
  if the lead adopts it.
- Draft:
  ```lean
  def DivisionPolynomialMultiplication : Prop :=
    ∀ (x y : K₀) (h : (E).toAffine.Nonsingular x y) (n : ℤ), n ≠ 0 →
      ((n • (WeierstrassCurve.Affine.Point.some h) = 0) ↔ psiAt n x y = 0) ∧
      (n • Point.some h ≠ 0 → ∃ h', n • Point.some h = Point.some (x := x - psiAt (n+1) x y * psiAt (n-1) x y / psiAt n x y ^ 2)
                                                     (y := psiAt (2*n) x y / (2 * psiAt n x y ^ 4)) h')
  ```
  with `psiAt n x y` the evaluation of `divPsi (-d^2) n`.
- Mathlib gap: Mathlib v4.35.0 has the division polynomials (`ψ`, `φ`, `Ψ`, `Φ`, `preΨ`) but
  not `ω_n` (the file's own TODO) and not the theorem that `n • P` has coordinates
  `(φ_n/ψ_n², ω_n/ψ_n³)` nor that the zeros of `ψ_n` are the `n`-torsion points. This is the
  missing input. Formalizing it in general is a substantial project (the algebraic route goes
  through the elliptic-net identities of `Mathlib/NumberTheory/EllipticDivisibilitySequence.lean`
  and Jacobian-coordinate addition formulas in `Mathlib/AlgebraicGeometry/EllipticCurve/Jacobian`).
- Status: the model chapter states a background theorem proving this proposition
  (model/field/division-polynomial-multiples.md). Until that theorem is formalized the
  proposition is a candidate extra hypothesis (reported to the lead). It is classical and
  elementary, a milestone-3 target like Mordell–Weil, and is used only by the fixed-scalar
  semantics (and by the model chapter's codes).
- Upstream reuse: none.
- Finite computation: no.
- Difficulty: high (if formalized).
