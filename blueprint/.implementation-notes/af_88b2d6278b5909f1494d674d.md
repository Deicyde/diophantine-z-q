# Implementation note: Evaluation of a template call

- Lean names: `ZInQ.Syntax.eval_callPoly`, `ZInQ.Syntax.exists_block_callPoly_iff`.
- Draft:
  ```lean
  theorem eval_callPoly (P : MvPolynomial ℕ ℤ) (p w : ℕ) (g : ℕ → MvPolynomial ℕ ℤ) (x : ℕ → ℚ) :
      MvPolynomial.eval₂ (Int.castRingHom ℚ) x (callPoly P p w g) =
        MvPolynomial.eval₂ (Int.castRingHom ℚ)
          (fun i => if i < p then MvPolynomial.eval₂ (Int.castRingHom ℚ) x (g i) else x (w + i - p)) P
  theorem exists_block_callPoly_iff (hP : ∀ i ∈ P.vars, i < p + m)
      (hg : ∀ i < p, ∀ j ∈ (g i).vars, j ∉ Finset.Ico w (w + m)) (x : ℕ → ℚ) :
      (∃ y : Fin m → ℚ, eval₂ _ (blockUpdate x w y) (callPoly P p w g) = 0) ↔
        Rel P p m (fun i => eval₂ _ x (g i))
  ```
