# Implementation note: Ideal counts are multiplicative

- Owner: pp-idealcount (plan step 3.3). Namespace `ZInQ.Progressions`; modules import Mathlib (and earlier `Progressions` modules) only.
- Lean name: proposed `ZInQ.Progressions.idealCount_mul`.
- Draft:
  ```lean
  theorem idealCount_one (K : Type*) [Field K] [NumberField K] : idealCount K 1 = 1
  theorem idealCount_mul (K : Type*) [Field K] [NumberField K] {m n : ℕ}
      (hmn : Nat.Coprime m n) : idealCount K (m * n) = idealCount K m * idealCount K n
  ```
- Mathlib: `Ideal.absNorm_eq_one_iff`, `map_mul Ideal.absNorm`, `Ideal.sup_eq_top_iff_isCoprime`, unique factorization in the Dedekind domain `𝓞 K` (`UniqueFactorizationMonoid.normalizedFactors`, `Ideal.prime_of_isPrime`), `Ideal.absNorm_dvd_absNorm_of_le`; the bijection `(J, J') ↦ J * J'` with inverse `I ↦ (I ⊔ m, I ⊔ n)` (`Ideal.mul_eq_inf_of_coprime`).
- If convenient, package as `ArithmeticFunction.IsMultiplicative` of the arithmetic function `idealCount K` with value `0` at `0`, which is what `EulerProduct.eulerProduct_hasProd` consumes.
