# Implementation note: Size of the formal multiple constant

- Lean name: `ZInQ.Size.cstar_lt`.
- Draft:
  ```lean
  theorem M0_bounds (hNs : 1 ≤ Syntax.Ns) : 1 ≤ Syntax.M0 ∧ Syntax.M0 ≤ Syntax.Ns ^ 10
  theorem cstar_lt (hCAT : CatalogueBound) : Syntax.cstar < 2 ^ 2 ^ 2059
  ```
  `M0_bounds` is `leastFormalMultiple_bounds Ns` (formal-multiple-existence note) specialized;
  it needs only `1 ≤ Ns`. Under CAT this is part of `Ns_lt`. Without CAT, `Hcat ≥ 1` needs every
  catalogue entry `Nat.nth … r j` to be a prime, i.e. the set of primes `> 324` in the class to be
  infinite (otherwise `Nat.nth` returns `0` past the end): Dirichlet's theorem
  `Nat.infinite_setOfPred_prime_and_eq_mod` (Mathlib/NumberTheory/LSeries/PrimesInAP.lean:431)
  with `Nat.nth_mem_of_infinite`. Either way, state `M0_bounds (hNs : 1 ≤ Syntax.Ns)` and supply
  the hypothesis from `Ns_lt hCAT`. The strict bound on `cstar` needs `Ns_lt`.
- Proof: `4 * Ns^10 < 2^2 * (2^(2^2054))^10 = 2^(2 + 10 * 2^2054)` and `2 + 10 * 2^2054 < 2^2059`
  (`calc`, or `decide` on the closed comparison: 2059-bit literals, cheap).
- Mathlib: `Nat.pow_lt_pow_left`, `pow_mul`, `Nat.pow_lt_pow_right`.
- Finite computation: only the closed comparison `2 + 10 * 2^2054 < 2^2059`.
- Upstream reuse: none.
- Difficulty: low.

Shared design (size notes): namespace `ZInQ.Size`, files under `ZInQKernel/Size/`. Constants are
the syntax chapter's abbreviations `ZInQ.Syntax.Ps`, `W`, `Hcat`, `Hmax`, `Ns`, `M0`, `cstar`,
`ell`, `F`, `D`, `G0`, `E0`, `R`, `Q`, `Bcm`, `Ccm`, `Aht`, `T` (natural numbers or `toNat` of
`FixedExpr.val`; prove unfolding lemmas `T_def : T = (48 * Aht)^13` etc. by `rfl`/`simp
[FixedExpr.val]`). None of them is ever evaluated: never `decide`, `norm_num` or `rfl`-reduce a
goal containing `D`, `T`, `Hcat`, `M0`, `cstar`, `ell` or `c_3`; mark them `@[irreducible]`
after the unfolding lemmas, and work with `Nat.pow_lt_pow_left/right`, `Nat.pow_le_pow_left/right`,
`Nat.lt_two_pow_self`, `Nat.mul_lt_mul_of_lt_of_lt` as in upstream
`ZInQ.ExplicitCutoffBounds` (lean/ZInQ/ExplicitCutoffBounds.lean).
