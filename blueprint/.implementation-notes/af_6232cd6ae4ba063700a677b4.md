# The formal logarithm (formal-logarithm)

- Lean names: `ZInQ.Mult.formalLog : PowerSeries K`, `ZInQ.Mult.formalLog_add`,
  `ZInQ.Mult.ellLog : formalNbhd A hA →+ K`.
- Draft:
  ```lean
  noncomputable def formalLog (A : K) : PowerSeries K
  theorem formalLog_add : (formalLog A).subst F = X₁-part + X₂-part   -- log ∘ F = log T₁ + log T₂
  noncomputable def ellLog (A) (hA) : formalNbhd A hA →+ K       -- P ↦ ∑' r, coeff r log * z(P)^r
  ```
- Mathlib: `FormalGroup` only; `PowerSeries.derivative` (verified, `Mathlib/RingTheory/PowerSeries/Derivative.lean`);
  formal integration is not in Mathlib (define coefficientwise: `coeff (n+1) = coeff n / (n+1)`);
  convergence via `NonarchimedeanAddGroup.summable_of_tendsto_cofinite_zero`;
  `padicValNat_le_nat_log` for `v_p(r) ≤ log_p r`.
  GAP: invariant differential and formal logarithm of a formal group (Silverman IV.4-IV.5) absent.
- Recommended route for this project: define `formalLog` as the explicit binomial series of the
  logarithm-series article (`∑ (-1)^j C(2j,j) d^{2j} T^{4j+1}/(4j+1)`), so that only the identity
  `log ∘ F = log + log` has to be proved (see the formal-group-law note).
- FINITE COMPUTATION: no. Difficulty: HARD (shared estimate with formal-group-law).

Shared design (multiplication chapter): namespace `ZInQ.Mult`, files under
`ZInQKernel/Multiplication/`. Points are `genCurve.toAffine.Point` over `K0 = QuadraticAlgebra ℚ 2 0`;
codes are `ZInQ.iota`; template relations are `ZInQ.Syntax.Rel`. Valuations on `K0` at a prime
`𝔭 : IsDedekindDomain.HeightOneSpectrum Zs` (with `Zs` the model chapter's `ℤ[√2]`) are taken as
`ℤ∪{∞}`-valued via `IsDedekindDomain.HeightOneSpectrum.valuation K0 𝔭` (multiplicative, `ℤᵐ⁰`);
a thin wrapper `ZInQ.Mult.vP 𝔭 : K0 → WithTop ℤ` is recommended. The completion is
`𝔭.adicCompletion K0`. The constants `c_*`, `ℓ_0`, `A_ht`, `T` are the syntax chapter's symbolic
`FixedExpr` values and are never evaluated (no `decide`/`norm_num` on them).
