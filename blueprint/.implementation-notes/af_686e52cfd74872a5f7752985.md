# Implementation note: The ideal register language

- Lean names: `ZInQ.Compiler.IR.Stmt`, `IR.Outcome`, `IR.BigStep` (inductive),
  `IR.Program`, `IR.Accepts`, `IR.Total`, `IR.bigStep_deterministic`.
- Draft:
  ```lean
  inductive Op | const (k : ℕ) | copy (y : ℕ) | add (y z) | sub (y z) | mul (y z) | div (y z) | mod (y z)
  inductive Stmt | assign (x : ℕ) (o : Op) | seq (s t : Stmt) | ifLt (y z : ℕ) (s t : Stmt)
    | ifEq (y z : ℕ) (s t : Stmt) | whileLt (y z : ℕ) (s : Stmt) | accept | reject
  inductive Outcome | normal (ρ : ℕ → ℕ) | accept | reject
  inductive BigStep : Stmt → (ℕ → ℕ) → Outcome → Prop
  ```
  Natural `/` and `%` in Lean already satisfy `y/0 = 0`, `y%0 = y`.
- Mathlib: none.
- Upstream reuse: none.
- FINITE COMPUTATION: no. Difficulty: easy.
- Note: S22 (`precision-register.js`) is not in this repository; if obtained, compare its
  IR instruction set with this one and add any missing primitive.
