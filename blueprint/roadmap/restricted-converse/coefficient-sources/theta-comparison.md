# The unaveraged weighted theta comparison (O.7)

Put $m=|h_*|$ and $F=\mathbb Q(\sqrt{Dh_*})$ for a positive squarefree $D$ in the fixed odd filter, and assume
$(D/\ell_0)=1$ at the chosen stage, so that $\ell_0$ is inert in $F$. Keep the local Schwartz functions,
$P_M(z)=\lambda_M(L\pi_{\ell_0}(z))$ and $c_0$. Then for a $2$-power root of unity $\zeta_M(D)$, in the field
generated by the fixed characters at the primes of $N$,
$$H_M(mD)=c_0\,2^{\omega(N)}\,\zeta_M(D)\,\lambda_M\bigl(\overline{LP_D}\bigr)\pmod{2^M}.\tag{O.7}$$
No class number is divided out. In Section 7 this is (3.8): $a_{M_\theta}(D)=c_0\,2^{\omega(N)}\zeta_{M_\theta}(D)\lambda_{M_\theta}(\overline{LP_D^{\rm gen}})$
for admissible $D$ with $(D/\ell_0)=1$, while $a_{M_\theta}(D)=0$ when $(D/\ell_0)\ne1$, by the local support.
For the witness, $v_2a_M(D_w)=c_\theta+c_w$ with $c_\theta=9+\omega(N)$ once $M>c_\theta+c_w$.

**Proof sketch.** On the support, $Q_B(x)=mD$ exactly when $x^2=Dh_*$, which makes $\mathcal O_F\to R_z$ an
optimal embedding. Local orientations number one away from $N\ell_0$, two at each $p^e\,\|\,N$ and two at
$\ell_0$, so $2^{\omega(N)+1}$ in all, and each oriented tuple is an actual torsor under $\operatorname{Pic}(\mathcal O_F)$
(Voight, Proposition 14.6.7). The weights are constant along a torsor up to the genus character, which is
unramified because the biquadratic discriminant is $(Dh_*)^2$. Cornut–Jetchev (Sections 3.1–3.3 and 3.6,
Theorem 3.1, Corollary 3.2, with $S=\{\ell_0\}$, and Sections 4.9–4.10) identifies the adelic map with geometric
reduction, so $\sum_a\chi_F(a)P_M(z_a)=\lambda_M(\overline{LP_D})$. The stabilizer of an embedding is $\pm1$, so each
orbit contributes $c_0/2$ times the reference value. The Atkin–Lehner normalizer at $p^e\,\|\,N$ and the
uniformizer at $\ell_0$ change the weight and the norm character by the same sign, by (O.3) and
$(-1/\ell_0)=\chi_{h_*}(\ell_0)=-1$, so all $2^{\omega(N)+1}$ tuples contribute equally, and the total is
$c_0\,2^{\omega(N)}$ with no loss of precision.

## Manuscript check

Checked line by line by AI review, with the same scripts as the theta form. A global model with the
manuscript's local weights, on a definite algebra of class number one with $\ell_0=3$, $N=1$ and constant
$P$, reproduces (O.7): $H(m)=\pm12h(F)$ with every orientation contributing equally, $H(mD)=0$ for $D>1$
because the genus character sums to zero, and exactly $(|R^\times|/2)\,h(F)\,2^{\omega(N)+1}$ supported
embeddings. The model does not test level-prime orientations, a nonconstant $P$, or the Cornut–Jetchev
reduction identity. No class number is divided out or hidden in a normalization. Two points of presentation
were noted: (O.7) holds modulo $2^M\mathcal O$ in the fixed character ring, and $\zeta_M(D)$ is defined only up to
the sign $\chi_F$ of the reference class; every use takes a $2$-adic valuation, so neither matters. At all five
uses of (O.7) the statement proved is the one used. Not yet checked: the Cornut–Jetchev preprint (Theorem 3.1,
Corollary 3.2, Sections 3.6 and 4.9–4.10, Lemma 2.1(ii), and its hypotheses H.1–H.3), which is the only input
to $\sum_a\chi_F(a)P_M(z_a)=\lambda_M(\overline{LP_D})$, and Voight's Proposition 14.6.7.
