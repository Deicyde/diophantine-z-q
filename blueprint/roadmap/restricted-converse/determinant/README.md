# The fixed-field determinant argument

Sections 9.5 and 9.6 of the manuscript, restated at the end of Appendix G.

In the branch where the odd symbol is not a unit at the empty configuration, the companion field $K$ is fixed and
$E/K$ has $2^\infty$-Selmer corank one. Over this one field the corrected coordinate of every member of the common
family has a common denominator with bounded valuation and bounded poles. A Boolean-degree count then finds a
nonzero address whose coordinate agrees with the base coordinate to high $2$-adic precision. If $L'(E/K,1)$
vanished, the base coordinate would be zero, against the upper bound at that address; so $L'(E/K,1)\ne0$, and with
$L(E^{(k)},1)\ne0$ the curve $E$ has a simple zero.
