# Theta constants of genus 2

For a matrix $\Omega$ in the Siegel upper half-space $\mathfrak H_2$ and a characteristic $m$, the
theta constant $\theta_m(0,\Omega)$ is the value at $0$ of the theta function with characteristic
$m$. The proof reads a height off the theta constants of a period matrix of an abelian surface; the
one statement of this group says that their ratios are algebraic when the surface is defined over a
number field.

It is not proved here.
