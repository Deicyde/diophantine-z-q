# Deep multiples of the generator

For every prime element $\pi$ of $\mathbb Z[s]$ and every integer $N\ge1$ there is an integer
$m\ge1$ with $[m]P_0\in E_N(\pi)$; then $[jm]P_0\in E_N(\pi)$ for every $j\in\mathbb Z$. Consequently,
for every finite set $\Pi$ of prime elements and every $N\ge1$ there is $\kappa\ge1$ with
$[j\kappa]P_0\in E_N(\pi)$ for all $\pi\in\Pi$ and $j\in\mathbb Z$.

This is the manuscript's "each sufficiently small local formal neighbourhood has finite index
in the compact local group; a positive common multiple of the quotient orders gives
$\kappa$", restricted to the cyclic group generated by $P_0$.

**Proof sketch.** First find $m_1\ge1$ with $[m_1]P_0\in E_1(\pi)$: if $\pi\sim s$, $m_1=1$ since
$P_0\in E_3(s)$; if $\pi\sim d$, $m_1=7$; otherwise the good-prime statement gives some
$m_1\le|\mathbb Z[s]/(\pi)|^2+1$. Let $p$ be the rational prime below $\pi$. Multiplying by $p$ raises
$\nu_\pi$ by at least one, so $m=p^{N-1}m_1$ works. Since $E_N(\pi)$ is a subgroup, every multiple
of $m$ works too. For a finite set $\Pi$, take $\kappa=\prod_{\pi\in\Pi}m_\pi$.
