# Square classes in a field

Let $K$ be a field. For $u,v\in K$ write $u\equiv v$ when $u=vs^2$ for some nonzero $s\in K$. This is an
equivalence relation compatible with products, and for nonzero $u,v$ it says that $uv$ is a square.
