# The statements of the main theorem

This chapter states the target and the inputs that the [main theorem](../main/README.md) is assembled from.
The other chapters prove these inputs or use them, so the statements are kept apart from the main theorem,
which depends on those chapters.

Throughout, $K_0=\mathbb Q(s)$ with $s^2=2$, $d=75-53s$, and $E:y^2=x^3-d^2x$ over $K_0$.
For a reduced fraction $a/b$ with $b>0$, $h(a/b)=\log\max(|a|,b)$.
