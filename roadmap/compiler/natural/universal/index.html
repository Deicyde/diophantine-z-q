    The universal interpreter and the five-input circuit

    Programs are numbered by \(e+1=2^w(2D+1)\), with four base-\(2^w\) digits of \(D\) per state; decoding is total. A valid primitive program has a code whose machine halts exactly when the program does.

    Decoding. Every \(e\in\mathbb N\) is uniquely \(e+1=2^w(2D+1)\) with \(w,D\in\mathbb N\). The machine \(\mu_e\) numbered by \(e\) is: if \(w=0\), \(\mu_e(i)=\mathrm{halt}\) for every \(i\). Otherwise, with \(\beta=2^w\) and \(d_t=\lfloor D/\beta^t\rfloor\bmod\beta\) the base-\(\beta\) digits of \(D\) (zero beyond its length), state \(i\) reads \((o,j,x,y)=(d_{4i},d_{4i+1},d_{4i+2},d_{4i+3})\) and $\(\mu_e(i)=\mathrm{inc}(j,x)\text{ if }o=1,\qquad\mu_e(i)=\mathrm{dec}(j,x,y)\text{ if }o=2,\qquad \mu_e(i)=\mathrm{halt}\text{ otherwise}.\)$ Decoding is total. The program numbered \(e\) halts on input \(n\), written \(\operatorname{halts}(e,n)\), if the run of \(\mu_e\) from state \(0\) with \(n\) in register \(0\) and all other registers zero halts.

    Encoding. For a primitive program \(p=(p_0,\dots,p_{m-1})\) valid for \(r\) registers, let \(w(p)\) be the least \(w\ge2\) such that every register index and every target of \(p\) is below \(2^w\), let the fields of an instruction be \((1,j,x,0)\) for \(\mathrm{inc}(j,x)\), \((2,j,x,y)\) for \(\mathrm{dec}(j,x,y)\) and \((0,0,0,0)\) for the final halt, and put $\(D(p)=\sum_{i<m}\sum_{t<4}f_{i,t}\,2^{w(p)(4i+t)},\qquad \operatorname{code}(p)=2^{w(p)}\bigl(2D(p)+1\bigr)-1,\)$ where \(f_{i,0},\dots,f_{i,3}\) are the fields of \(p_i\).

    Let \(p\) be a primitive program with \(m\) instructions, valid for \(r\) registers. Then \(\mu_{\operatorname{code}(p)}(i)=p_i\) for every \(i<m\) and \(\mu_{\operatorname{code}(p)}(i)=\mathrm{halt}\) for \(i\ge m\). Consequently, for every \(n\in\mathbb N\), $\(\operatorname{halts}(\operatorname{code}(p),n)\iff p\text{ halts on the one input }n .\)$ Moreover \(\operatorname{code}(p)<2^{w(p)(4m+1)+1}\), and if \(m\ge2\) then \(\operatorname{code}(p)+1\ge2^{w(p)(4m-7)+1}\).

    Proof sketch. \(\operatorname{code}(p)+1=2^{w}(2D+1)\) with \(2D+1\) odd, so decoding recovers \(w=w(p)\ge2\) and \(D=D(p)\). All fields are below \(2^w\), so the base-\(2^w\) digits of \(D\) are exactly the fields, and digits beyond position \(4m\) are zero. The opcode fields \(1,2,0\) decode to \(\mathrm{inc}\), \(\mathrm{dec}\), \(\mathrm{halt}\) with the same register and targets (note \(2<2^w\) as \(w\ge2\)). Hence the two machines agree, and since every target of \(p\) is below \(m\) the runs agree and halt at the same time (only at state \(m-1\)). The bounds: \(D<2^{4wm}\), and for \(m\ge2\) the instruction \(p_{m-2}\) is not a halt, so its opcode digit at position \(4(m-2)\) is at least \(1\) and \(D\ge2^{4w(m-2)}\).

    The universal interpreter is assembled from primitive-program blocks, each with an entry state, exit states, argument and result registers, and private scratch registers, using a reserved jump register \(J\) (register \(2\) in the interpreter) that is zero at every block boundary. Each block clears its scratch registers before using them. For each of the following blocks, entered with \(J=0\) and arbitrary scratch values, the run reaches an exit after finitely many steps with the stated effect on its result registers and \(J=0\) again; every register other than its results and scratch registers is unchanged, and the scratch registers may be left nonzero:

    1. clear \(x\): \(x\leftarrow0\);
    2. preserving zero test of \(x\): exits to the zero or nonzero exit according to \(x\), with \(x\) unchanged (decrement and restore);
    3. copy \(x\leftarrow y\) (\(x\ne y\)): \(y\) is restored through a scratch counter;
    4. addInto \(x\leftarrow x+y\), also when \(x\) and \(y\) are the same register (the operand is snapshot before \(x\) is overwritten);
    5. ifLt \(y<z\): a comparison loop that consumes both registers and exits according to whether \(y<z\), leaving \(y=0\), \(z=z-y-1\) if \(y<z\) and \(y=y-z\), \(z=0\) otherwise (callers compare private copies);
    6. divmod with divisor \(z\ge1\): \(q\leftarrow\lfloor y/z\rfloor\), \(r\leftarrow y\bmod z\), by repeated subtraction from a private remainder maintaining \(y=qz+r\), subtracting only when \(r\ge z\) (the interpreter's divisors are at least \(2\));
    7. divmod2 of \(y\) into \((q,r)\): \(q\leftarrow q+\lfloor y/2\rfloor\), \(r\leftarrow y\bmod2\) and \(y\leftarrow0\) (halving with parity, consuming \(y\) in pairs; callers clear \(q\) first).

    Proof sketch. Each block is a fixed short program; its correctness is a loop invariant (the sum of the moved register and the counter is constant for copies and additions; \(y=qz+r\) for division) and termination by a decreasing register.

    With the conventions of the arithmetic blocks, the interpreter has blocks with the following effects, each terminating after finitely many steps:

    1. uncons \(x\mapsto(h,t)\): if \(x=\operatorname{cons}(h,t)\) then \((h,t)\), and \((0,0)\) for \(x=\operatorname{nil}\); it copies its input first and halves a positive even value until it is odd, each halving strictly decreasing that value;
    2. cons \((h,t)\mapsto\operatorname{cons}(h,t)\), copying both inputs before the final write, so that aliased arguments are safe;
    3. getList \((L,i)\mapsto\operatorname{get}(L,i)\), following \(i\) links (reading past the end gives \(0\));
    4. setList \((L,i,v)\mapsto\operatorname{set}(L,i,v)\): save the traversed prefix in reverse, replace the selected entry (padding with zeros past the end), then restore the prefix; the saved list strictly decreases during restoration.

    Proof sketch. Compositions of the arithmetic blocks with loops whose measures are the halved value, the remaining index and the saved reversed prefix; the effect is computed with the tape-list equations.

    ZInQ.Compiler.Universal.interpreter

    The universal interpreter \(\mathcal U\) is a primitive program with \(2\) inputs (\(e\) in register \(0\), \(n\) in register \(1\)), reserved jump register \(2\), valid for \(204\) registers, assembled from the arithmetic and list blocks. It performs:

    1. Decode the number. Compute \(w\) and \(D\) with \(e+1=2^w(2D+1)\) by repeated halving of \(e+1\). If \(w=0\), go to cleanup. Otherwise set \(\beta=2^w\).
    2. Initialize. Set the tape to \(\operatorname{cons}(n,\operatorname{nil})\) (the virtual file with \(n\) in register \(0\)) and the virtual state \(\mathrm{pc}=0\).
    3. Main loop. Extract the base-\(\beta\) digits \(o,j,x,y\) of \(D\) at positions \(4\mathrm{pc},\dots,4\mathrm{pc}+3\) by repeated division. If \(o=1\): replace entry \(j\) of the tape by its successor and set \(\mathrm{pc}=x\). If \(o=2\): read \(v=\operatorname{get}(\text{tape},j)\); if \(v>0\) write \(v-1\) and set \(\mathrm{pc}=x\), else write \(v=0\) back and set \(\mathrm{pc}=y\) (the entry is always written with setList, which may pad the tape with zeros). Otherwise leave the loop (a simulated halt). Return to the start of the loop.
    4. Cleanup. Clear all \(204\) registers and reach the final halt.

    Its shape, recorded in the interpreter-shape statement, is \(1{,}399\) instructions (\(1{,}022\) sub instructions, \(376\) add instructions and the final halt) over \(204\) registers. The manuscript's interpreter is pinned only through its compiled polynomial; its program is recoverable from the saved universal circuit (state and register histories carry their indices), and the Lean definition is required to reproduce it exactly, so that the counts of the compiled circuit are those of the specification.
