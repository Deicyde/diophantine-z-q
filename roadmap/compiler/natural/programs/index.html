    Programs, lowering and the wrapper

    Register machines have increment, decrement-or-branch and halt instructions. A primitive program halts only at its last instruction; it accepts when it halts with every register zero.

    Instructions. An instruction is \(\mathrm{inc}(j,x)\) (increment register \(j\), go to state \(x\)), \(\mathrm{dec}(j,x,y)\) (if register \(j\) is positive, decrement it and go to \(x\); otherwise go to \(y\)) or \(\mathrm{halt}\). Registers are indexed by \(\mathbb N\) and hold natural numbers; a register file is a map \(\rho:\mathbb N\to\mathbb N\).

    Machines and virtual halting. A machine is a map \(\mu:\mathbb N\to\) instructions. A configuration is a pair \((i,\rho)\) of a state and a register file; the step relation executes \(\mu(i)\) and is undefined at a halt instruction. The run of \(\mu\) from \((0,\rho_0)\) halts if it reaches, after finitely many steps, a state \(i\) with \(\mu(i)=\mathrm{halt}\).

    Primitive programs. A primitive program is a list \(p=(p_0,\dots,p_{m-1})\), \(m\ge1\), of instructions. It is valid for \(r\) registers if \(p_{m-1}=\mathrm{halt}\), no other instruction is a halt, every register index is below \(r\) and every target is below \(m\). It induces the machine with \(\mu(i)=p_i\) for \(i<m\) and \(\mu(i)=\mathrm{halt}\) for \(i\ge m\). For \(k\le r\) and inputs \(a\in\mathbb N^k\) the initial file has \(\rho_0(i)=a_i\) for \(i<k\) and \(0\) otherwise. A valid \(p\)

    • halts on \(a\) if its run from \((0,\rho_0)\) reaches the final state \(m-1\);
    • accepts \(a\) if its run reaches the final state \(m-1\) with every register zero.

    The number of add instructions (increments), sub instructions (decrements) and registers \(r\) are the shape of \(p\). Since a valid program halts only at its final state, a run reaches it at most once and then stops.

    This is a definition. Acceptance is the convention of the packed compiler; halting is the convention of the universal numbering; a cleanup stage that clears every register before the final halt converts the second into the first.

    The precision program is written in an ideal register language with natural arithmetic and structured control, whose semantics is a statement about terminating executions, not about a budgeted simulator. Lowering replaces each operation by a primitive block with fresh auxiliary registers; acceptance enters cleanup and rejection a permanent self-loop.

    The ideal register language has registers indexed by \(\mathbb N\) holding natural numbers. Its statements are:

    • assignments \(x\leftarrow k\) (a natural constant), \(x\leftarrow y\), \(x\leftarrow y+z\), \(x\leftarrow y\mathbin{\dot-}z\) (truncated subtraction), \(x\leftarrow y\cdot z\), \(x\leftarrow\lfloor y/z\rfloor\) and \(x\leftarrow y\bmod z\) (with \(\lfloor y/0\rfloor=0\) and \(y\bmod0=y\)), where \(x,y,z\) are registers that may coincide;
    • sequencing \(S_1;S_2\), the conditionals \(\mathbf{if}\ y<z\ \mathbf{then}\ S_1\ \mathbf{else}\ S_2\) and \(\mathbf{if}\ y=z\ \mathbf{then}\ S_1\ \mathbf{else}\ S_2\), the loop \(\mathbf{while}\ y<z\ \mathbf{do}\ S\), and the terminal statements \(\mathbf{accept}\) and \(\mathbf{reject}\).

    The big-step semantics is the inductive relation \(\langle S,\rho\rangle\Downarrow o\) between a statement, a register file and an outcome \(o\in\{\mathrm{normal}(\rho'),\mathrm{accept},\mathrm{reject}\}\), with the usual rules (assignments update one register with the exact value; a terminal outcome of \(S_1\) skips \(S_2\); a loop iterates while its test holds). A derivation exists only for terminating executions. A program is a statement \(S\) with a register bound \(\rho_S\) (all registers occurring in \(S\) are below \(\rho_S\)) and \(k\le\rho_S\) input registers; it accepts \(a\in\mathbb N^k\) if \(\langle S,\rho_0(a)\rangle\Downarrow\mathrm{accept}\) for the initial file \(\rho_0(a)\) (inputs in registers \(0,\dots,k-1\), all others \(0\)), and it is total if for every \(a\) some outcome is derivable. The language is deterministic: each statement and file have at most one outcome.

    For a program \(S\) of the ideal register language with register bound \(\rho_S\), the lowering \(\mathrm{low}(S)\) is the primitive program built as follows.

    1. Layout. Registers below \(\rho_S\) keep their meaning; register \(J=\rho_S\) is the reserved jump register (always \(0\) at block boundaries, so \(\mathrm{dec}(J,x,x)\) is an unconditional jump to \(x\)); the six registers \(J+1,\dots,J+6\) are auxiliary registers shared by all primitive blocks, each block starting and ending with them zero.
    2. Primitive blocks. Every block for an assignment to \(x\) first snapshots each source \(y\): it moves \(y\) into two fresh auxiliary registers \(a,a'\) (decrement \(y\), increment \(a\) and \(a'\), until \(y=0\)) and moves \(a\) back into \(y\), so that \(y\) is restored and \(a'\) holds its value. Only after all sources are snapshot is \(x\) cleared (a loop of decrements) and written; hence aliasing of \(x\) with \(y\) or \(z\), and \(y=z\), are safe. Then: \(x\leftarrow k\) increments \(x\) \(k\) times; \(x\leftarrow y\) and \(x\leftarrow y+z\) move the snapshots into \(x\); \(x\leftarrow y\mathbin{\dot-}z\) moves the snapshot of \(y\) into \(x\) and then, once per unit of the snapshot of \(z\), decrements \(x\) if it is positive (saturating decrement); \(x\leftarrow y\cdot z\) adds the snapshot of \(y\) into \(x\) (restoring it through a further auxiliary register) once per unit of the snapshot of \(z\), then clears the snapshot of \(y\); \(x\leftarrow\lfloor y/z\rfloor\) and \(x\leftarrow y\bmod z\) test the snapshot of \(z\) for zero (giving \(0\), respectively the snapshot of \(y\)) and otherwise move the snapshot \(r\) of \(y\) one unit at a time into a counter \(m\), keeping a quotient \(q\) and a register \(c=z-m\ge1\): each unit decrements \(c\), and when \(c\) reaches \(0\) the counter \(m\) is cleared, \(q\) is incremented and \(c\) is refilled with \(z\). This maintains \(y=r+qz+m\) with \(0\le m<z\), so at exit (\(r=0\)) \(q=\lfloor y/z\rfloor\) and \(m=y\bmod z\), and \(q\) or \(m\) is moved into \(x\). Every block ends with its auxiliary registers zero and every register below \(\rho_S\) other than \(x\) unchanged.
    3. Control. Sequencing concatenates blocks; a test \(y<z\) or \(y=z\) is a comparison loop on snapshots of \(y\) and \(z\) that branches directly to the two targets; a loop jumps back to its test.
    4. Termination. \(\mathbf{accept}\) jumps to a final cleanup stage that clears every register used by the program and then reaches the final halt; \(\mathbf{reject}\) and normal completion of \(S\) jump to a permanent self-loop \(\mathrm{dec}(J,i,i)\) at its own state \(i\).

    Items 1-3 produce the open code \(\mathrm{code}(S)\) of a statement, a list of instructions with one entry state and one normal exit (the state after its last block), parameterized by its start state; item 4 closes it into the primitive program \(\mathrm{low}(S)\), valid for its register count \(r=J+7\), with all targets absolute.

    Let \(S\) be a program of the ideal register language with \(k\) inputs, register bound \(\rho_S\) and lowering \(\mathrm{low}(S)\) with \(r\) registers.

    1. (Open code) Say that a machine file \(\sigma\) simulates a file \(\rho\) if \(\sigma(i)=\rho(i)\) for \(i<\rho_S\) and \(\sigma(i)=0\) for \(i\ge\rho_S\) (in particular the jump register and the auxiliary registers are zero). Let \(S'\) be a statement of \(S\) and let \(\sigma\) simulate \(\rho\). If \(\langle S',\rho\rangle\Downarrow\mathrm{normal}(\rho')\), the run from the entry of \(\mathrm{code}(S')\) with file \(\sigma\) reaches its normal exit with a file simulating \(\rho'\); if the outcome is \(\mathrm{accept}\), it reaches the cleanup entry with every register \(i\ge\rho_S\) zero; if it is \(\mathrm{reject}\), it reaches the self-loop. Conversely, if the run from the entry with file \(\sigma\) reaches a halt instruction after \(t\) steps, then either \(\langle S',\rho\rangle\Downarrow\mathrm{accept}\); or \(\langle S',\rho\rangle\Downarrow\mathrm{normal}(\rho')\) and the run from the normal exit, with some file simulating \(\rho'\), reaches a halt instruction within \(t\) steps; or \(\langle S',\rho\rangle\Downarrow\mathrm{reject}\) and the run from the self-loop reaches a halt instruction within \(t\) steps.

    For every \(a\in\mathbb N^k\):

    1. if \(\langle S,\rho_0(a)\rangle\Downarrow\mathrm{accept}\), then \(\mathrm{low}(S)\) accepts \(a\) (it reaches its final halt with every register zero);
    2. if \(\mathrm{low}(S)\) halts on \(a\) (reaches its final halt), then \(\langle S,\rho_0(a)\rangle\Downarrow\mathrm{accept}\).

    Hence \(\mathrm{low}(S)\) halts on \(a\) iff it accepts \(a\) iff \(S\) accepts \(a\); for a total program that rejects \(a\), the run of \(\mathrm{low}(S)\) never halts.

    Proof sketch. Blocks. Each primitive block, entered with the jump register and its auxiliary registers in the state required at block boundaries, reaches its exit after finitely many steps with the register below \(\rho_S\) updated to the exact value and every other register restored (copies restore their source; snapshots make aliased operands safe; saturating decrement is truncated subtraction; repeated addition is multiplication; division maintains \(y=r+qz+m\) with \(0\le m<z\) while it moves the dividend unit by unit). Statements. By induction on the derivation of \(\langle S',\rho\rangle\Downarrow o\), the run from the entry of the code of \(S'\) with a file simulating \(\rho\) reaches its normal exit with a file simulating \(\rho'\), the cleanup entry, or the self-loop, according to \(o\); loops by induction on completed iterations. Cleanup clears all registers and halts. (2) The run is deterministic and the final halt is reachable only through cleanup, which is entered only from the code of \(\mathbf{accept}\). By induction on the statement and, for loops, strong induction on the length of the run fragment from the entry, a fragment reaching a halt yields one of the three alternatives of (0) for that statement (the fragment is a sequence of block executions mirroring the semantics, so for a loop it contains finitely many iterations). At the top level the second and third alternatives are impossible, since the run from the self-loop never halts, so \(\langle S,\rho_0(a)\rangle\Downarrow\mathrm{accept}\).
