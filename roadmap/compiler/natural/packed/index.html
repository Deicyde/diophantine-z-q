    The packed-history compiler

    A primitive program with \(m\) instructions over \(r\) registers is compiled by packing a run of length \(q\) into base-\(B\) integers, with \(K=2^c\), \(B=4K>m\), \(T=B^q\), \(F_q=1+B+\dots+B^q\) and \(D=(K-1)F_q\), every input being below \(K\).

    DefinitionThe packed-history construction#✓fully proved

    ZInQ.Compiler.Packed.construction ZInQ.Compiler.Packed.compiled

    Let \(p=(p_0,\dots,p_{m-1})\) be a primitive program valid for \(r\) registers and let \(1\le k\le r\). The packed-history construction of \(p\) is the natural construction in hierarchical mode with \(k\) inputs \(a_0,\dots,a_{k-1}\) (\(=X_0,\dots,X_{k-1}\)) which takes the fresh variables $\(q,\ c,\ K,\ B,\ T,\ F,\ D,\qquad R_0,\dots,R_{r-1},\qquad N_0,\dots,N_{r-1},\qquad S_0,\dots,S_{m-1}\)$ in this order and returns the conjunction of the following formulas, in this order:

    1. \(\mathrm{lt}(0,c)\), \(\mathrm{power}(K,2,c)\), \(B\doteq4K\), \(\mathrm{lt}(m,B)\), \(\mathrm{power}(T,B,q)\), then \(\mathrm{lt}(a_i,K)\) for \(i<k\);
    2. \(BF+1\doteq F+BT\), \(D+F\doteq KF\), \(S_0+\dots+S_{m-1}\doteq F\), \(S_{m-1}\doteq T\);
    3. \(\mathrm{mask}(S_i,F)\) for \(i<m\);
    4. for each \(j<r\): \(\mathrm{mask}(R_j,D)\), \(\mathrm{lt}(R_j,T)\), \(\mathrm{bitAnd}(K\cdot N_j,\ R_j+D,\ K\cdot F)\);
    5. for each sub instruction \(p_i=\mathrm{dec}(j,x,y)\), in increasing \(i\): fresh \(V_i,W_i\), then \(\mathrm{bitAnd}(V_i,S_i,N_j)\) and \(S_i\doteq V_i+W_i\);
    6. for each \(j<r\): \(R_j+B\cdot C_j\doteq\iota_j+B\cdot R_j+B\cdot A_j\), where \(\iota_j=a_j\) for \(j<k\) and \(0\) otherwise, \(A_j=\sum_{i:\,p_i=\mathrm{inc}(j,\cdot)}S_i\) and \(C_j=\sum_{i:\,p_i=\mathrm{dec}(j,\cdot,\cdot)}V_i\);
    7. for each \(i<m\): \(S_i\doteq[i=0]+B\cdot I_i\), where \(I_i\) is the sum, in program order, of \(S_{i'}\) for \(p_{i'}=\mathrm{inc}(\cdot,i)\), of \(V_{i'}\) for \(p_{i'}=\mathrm{dec}(\cdot,i,\cdot)\) and of \(W_{i'}\) for \(p_{i'}=\mathrm{dec}(\cdot,\cdot,i)\) (for a sub instruction its nonzero target is listed before its zero target).

    Empty sums are the constant \(0\). The compiled circuit \(\mathcal C_{p,k}\) is the natural circuit of this construction. Here \(R_j\) is the packed history of register \(j\), \(S_i\) that of state \(i\), \(N_j\) the packed nonzero indicator, \(V_i,W_i\) the nonzero and zero branch histories, and \(F=F_q=1+B+\dots+B^q\), \(D=(K-1)F_q\) by item 2.

    This is a definition. No equation is repeated \(q\) times: \(q\) is one variable and the number of conjuncts depends only on \(p\).

    Masks by \(D\) and \(F_q\) and the bound \(R_j<T\) make register digits smaller than \(K\) with a zero final digit, and state digits zero or one; since \(B>m\) the state sum selects exactly one state at each time.

    TheoremDigits of masked histories#✓fully proved

    ZInQ.Compiler.Packed.packed_masks

    Let \(c>0\), \(K=2^c\), \(B=4K\), \(q\in\mathbb N\), \(T=B^q\), and let \(F,D\in\mathbb N\) satisfy \(BF+1=F+BT\) and \(D+F=KF\). Then:

    1. \(F=F_q=\sum_{t=0}^qB^t\) and \(D=(K-1)F_q=\sum_{t=0}^q(K-1)B^t\);
    2. a natural number \(R\) is masked by \(D\) and satisfies \(R<T\) if and only if \(R=\sum_{t=0}^q\rho_tB^t\) with \(\rho_t<K\) for all \(t\) and \(\rho_q=0\);
    3. a natural number \(S\) is masked by \(F_q\) if and only if \(S=\sum_{t=0}^q\sigma_tB^t\) with \(\sigma_t\in\{0,1\}\).

    In words: register digits are below \(K\), the terminal register digit is zero, and state digits are zero or one. The digit sequences are unique.

    Proof sketch. (1) \(B\ge8\), so \(BF+1=F+BT\) gives \((B-1)F=B^{q+1}-1\), hence \(F=\sum_{t\le q}B^t\); then \(D=KF-F\). (2), (3) \(B=2^{c+2}\), so the binary expansion of a number splits into base-\(B\) slots of \(c+2\) bits. \(D\) has, in each slot \(t\le q\), the bits \(0,\dots,c-1\) set (value \(K-1\)) and nothing above slot \(q\); \(F_q\) has bit \(0\) of each slot \(t\le q\). Masking by \(D\) (resp. \(F_q\)) therefore says exactly that every slot digit is below \(K\) (resp. at most \(1\)) and that the slots above \(q\) vanish. Finally \(R<B^q\) is equivalent to \(\rho_q=0\) given the other slots vanish.

    theorem packed_masks {c q K B T F D : ℕ} (_hc : 0 < c) (hK : K = 2 ^ c) (hB : B = 4 * K)
    (hT : T = B ^ q) (hF : B * F + 1 = F + B * T) (hD : D + F = K * F) :
    (F = ∑ t ∈ range (q + 1), B ^ t ∧ D = ∑ t ∈ range (q + 1), (K - 1) * B ^ t) ∧
    (∀ R, (Nat.land R D = R ∧ R < T) ↔
      ∃ ρ : ℕ → ℕ, (∀ t ≤ q, ρ t < K) ∧ ρ q = 0 ∧ R = ∑ t ∈ range (q + 1), ρ t * B ^ t) ∧
    (∀ S, Nat.land S F = S ↔
      ∃ σ : ℕ → ℕ, (∀ t ≤ q, σ t ≤ 1) ∧ S = ∑ t ∈ range (q + 1), σ t * B ^ t)

    TheoremOne active state per time slot#✓fully proved

    ZInQ.Compiler.Packed.one_active_state

    Let \(B,q,T=B^q,F_q\) be as in the masked-digit statement, let \(1\le m<B\), and let \(S_0,\dots,S_{m-1}\) be masked by \(F_q\), with digits \(\sigma_i(t)\in\{0,1\}\) (\(t\le q\)). If $\(S_0+\dots+S_{m-1}=F_q\qquad\text{and}\qquad S_{m-1}=T,\)$ then for every \(t\le q\) there is exactly one \(i<m\) with \(\sigma_i(t)=1\), and \(\sigma_{m-1}(t)=1\) if and only if \(t=q\). Conversely, if exactly one state digit is \(1\) in each slot \(t\le q\) and the last state's digit is \(1\) exactly at \(t=q\), both equations hold.

    Proof sketch. In slot \(t\) the digits sum to \(\sum_i\sigma_i(t)\le m<B\), so the sum of the \(S_i\) is computed without carries and its slot-\(t\) digit is \(\sum_i\sigma_i(t)\); comparing with the digit \(1\) of \(F_q\) gives exactly one active state. \(S_{m-1}=B^q\) says the last state's digits are \(0\) except at \(t=q\).

    theorem one_active_state {B q m : ℕ} (hm : m < B) (hm0 : 0 < m) (σ : ℕ → ℕ → ℕ)
    (hσ : ∀ i < m, ∀ t ≤ q, σ i t ≤ 1) :
    (∑ i ∈ range m, ∑ t ∈ range (q + 1), σ i t * B ^ t = ∑ t ∈ range (q + 1), B ^ t ∧
      ∑ t ∈ range (q + 1), σ (m - 1) t * B ^ t = B ^ q) ↔
    (∀ t ≤ q, ∃! i, i < m ∧ σ i t = 1) ∧ (∀ t ≤ q, σ (m - 1) t = 1 ↔ t = q)

    The nonzero indicator is read off one bit per slot of \(R_j+D\), and a sub instruction splits its state history into nonzero and zero branch histories; the increment, decrement and incoming indicators then have zero-one digits.

    TheoremThe packed nonzero indicator#✓fully proved

    ZInQ.Compiler.Packed.nonzero_indicator

    Let \(c>0\), \(K=2^c\), \(B=4K\), \(F_q\), \(D=(K-1)F_q\) be as in the masked-digit statement and \(R=\sum_{t=0}^q\rho_tB^t\) with all \(\rho_t<K\). Then $\((R+D)\mathbin{\mathrm{AND}}(KF_q)=K\cdot\sum_{t=0}^q[\rho_t>0]\,B^t .\)$ Consequently, for \(N\in\mathbb N\), \(KN=(R+D)\mathbin{\mathrm{AND}}(KF_q)\) holds if and only if \(N=\sum_{t\le q}[\rho_t>0]B^t\), the packed nonzero indicator of \(R\); no separate mask condition on \(N\) is needed.

    Proof sketch. \(R+D=\sum_t(\rho_t+K-1)B^t\), and each slot digit satisfies \(\rho_t+K-1\le2K-2<2K<B\), so the sum has no carries. \(KF_q\) has exactly bit \(c\) of each slot \(t\le q\). The bit \(c\) (value \(K\)) of the slot digit \(\rho_t+K-1\in[K-1,2K-2]\) is set exactly when \(\rho_t+K-1\ge K\), that is when \(\rho_t>0\). Cancel the factor \(K=2^c\).

    theorem nonzero_indicator {c q K B F D : ℕ} (_hc : 0 < c) (hK : K = 2 ^ c) (hB : B = 4 * K)
    (hF : F = ∑ t ∈ range (q + 1), B ^ t) (hD : D = (K - 1) * F) (ρ : ℕ → ℕ)
    (hρ : ∀ t ≤ q, ρ t < K) :
    Nat.land (∑ t ∈ range (q + 1), ρ t * B ^ t + D) (K * F) =
        K * ∑ t ∈ range (q + 1), (if 0 < ρ t then 1 else 0) * B ^ t ∧
      ∀ N, K * N = Nat.land (∑ t ∈ range (q + 1), ρ t * B ^ t + D) (K * F) ↔
        N = ∑ t ∈ range (q + 1), (if 0 < ρ t then 1 else 0) * B ^ t

    TheoremBranch histories and indicator digits#✓fully proved

    ZInQ.Compiler.Packed.branch_split ZInQ.Compiler.Packed.indicator_digits

    Let \(B\ge2\), \(q\in\mathbb N\), \(S=\sum_{t\le q}\sigma_tB^t\) and \(N=\sum_{t\le q}\nu_tB^t\) with \(\sigma_t,\nu_t\in\{0,1\}\), \(B\) a power of two.

    1. \(V=S\mathbin{\mathrm{AND}}N\) and \(S=V+W\) hold (for natural \(V,W\)) if and only if \(V=\sum_t\sigma_t\nu_tB^t\) and \(W=\sum_t\sigma_t(1-\nu_t)B^t\).
    2. In the setting of the packed-history construction, suppose that in every slot \(t\le q\) exactly one state digit \(\sigma_i(t)\) is \(1\) and that the halt state has no outgoing instruction. Then the packed indicators \(A_j\), \(C_j\) and \(I_i\) of items 6 and 7 of the construction have all slot digits in \(\{0,1\}\); precisely, writing \(i_t\) for the active state at time \(t\), the slot-\(t\) digit of \(A_j\) is \([p_{i_t}=\mathrm{inc}(j,\cdot)]\), that of \(C_j\) is \([p_{i_t}=\mathrm{dec}(j,\cdot,\cdot)]\,\nu_j(t)\), and that of \(I_i\) is \(1\) exactly when the instruction at \(i_t\) takes, at time \(t\), a branch to \(i\) (the nonzero branch of a sub instruction if \(\nu_j(t)=1\), its zero branch otherwise).

    Proof sketch. (1) Both \(S\) and \(N\) have zero-one digits in distinct bit positions, so \(S\mathbin{\mathrm{AND}}N\) is computed slotwise; \(W=S-V\) slotwise. (2) A sum of packed numbers with zero-one digits is computed slotwise as long as the slot sums stay below \(B\); at time \(t\) only the instruction at \(i_t\) contributes, through \(S_{i_t}\), \(V_{i_t}\) or \(W_{i_t}\), and for a sub instruction exactly one of \(V_{i_t},W_{i_t}\) has digit \(1\) by (1); this holds even if two branches of the program have the same target, since only one branch is taken at a time.

    The register and state equations have all coefficients below \(B\), so uniqueness of base-\(B\) digits turns them into the initial conditions and the exact transitions, the extra final slot vanishing.

    TheoremDecoding the transition equations#✓fully proved

    ZInQ.Compiler.Packed.packed_register_iff ZInQ.Compiler.Packed.packed_state_iff

    Let \(K<B\) be natural numbers and \(q\in\mathbb N\).

    1. (Registers) Let \(\rho_t<K\), \(\alpha_t\le1\), \(\gamma_t\le1\) for \(t\le q\), let \(\iota<K\), and put \(R=\sum_{t\le q}\rho_tB^t\), \(A=\sum_{t\le q}\alpha_tB^t\), \(C=\sum_{t\le q}\gamma_tB^t\). Then $\(R+BC=\iota+BR+BA\)$ holds if and only if \(\rho_0=\iota\), \(\rho_{t+1}+\gamma_t=\rho_t+\alpha_t\) for all \(t<q\), and \(\gamma_q=\rho_q+\alpha_q\).
    2. (States) Suppose \(B\ge2\). Let \(\sigma_t\le1\) and \(\eta_t\le1\) for \(t\le q\), \(S=\sum_{t\le q}\sigma_tB^t\), \(I=\sum_{t\le q}\eta_tB^t\) and \(e\in\{0,1\}\). Then \(S=e+BI\) holds if and only if \(\sigma_0=e\), \(\sigma_{t+1}=\eta_t\) for \(t<q\), and \(\eta_q=0\).

    Proof sketch. Compare base-\(B\) digits. In item 1 the slot-\(0\) digits are \(\rho_0\) and \(\iota\), the slot-\((t+1)\) digits are \(\rho_{t+1}+\gamma_t\le K\) and \(\rho_t+\alpha_t\le K\) for \(t<q\), and the slot-\((q+1)\) digits are \(\gamma_q\) and \(\rho_q+\alpha_q\le K\); every digit on either side is at most \(K<B\), so uniqueness of base-\(B\) expansions (with an unbounded top part) gives digitwise equality, and conversely. Item 2 is the same with digits at most \(1<B\).

    theorem packed_register_iff {B K q ι : ℕ} (hKB : K < B) (ρ α γ : ℕ → ℕ)
    (hρ : ∀ t ≤ q, ρ t < K) (hα : ∀ t ≤ q, α t ≤ 1) (hγ : ∀ t ≤ q, γ t ≤ 1) (hι : ι < K) :
    (∑ t ∈ range (q + 1), ρ t * B ^ t) + B * (∑ t ∈ range (q + 1), γ t * B ^ t) =
        ι + B * (∑ t ∈ range (q + 1), ρ t * B ^ t) + B * (∑ t ∈ range (q + 1), α t * B ^ t) ↔
      ρ 0 = ι ∧ (∀ t < q, ρ (t + 1) + γ t = ρ t + α t) ∧ γ q = ρ q + α q
    theorem packed_state_iff {B q e : ℕ} (hB : 1 < B) (σ η : ℕ → ℕ) (hσ : ∀ t ≤ q, σ t ≤ 1)

    Proof sketch.     TheoremVariable and gadget counts of the packed construction#✓fully proved

    ZInQ.Compiler.Packed.packed_counts

    Let \(p\) be valid for \(r\) registers with \(m\) instructions, of which \(s\) are sub instructions, and \(1\le k\le r\). The packed-history construction of \(p\) creates

    • \(m+r\) mask macros, \(r+s\) bitAnd macros, \(3(r+s)\) orthogonal macros, \(m+4r+3s\) binomial macros, \(m+4r+3s\) odd gadgets and \(2+k+r+2(m+4r+3s)\) strict-inequality gadgets (\(2+k+r\) outside the binomials and two in each binomial);
    • \(2+3(m+4r+3s)=2+3m+12r+9s\) power calls, each with a private block of \(79\) variables;
    • \(2k+9+41r+10m+31s\) explicit variables, the \(k\) inputs included.

    Hence the compiled circuit \(\mathcal C_{p,k}\) has variable count $\(V=(2k+9+41r+10m+31s)+79\,(2+3m+12r+9s).\)$ These counts are independent of the order of the instructions and of the jump targets. The numbers of addition and multiplication nodes depend on hash-consing and on the targets, and are not given in closed form here.

    Proof sketch. Count the allocations of each step of the construction: seven fresh variables \(q,\dots,D\), \(2r\) for \(R_j,N_j\), \(m\) for \(S_i\), \(2s\) for \(V_i,W_i\); each lt, divides and odd gadget takes one variable and each congruent two (only lt and odd occur outside the power template); a binomial takes \(5\) fresh variables, three power calls and two lt gadgets; a mask or orthogonal macro takes one fresh variable, one binomial and one odd gadget; a bitAnd takes two fresh variables and three orthogonals.
