    Recipes and witness accounting

    A natural circuit is translated into a model-evaluation recipe: every variable and node gets a point code, natural variables get the natural template, constants get fixed-scalar templates, and additions, multiplications and power calls get the corresponding templates.

    DefinitionTranslation of a natural circuit into a model-evaluation recipe#✓fully proved

    ZInQ.Syntax.translate ZInQ.Syntax.translate_variableCount

    Natural circuits. A natural circuit has \(k\) inputs, a list of explicit variables \((i_0,\kappa_0),(i_1,\kappa_1),\dots\) (variable index and kind, the inputs first with indices \(0,\dots,k-1\)), a node list whose nodes are \(\mathrm{const}\ c\), \(\mathrm{var}\ i\), \(\mathrm{add}\ j\ j'\), \(\mathrm{mul}\ j\ j'\) or \(\mathrm{call}\ (a,b,c)\ w\) (a call of the power template on three earlier nodes with a private block of \(79\) variables at \(w\)), and a root node. The power template is itself a natural circuit with \(3\) inputs, \(79\) witnesses, no calls, and explicit variables \(0,\dots,81\).

    Translation. Fix the operation templates \(\nu=\mathtt{natural}\), \(\alpha=\mathtt{raw\_add}\), \(\mu=\mathtt{multiply}\) with witness counts \(140604\), \(6\), \(35134\). The translation of a natural circuit with \(k\) inputs, in mode \(\mathrm{value}\) or \(\mathrm{zero}\), with or without natural constraints on the inputs, and with an optional power recipe \(\pi\), is the model-evaluation recipe with \(p=5(k+[\mathrm{value}])\) parameters built by one allocation counter starting at \(p\):

    1. the generator indices \(g_0,g_1,g_2\) take the next three variables;
    2. for each explicit variable in list order: an input \(i\) gets the point reference \(5i\) (inside the parameters), any other variable gets a fresh point (five variables); then, unless it is an input and inputs are unconstrained, a natural block of \(140604\) variables is taken; the row records the reference and the natural start (or none);
    3. each node \(j\) in order gets a point reference \(\mathrm{pt}(j)\): \(\mathrm{var}\ i\) the reference of \(i\); \(\mathrm{const}\ 0\), \(1\), \(-1\) the references \(-1\), \(-2\), \(-3\); any other constant \(c\) (the translation is defined only when every such constant is an integer \(c\ge2\), which holds for both circuits translated here), at its first occurrence in this circuit, a fresh point followed by a block of \(1\), recording the constant definition \((S_{\mathrm{integer\_constant}_h},\text{point},\text{start})\) where \(\mathrm{integer\_constant}_h=c\) (a new index \(h\) is created when \(c\) has not occurred in any earlier translation), and later occurrences reuse that point; \(\mathrm{add}\ j_1\ j_2\) and \(\mathrm{mul}\ j_1\ j_2\) nodes a fresh point followed by a block of \(6\) or \(35134\), recording the operation \((0\text{ or }1,\ \mathrm{pt}(j_1),\ \mathrm{pt}(j_2),\ \text{point},\ \text{start})\); a \(\mathrm{call}\ (a,b,c)\ w\) a fresh point followed by a block of the witness count of \(\pi\), recording \((2,\mathrm{pt}(a),\mathrm{pt}(b),\mathrm{pt}(c),\text{point},\text{start})\); the source block at \(w\) is not used;
    4. the root equality is \((\mathrm{pt}(\mathrm{root}),5k)\) in value mode and \((\mathrm{pt}(\mathrm{root}),-1)\) in zero mode;
    5. the variable count is the final counter.

    The polynomial of the result is given by the semantics of model-evaluation recipes: the three generator constraints, the natural calls, the constant definitions (each a fixed-scalar template on \((\mathrm{ref}(-2),\text{point})\)), the operation calls and the five root differences, squared and summed.

    Equivalently, the translation takes the table of nontrivial constants as an argument, listed in order of first occurrence across the translations: \((4,2,3)\) for power_value and \((4,2,3,c_3,1399)\) for precision, a constant \(c\) using the fixed-scalar template of its position in the table.

    This is a definition. The arithmetic meaning (every node point is the code of the node's signed integer value) is the compiler chapter's rational translation statement.

    The recipe \(\mathtt{precision}\) is the translation of the five-input natural precision polynomial in zero mode, with natural constraints on the inputs and with power recipe \(\mathtt{power\_value}\), performed after the translation of the power template (so the constants \(4,2,3\) keep their indices \(0,1,2\)).     Five composition recipes assemble the value relation and the root.

    DefinitionThe outer composition recipes#✓fully proved

    ZInQ.Syntax.closeRecipe ZInQ.Syntax.mainRecipe ZInQ.Syntax.valueUnionRecipe ZInQ.Syntax.valueRecipe ZInQ.Syntax.integersRecipe

    Five composition recipes assemble the ordinary-value relation; each is built with one allocation counter starting at its parameter count, fresh ranges first, then the calls in order. Write \(\mathbf X_a=(X_a,\dots,X_{a+4})\).

    1. \(\mathtt{close}\) (sum of squares), parameters \(N=\mathbf X_0\), \(K=\mathbf X_5\), \(t=X_{10}\). Fresh points \(A=\mathbf X_{11}\), \(L=\mathbf X_{16}\), \(J=\mathbf X_{21}\) and \(E_0,\dots,E_4=\mathbf X_{26},\mathbf X_{31},\dots,\mathbf X_{46}\). Calls: \(\mathtt{value.signed\_encode}[\Sigma_i,E_i]\) for \((\Sigma_0,\dots,\Sigma_4)=(N,K,A,L,J)\) (starts \(51+140654i\)); \(\mathtt{precision}[E_0,\dots,E_4]\) (start \(703321\)); \(\mathtt{value.close\_coordinates}[A,L,J,t]\) (start \(292890196157\)). \(11\) parameters, \(292890196199\) witnesses.
    2. \(\mathtt{main}\) (sum of squares), parameters \(N=\mathbf X_0\), \(t=X_5\). Fresh point \(K=\mathbf X_6\). Calls: \(\mathtt{close}[N,K,t]\) (start \(11\)) and \(\mathtt{value.test}[N,K,t]\) (start \(292890196210\)). \(6\) parameters, \(292890231486\) witnesses.
    3. \(\mathtt{value\_union}\) (product), parameters \(N=\mathbf X_0\), \(t=X_5\). Calls: \(\mathtt{value.exceptions}[N,t]\) (start \(6\)) and \(\mathtt{main}[N,t]\) (start \(412\)). \(6\) parameters, \(292890231892\) witnesses.
    4. \(\mathtt{value}\) (sum of squares), parameters \(N=\mathbf X_0\), \(t=X_5\). Calls: \(\mathtt{member}[N]\) (start \(6\)) and \(\mathtt{value\_union}[N,t]\) (start \(13\)). \(6\) parameters, \(292890231899\) witnesses.
    5. \(\mathtt{integers}\) (sum of squares), parameter \(t=X_0\). Fresh point \(N=\mathbf X_1\). Call: \(\mathtt{value}[N,t]\) (start \(6\)). \(1\) parameter, \(292890231904\) witnesses.

    Thus, with call polynomials as in the semantics of recipes, $\([\![\mathtt{integers}]\!]=\mathtt{value}[X_1,\dots,X_5,X_0;6]^2,\qquad [\![\mathtt{value}]\!]=\mathtt{member}[\mathbf X_0;6]^2+\mathtt{value\_union}[\mathbf X_0,X_5;13]^2,\)$ $\([\![\mathtt{value\_union}]\!]=\mathtt{value.exceptions}[\mathbf X_0,X_5;6]\cdot\mathtt{main}[\mathbf X_0,X_5;412],\)$ and similarly for \(\mathtt{main}\) and \(\mathtt{close}\). The same coordinates of \(K\) occur in \(\mathtt{close}\) and \(\mathtt{value.test}\); the exceptional branch and the main branch have disjoint private blocks.

    The starts and witness counts from the precision call on are those for a precision recipe with \(292{,}889{,}492{,}836\) witnesses, the bound of the precision recipe; in general each of them shifts with the witness count of the recipe called (for instance \(\mathtt{close}\) has \(703310+w+53\) witnesses when precision has \(w\)), so the displayed values are upper bounds.
