    From the Rédei matrix to Rédei's bits

    For an odd number \(d\) and a nonempty set \(B\) of its primes, the Rédei matrix of \(d_B\) is the Laplacian \(L_B\) of the bits \(a_{qp}=[p/q]\) of \(d\), bordered by the column \(z_B\) exactly when \(y(B)=0\). Its kernel is \(\{0,e_{d_B}\}\) exactly when \(g_d(B)=1\). The first two articles prove the last statement for arbitrary bits satisfying reciprocity; the others identify the Rédei matrix of \(\mathbb Q(\sqrt{-d_B})\) with the bits, and deduce Rédei's formula from the 4-rank statement.

    Let \(V\) be a finite set with bits \(a_{ij},y_i,z_i\in\mathbb F_2\) on \(V\) satisfying reciprocity, as in Rédei's \(g\) from the bits. Let \(B\subseteq V\), \(\rho\in B\), \(y(B)=\sum_{i\in B}y_i\), and let \(L_B\) be the Laplacian of \(a\) on \(B\). Say that the kernel of \((L_B\mid z_B)\) is trivial if the following holds: for every \(e:V\to\mathbb F_2\) vanishing off \(B\) and every \(e_2\in\mathbb F_2\) with \(e_2=0\) when \(y(B)=1\), if $\(\sum_{p\in B}(L_B)_{qp}e_p+e_2z_q=0\quad\text{for every }q\in B,\)$ then \(e_2=0\) and \(e\) is constant on \(B\) (identically \(0\) or identically \(1\) there). So the column \(z_B\) counts only when \(y(B)=0\).

    Let \(w=y\) if \(y(B)=1\) and \(w=z\) otherwise, and let \(N\) be \(L_B\) with its column \(\rho\) replaced by \(w\). Then the kernel of \((L_B\mid z_B)\) is trivial if and only if every \(F:V\to\mathbb F_2\) vanishing off \(B\) with \(\sum_{p\in B}N_{qp}F_p=0\) for all \(q\in B\) vanishes on \(B\).

    Along the way, without reciprocity:

    • the rows of \(L_B\) sum to zero over \(B\): \(\sum_{p\in B}(L_B)_{qp}=0\) for \(q\in B\);
    • splitting off the column \(\rho\): \(\sum_{p\in B}N_{qp}F_p=\sum_{p\in B}(L_B)_{qp}F'_p+w_qF_\rho\), where \(F'\) is \(F\) with \(F'_\rho=0\);
    • every element of \(\mathbb F_2\) is \(0\) or \(1\).

    Proof sketch. (⇒) Let \(F\) vanish off \(B\) with \(\sum_pN_{qp}F_p=0\) on \(B\). Put \(e=F\) with \(e_\rho=0\), and \(e_2=F_\rho\), so that \(L_Be+F_\rho w=0\) on \(B\).

    • If \(y(B)=1\), sum over \(q\in B\). Under reciprocity the column sums of \(L_B\) over \(B\) are \(y_v(1+y(B))=0\), while \(\sum_{q\in B}w_q=y(B)=1\), so \(F_\rho=0\).
    • In either case the triviality of the kernel applies (with \(w=z\) when \(y(B)=0\)). It gives \(e_2=0\) and \(e\) constant on \(B\), and \(e_\rho=0\), so \(F=0\) on \(B\).

    (⇐) Given \((e,e_2)\), replace \(e\) by \(e-e_\rho\) on \(B\); this does not change \(L_Be\) on \(B\), since the rows of \(L_B\) sum to zero. Set its value at \(\rho\) to \(e_2\) and call the result \(F\). Then \(\sum_pN_{qp}F_p=0\) on \(B\) (when \(y(B)=1\) because \(e_2=0\), when \(y(B)=0\) because \(w=z\)), so \(F=0\) on \(B\): \(e_2=0\), and \(e=e_\rho\) is constant on \(B\).

    Let \(V\) be a finite set with bits \(a_{ij},y_i,z_i\in\mathbb F_2\) satisfying reciprocity, and let \(B\subseteq V\) be nonempty. Then the kernel of \((L_B\mid z_B)\) is trivial (the column \(z_B\) counting only when \(y(B)=0\)) if and only if \(g(B)=1\), where $\(g(B)=\sum_{\rho\in B}y_\rho\,\kappa_\rho(B)\ \text{ if }y(B)=1,\qquad g(B)=\sum_{\rho\in B}z_\rho\,\kappa_\rho(B)\ \text{ if }y(B)=0,\)$ and \(\kappa_\rho(B)=\det L_B[B\setminus\rho,B\setminus\rho]\).

    Along the way, without reciprocity:

    • for \(\rho\in B\) and any \(w:V\to\mathbb F_2\), the matrix \(L_B\) with column \(\rho\) replaced by \(w\) has determinant \(\sum_{v\in B}w_v\,\kappa_v(B)\) on \(B\times B\);
    • a square matrix \(N\) on \(B\) has trivial kernel, in the sense that every \(F:V\to\mathbb F_2\) vanishing off \(B\) with \(\sum_{p\in B}N_{qp}F_p=0\) for all \(q\in B\) vanishes on \(B\), if and only if its determinant on \(B\times B\) is nonzero.

    Proof sketch. Fix \(\rho\in B\), let \(w=y\) if \(y(B)=1\) and \(w=z\) otherwise, and let \(N\) be \(L_B\) with column \(\rho\) replaced by \(w\). By the kernel through a square matrix, the kernel of \((L_B\mid z_B)\) is trivial if and only if \(N\) has trivial kernel on \(B\), that is, \(\det N\ne0\). Expanding \(\det N\) along column \(\rho\), the minor of \(L_B\) with row \(v\) and column \(\rho\) deleted is \(\kappa_v(B)\) (Lemma 2.2(2)), so \(\det N=\sum_{v\in B}w_v\kappa_v(B)\), which is \(g(B)\) by its definition. In \(\mathbb F_2\), nonzero means \(1\).

    Let \(d\) be a natural number, \(B\) a set of primes of \(d\) and \(d_B=\prod_{p\in B}p\). Then:

    • the primes of \(d_B\) are exactly the elements of \(B\), and \(d_B\) is squarefree;
    • if \(B\) is nonempty, then \(d_B>1\);
    • for \(q\in B\), \(d_B/q=\prod_{k\in B,\,k\ne q}k\);
    • every element of \(B\) lies in \(T_{d_B}\), and every element of \(T_{d_B}\) is \(2\) or an element of \(B\).

    If \(d\) is odd, then moreover:

    • the primes of \(d\) are different from \(2\), so \(2\) is not a prime of \(d_B\) and \(d_B\) is odd;
    • \(2\in T_{d_B}\) if and only if \(d_B\not\equiv3\pmod4\);
    • \(y(B)=\sum_{q\in B}y_q=1\) if and only if \(d_B\equiv3\pmod4\).

    Proof sketch. \(d_B\) is a product of distinct primes, so its primes are the elements of \(B\) and it is squarefree; the statements about \(T_{d_B}\) follow from its definition. For odd \(d\), \(y(B)\) is \(\lambda(d_B)=[d_B\equiv3\pmod4]\), by the multiplicativity of \(\lambda\) on odd residues modulo \(8\).

    Let \(d\) be odd, \(B\) a set of primes of \(d\), \(R\) the Rédei matrix of \(d_B\), and \(L_B\) the Laplacian on \(B\) of the bits \(a_{qp}=[p/q]\) of \(d\). For \(q\in B\) and every function \(F\) from the natural numbers to \(\mathbb F_2\), $\(\sum_{p\in T_{d_B}}R_{qp}F(p)=\sum_{p\in B}(L_B)_{qp}F(p)+\begin{cases}0,&d_B\equiv3\pmod4,\\ z_qF(2),&\text{otherwise.}\end{cases}\)$ More precisely, for \(q\in B\) and every prime \(p\) of \(d\), the entry given by the formula of the Rédei matrix of \(d_B\), namely \([p/q]\) for \(p\ne q\) and \([(d_B/q)/q]\) for \(p=q\), equals \((L_B)_{qp}\).

    Proof sketch. The off-diagonal entries are \([p/q]=a_{qp}=(L_B)_{qp}\). On the diagonal, \(d_B/q=\prod_{k\in B,\,k\ne q}k\), and the other primes of \(B\) are prime to \(q\), so by the multiplicativity of the residue bit \([(d_B/q)/q]=\sum_{k\in B,\,k\ne q}[k/q]=(L_B)_{qq}\). That holds if and only if the kernel of \((L_B\mid z_B)\) is trivial for the bits of \(d\). These bits satisfy reciprocity because \(d\) is odd, so the kernel is trivial if and only if \(g_d(B)=1\).
