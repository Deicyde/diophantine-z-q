    The 4-rank

    Let \(n>1\) be odd and squarefree, \(t=|T_n|\), and let \(\chi:\mathrm{Cl}\to\mathbb F_2^{\{q\mid n\}}\) be the genus map, \(c\mapsto(\chi_q(c))_q\). Counting gives $\([\mathrm{Cl}:\mathrm{Cl}^2]=|\mathrm{Cl}[2]|\le2^{t-1}\le|\mathrm{im}\,\chi|=[\mathrm{Cl}:\ker\chi]\le[\mathrm{Cl}:\mathrm{Cl}^2],\)$ so the principal genus theorem \(\mathrm{Cl}^2=\bigcap_q\ker\chi_q\) holds and \(|\mathrm{Cl}[2]|=2^{t-1}\). Since \(g(n)=|\mathrm{Cl}^2|\) is odd exactly when \(\mathrm{Cl}[2]\cap\mathrm{Cl}^2=1\), Rédei's theorem follows: \(g(n)\) is odd if and only if the kernel of the Rédei matrix is \(\{0,e_n\}\), where \(e_n\) is the exponent vector of \((\sqrt{-n})\).

    Let \(G\) be a finite commutative group, \(G^2=\{x^2:x\in G\}\) its subgroup of squares and \(G[2]=\{x\in G:x^2=1\}\) its 2-torsion. Then \(|G^2|\) is odd if and only if \(G[2]\cap G^2=1\).

    Moreover every commutative group \(G\) satisfies \(|G[2]|\cdot|G^2|=|G|\), where an infinite group is given order \(0\).

    Proof sketch. If \(|G^2|\) is odd, an element of \(G[2]\cap G^2\) has order dividing \(2\) and, as an element of \(G^2\), dividing \(|G^2|\), so it is trivial. If \(|G^2|\) is even, Cauchy's theorem gives an element of order \(2\) in \(G^2\), and it lies in \(G[2]\cap G^2\). The identity is the first isomorphism theorem for the homomorphism \(x\mapsto x^2\), whose kernel is \(G[2]\) and whose image is \(G^2\).

    For \(n\ge1\) the genus map of \(\mathbb Q(\sqrt{-n})\) is the homomorphism $\(\chi:\mathrm{Cl}\to\mathbb F_2^{\{q\mid n\}},\qquad c\mapsto(\chi_q(c))_q,\)$ indexed by the primes \(q\mid n\). Let \(n>1\) be odd and squarefree and \(t=|T_n|\). Then the image of the genus map has at least \(2^{t-1}\) elements.

    Along the way:

    • every \(n>1\) has a prime factor;
    • for odd \(n\) with \(r\) prime factors, \(t=r\) if \(n\equiv3\pmod4\) and \(t=r+1\) otherwise;
    • for a nonempty finite set \(I\), the hyperplane \(\{e\in\mathbb F_2^I:\sum_ie_i=0\}\), the kernel of the sum map \(\mathbb F_2^I\to\mathbb F_2\), has \(2^{|I|-1}\) elements.

    Proof sketch. Let \(r\ge1\) be the number of primes of \(n\).

    • If \(n\equiv3\pmod4\), then \(t=r\). The genus characters take every value with \(\sum_q\varepsilon_q=0\), so the image of \(\chi\) contains the sum-zero hyperplane, which has \(2^{r-1}\) elements.
    • Otherwise \(t=r+1\), since \(2\) is not a prime of \(n\). The genus characters take every value, so the image of \(\chi\) is all of \(\mathbb F_2^r\), which has \(2^r=2^{t-1}\) elements.

    Let \(n>1\) be odd and squarefree, \(\mathrm{Cl}\) the class group of \(\mathbb Q(\sqrt{-n})\) and \(t=|T_n|\). Then the subgroup of squares is the intersection of the kernels of the genus characters, $\(\mathrm{Cl}^2=\bigcap_{q\mid n}\ker\chi_q,\)$ which is the kernel of the genus map, and \(|\mathrm{Cl}[2]|=2^{t-1}\).

    Along the way:

    • for every \(n\ge1\), a class lies in the kernel of the genus map exactly when \(\chi_q\) vanishes on it for every prime \(q\mid n\), and \(\mathrm{Cl}^2\) lies in that kernel, since every element of \(\mathbb F_2\) has \(2x=0\);
    • natural numbers with \(a\le b\), \(c\le d\), \(b,c>0\) and \(ac=bd\) satisfy \(a=b\) and \(c=d\).

    Proof sketch. The genus characters take values in \(\mathbb F_2\), so \(\mathrm{Cl}^2\subseteq\ker\chi\). Count: $\(|\mathrm{Cl}^2|\cdot|\mathrm{Cl}[2]|=|\mathrm{Cl}|=|\ker\chi|\cdot|\mathrm{im}\,\chi|.\)$ Here \(|\mathrm{Cl}^2|\le|\ker\chi|\), and \(|\mathrm{Cl}[2]|\le2^{t-1}\le|\mathrm{im}\,\chi|\) by the bound on the 2-torsion and the number of genera. The arithmetic fact above gives \(|\mathrm{Cl}^2|=|\ker\chi|\), hence \(\mathrm{Cl}^2=\ker\chi\), and \(|\mathrm{Cl}[2]|=|\mathrm{im}\,\chi|\), hence \(|\mathrm{Cl}[2]|=2^{t-1}\). This is the classical count of genera, with the principal genus theorem obtained by counting.

    DefinitionThe 4-rank statement#✓fully proved

    ZInQ.RouteK.Redei.OddGClStatement

    The 4-rank statement is the following assertion. For every odd squarefree \(n>1\), the genus class number \(g(n)\) is odd if and only if every \(e\in\mathbb F_2^{T_n}\) with $\(\sum_{p\in T_n}R_{qp}\,e_p=0\quad\text{for every prime }q\mid n\)$ is \(0\) or \(e_n\). Here \(R\) is the Rédei matrix of \(n\), and \(e_n\in\mathbb F_2^{T_n}\) is \(1\) at the primes of \(n\) and \(0\) at \(2\); it is the exponent vector of the ideal \((\sqrt{-n})\).

    The hypothesis \(n>1\) is needed. For \(n=1\) the class group of \(\mathbb Q(i)\) is trivial (a classical fact), so \(g(1)=1\) is odd. But \(T_1=\{2\}\), the Rédei matrix has no rows and \(e_1=0\), so the nonzero vector at \(2\) is killed by it.

    def OddGClStatement : Prop :=
  ∀ (n : ℕ) [NeZero n], Odd n → Squarefree n → 1 < n →
    (Odd (gCl n) ↔ ∀ e : ramSet n → ZMod 2, (∀ q, ∑ p, redeiEntry n q p * e p = 0) →
      e = 0 ∨ e = fun p : ramSet n => if (p : ℕ) ∈ n.primeFactors then (1 : ZMod 2) else 0)

    TheoremRédei's theorem on the 4-rank#✓fully proved

    ZInQ.RouteK.Redei.oddGClStatement ZInQ.RouteK.Redei.odd_gCl_iff ZInQ.RouteK.Redei.fourRankVec ZInQ.RouteK.Redei.fourRankVec_ne_zero

    The 4-rank statement holds: for every odd squarefree \(n>1\), the genus class number \(g(n)=|\mathrm{Cl}(\mathbb Q(\sqrt{-n}))^2|\) is odd if and only if every vector \(e\in\mathbb F_2^{T_n}\) killed by the Rédei matrix of \(n\) is \(0\) or \(e_n\). Here \(e_n\) is \(1\) at the primes of \(n\) and \(0\) at \(2\), and it is nonzero for \(n>1\).

    Proof sketch. By the principal genus theorem and the values of the genus characters on the ambiguous classes, \(\psi(e)\in\mathrm{Cl}^2\) if and only if \(\sum_pR_{qp}e_p=0\) for every prime \(q\mid n\). Also \(\psi(e_n)=1\), the image of \(\psi\) is \(\mathrm{Cl}[2]\), and \(g(n)=|\mathrm{Cl}^2|\) is odd if and only if \(\mathrm{Cl}[2]\cap\mathrm{Cl}^2=1\).

    • If \(g(n)\) is odd and \(e\) is killed by \(R\), then \(\psi(e)\in\mathrm{Cl}[2]\cap\mathrm{Cl}^2=1\). So \(e\in\ker\psi\), which has two elements and contains \(0\) and \(e_n\ne0\); hence \(e\in\{0,e_n\}\).
    • Conversely, an element of \(\mathrm{Cl}[2]\cap\mathrm{Cl}^2\) is \(\psi(m)\) with \(m\) killed by \(R\). So \(m\in\{0,e_n\}\), and \(\psi(m)=1\).
