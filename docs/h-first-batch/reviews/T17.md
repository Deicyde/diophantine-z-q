## 3. Statement fidelity (scope only)

My initial reconstruction was frozen before I read any author notes: `R/00-initial-reconstruction.md`, `178d18bf…1e03`. The checks below confirm it. No point was refuted.

1. **"Abelian extension of ℚ" = `[NumberField L] [IsGalois ℚ L]` + pairwise-commuting `L ≃ₐ[ℚ] L`.**
   * "Finite" comes from `NumberField`: char 0 plus `FiniteDimensional ℚ L`.
   * This is exactly Mathlib's `IsAbelianGalois ℚ L`. My `t17rev_isAbelianGalois_iff` checks this independently, and the packet's `isAbelianGalois_iff_comm` checks it too.
   * Milne's "abelian extension" in both sentences above is a finite abelian extension. It has a conductor (V.3.10) and is a class field of a ray class group (Thm 0.5).
2. **"Contained in a cyclotomic field" vs `Nonempty (L →ₐ[ℚ] CyclotomicField n ℚ)`.**
   * A ℚ-algebra map out of a field is injective, so L is ℚ-isomorphic to a subfield of `CyclotomicField n ℚ`.
   * `CyclotomicField n ℚ` is normal over ℚ. So for any fixed embedding into an algebraic closure, every embedding of L lands inside the copy of ℚ(ζ_n), and conversely.
   * Hence the abstract-embedding form is equivalent to the concrete inclusion form. No algebraic-closure transport has to be stated.
3. **Level n positive (`ℕ+`).** Mathlib allows n = 0: `cyclotomic 0 = 1`, so `CyclotomicField 0 ℚ` is a trivial splitting field (checked: `cyclotomic_zero`, L687). Allowing n = 0 would add nothing, because ℚ already embeds at n = 1. The `ℕ+` witness matches Tau Ceti's `n ≠ 0` exactly (§5).
4. **Trivial or exceptional L.** L = ℚ, or any degree-1 L, is witnessed at n = 1 by `Algebra.ofId` (checked). The hypotheses are non-vacuous: ℚ and every `CyclotomicField n ℚ` satisfy them (checked).
5. **Direction and content.** The statement is pure existence of an embedding. It makes no claim about a minimal conductor, an explicit n, or the Artin map. This matches the published statement and Tau Ceti.

## 4. Caveats to carry into registration (none of them change the mathematics)

* **C1 — Universe.** `L : Type` (universe 0) only. Every number field is isomorphic to one in `Type`, so mathematically nothing is lost. Formally it is a specialization, and should not be described as universe-polymorphic. Tau Ceti uses `E : Type` too, so they match.
* **C2 — Algebra-map carrier (actual elaborated instance).** In `L →ₐ[ℚ] CyclotomicField (n:ℕ) ℚ`, the codomain's ℚ-algebra elaborates to **`DivisionRing.toRatAlgebra`**, not `CyclotomicField.algebra` (`pp.explicit` output, run 1).
  * The two are equal by `Subsingleton.elim`, and are definitionally equal at default transparency (`rfl` passes, run 2).
  * They are **not** equal at reducible-and-instances transparency (run 1). As a result, `IsCyclotomicExtension {n} ℚ (CyclotomicField n ℚ)` and `IsAbelianGalois ℚ (CyclotomicField n ℚ)` are **not found by instance search** against the target's instance.
  * Providers must supply `CyclotomicField.isCyclotomicExtension n ℚ` explicitly, or transport by `Subsingleton.elim`. Tau Ceti L166–169 documents and handles exactly this, and the packet's `Embedding.lean` does the same.
  * This does not affect fidelity: any two ℚ-algebra structures on a ring coincide.
* **C3 — Locator wording.** The target docstring cites "Washington Thm 14.1". I did not open it. The verified public statement is Milne CFT v4.03, Intro p. 6 and V Ex. 3.10, which agree with the target. Recommend recording Washington as UNVERIFIED and adding the Milne locator.
* **C4 — Tau Ceti's own citations are off for v4.03.** Its header cites "Milne CFT v4.03, Ch. V Example 3.11, and Ch. VIII Theorem 3.4".
  * In the v4.03 PDF I read, KW is **Example 3.10** (p. 159). Example 3.11 is the conductor of ℚ(√d).
  * On pp. 234–236, "3.4" in Ch. VIII is **Lemma 3.4** on quadratic forms, not a KW theorem. I did not read all of Ch. VIII.
  * Do not copy those locators.
