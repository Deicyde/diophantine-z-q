## 2. Exact target (frozen before reading any PR #42 notes; `INITIAL.md`/`INITIAL.json`)

```
def ZInQ.Targets.H.T13 : Prop :=
∀ (K A B : Type) [inst : Field K] [inst_1 : Ring A] [inst_2 : Algebra K A] [Algebra.IsCentral K A] [IsSimpleRing A]
  [FiniteDimensional K A] [inst_6 : Ring B] [inst_7 : Algebra K B] [IsSimpleRing B] [FiniteDimensional K B]
  (f g : B →ₐ[K] A), ∃ (x : Aˣ), ∀ (b : B), g b = ↑x * f b * ↑x⁻¹
```

* The target is a closed `Prop` with `levelParams = []`. All carriers are in `Type`. `#print axioms` gives only
  the three standard axioms.
* The fully explicit elaboration was checked:
  * `Algebra.IsCentral` is Mathlib's `Subalgebra.center K A ≤ ⊥`.
  * `IsSimpleRing` is Mathlib's `IsSimpleOrder (TwoSidedIdeal _)` (two-sided simplicity, which implies
    nontriviality).
  * `FiniteDimensional` goes through `Algebra.toModule`.
  * `x⁻¹` is the inverse in `Aˣ` (`Units.instInv`), coerced by `Units.val`.
  * `f` and `g` are unital `AlgHom`s.
  * `open HSyn` has no effect on T13: HSyn shadows none of the names used.
* **Hypotheses:**
  * K is any field. There is no characteristic, perfectness or separability condition.
  * A is a central simple, finite-dimensional K-algebra.
  * B is a simple, finite-dimensional K-algebra. It is **not** assumed central or separable.
  * f and g are arbitrary, with no surjectivity assumed.
* **Faithfulness:** the T13 body is textually identical to `HSyn.SkolemNoether` (reference lines 8987–8990 at
  `48b5f07`). It is also identical to `HSyn.SkolemNoether` at revision `533aa66` (line 12050), which the PR cites.
* **Orientation and degenerate cases:**
  * `g b = x f(b) x⁻¹` is equivalent to the `x⁻¹ f(b) x` form (replace x by x⁻¹), and the statement is symmetric
    in f and g. Both facts are Lean-checked, so orientation does not affect truth.
  * The zero ring is excluded by `IsSimpleRing`.
  * For scalars (B = K), x = 1 works.
  * For A = K, f is injective, so B ≅ K and f = g.
  * Tensor products and opposites occur only inside the proof.
  * Non-vacuity with a **non-central** source was Lean-checked: K = ℝ, B = ℂ (simple, finite-dimensional, proved
    not central), A = M₂(ℝ) (central simple). The proof applies.
  * The ambient-centrality hypothesis is necessary (Lean-checked): A = B = ℂ over ℝ with `id` and conjugation is
    not inner.
* **Baseline identity:** `ZInQ.Targets.H.T13 = PkgI6.SkolemNoether` holds by `rfl` (Lean-checked). The baseline
  leaf in `ZInQKernel/HDecomp/Conductor/I6Base.lean` (SHA-256
  `3a2688e5271203cb1d28663fefe3c017426a43dd4c5f4a710f0dabe6de96ce2d`, unchanged on main) is the same proposition.

## 3. Proof review (PR #42)

Mathematical route, reconstructed from the code. It is the classical module-theoretic proof, with centrality
supplied by the **ambient** algebra:

1. **TensorCoordinates.** Proves coordinate formulas for `(a⊗1)·x` and `x·(a⊗1)` in an `A`-basis of `A ⊗ B`, and
   `forall_commute_tmul_one_iff`. If A is central, the centralizer of `A⊗1` is `1⊗B`. The proof uses Mathlib's
   `Subalgebra.centralizer_coe_range_includeLeft_eq_center_tensorProduct`.
2. **TensorSimple.** Proves `tensorProduct_simple`: (central simple) ⊗ (simple) is simple, with no
   finite-dimensionality. The argument takes a minimal-support element, rescales one coordinate to 1, kills the
   commutators, gets `1⊗b`, and pulls back to B. `tensorProduct_simple_right` transports this along
   `Algebra.TensorProduct.comm`.
3. **ModuleClassification.** Over a finite-dimensional simple K-algebra R, finite modules with the same K-dimension
   are R-isomorphic. Both are powers of one minimal left ideal, and its positive dimension cancels.
4. **Bimodule.** `Bimodule f` is a type synonym for A carrying the `B ⊗ Aᵐᵒᵖ` action `b⊗op a : x ↦ f(b)·x·a`, defined
   through `AlgHom.mulLeftRight ∘ map f id`. An R-linear map φ is left multiplication by `u = φ(1)`, and
   `u f(b) = g(b) u`. If 1 is in the range of φ, then u has a right inverse.
5. **Basic.** The acting ring is exactly `R = B ⊗[K] Aᵐᵒᵖ`.
   * R is simple by step 2 with the **right** factor `Aᵐᵒᵖ` central simple. This uses Mathlib's instances
     `Algebra.IsCentral K Dᵐᵒᵖ` (`Mathlib/Algebra/Central/Basic.lean`) and `IsSimpleRing Rᵐᵒᵖ`
     (`Mathlib/RingTheory/SimpleRing/Basic.lean`). Centrality of B is never used.
   * Equal K-dimensions give φ.
   * A is Artinian, hence Dedekind-finite, so `uv = 1` yields a two-sided unit.
   * `g b = u f(b) u⁻¹` is exactly the target orientation.
   * `t13` restates the closed quantified proposition at `Type`. `skolemNoether` is the universe-polymorphic
     version, which is stronger than needed.

**Comparison with the sources.** Tau Ceti's `TauCeti.skolemNoether` (line 105 at the pinned revision) assumes
`Algebra.IsCentral K B` on the **source**. Its docstring (lines 68–73) says the ambient-central / simple-source form
"needs the centralizer theorem and is not formalised here". That remark is over-cautious. Tau Ceti's own
`tensorProduct_of_isCentral_right` (lines 225–227 of `TauCeti/Algebra/CentralSimple/TensorProduct.lean`) together with
centrality of `Aᵐᵒᵖ` gives simplicity of `B ⊗ Aᵐᵒᵖ`, and the PR's proof is this route. The kernel check confirms it.
The adapted proof scripts in TensorSimple and ModuleClassification were diffed against upstream. They are the same
proofs with namespace and comment changes. ModuleClassification assumes `FiniteDimensional K R` rather than deriving
it, and Basic supplies that fact. Mathlib at the pin has no Skolem–Noether theorem.
