Statement (as elaborated, `#print`):
```
∀ (L : Type) [Field L] [NumberField L] (p : ℕ), Nat.Prime p →
  ∀ (P : Ideal (𝓞 L)) [P.IsPrime], P.LiesOver (Ideal.span {↑p}) →
    ¬ P ^ (P.ramificationIdx ℤ - 1 + P.ramificationIdx ℤ * padicValNat p (P.ramificationIdx ℤ) + 1)
        ∣ differentIdeal ℤ (𝓞 L)
```
i.e. `v_P(𝔇_{𝓞_L/ℤ}) ≤ e − 1 + e·v_p(e)` with `e = e(P|p)`.

## 2. Sources actually opened

1. MIT 18.785 Number Theory I, Fall 2021, Lecture #12 notes ("The different and the discriminant"),
   public OCW PDF `https://ocw.mit.edu/courses/18-785-number-theory-i-fall-2021/mit18_785f21_lec12.pdf`,
   **Theorem 12.27**: "Assume AKLB and let q be a prime of L lying above p = q∩A for which the residue
   field extension (B/q)/(A/p) is separable. Then e_q − 1 ≤ v_q(D_{B/A}) ≤ e_q − 1 + v_q(e_q), and the
   lower bound is an equality iff q is tamely ramified." (Proof deferred to a problem set.)
   AKLB = A Dedekind, K = Frac A, L/K finite separable, B integral closure: this is a **global
   Dedekind statement**; with A = ℤ, B = 𝓞_L (residue fields finite ⇒ separable) it is T21 verbatim
   up to `v_q(e) = e·v_p(e)`.
2. K. Conrad, "The different ideal" (expository notes; canonical URL
   `https://kconrad.math.uconn.edu/blurbs/gradnumthy/different.pdf`, read through a cached copy;
   revision date not shown in the cached text), Section 4, paragraph "(1) Upper and lower bounds":
   `e − 1 ≤ ord_p(D_K) ≤ ord_p(e) + e − 1`, `e = e_p(K/Q)`, and explicitly
   `ord_p(e) = e·ord_p(e)` (prime number p) so the upper bound is `(ord_p(e)+1)e − 1`. Attribution:
   lower bound Dedekind (Conrad's Thm 4.13), upper bound conjectured by Dedekind and proved by
   Hensel (Conrad's references [3], [6]). This is **exactly** T21's exponent:
   `¬P^{e(1+v_p(e))} ∣ 𝔇`.
3. Serre, *Local Fields* III §6 (remark after Prop. 13): Google Books pages opened returned only the
   blurb; the cited remark text was **not** seen. Locator stays UNVERIFIED. Recommendation: cite
   (1)+(2) (and Hensel 1894 via Conrad) for the global statement; keep Serre as the local-form
   citation for `PkgI6.DifferentBound` with the UNVERIFIED tag until someone reads the page.

Hypothesis check vs. sources: both sources need only separable residue extension (automatic for
number fields) and separable L/K (char 0). No source requires Galois, tame, or complete fields for
the global statement. Index-set coverage: all `L : Type`, all primes p, all P | p — matches.

## 5. Local → global transport: what the closed local leaf supplies vs. what T21 needs

`PkgI6.DifferentBound` (local): for complete DVR `A` (perfect residue field), DVR `B` finite,
torsion-free, separable over `A`: `differentIdeal A B ∣ 𝔪_B^(e−1) · (e)` with
`e = ramificationIdx 𝔪_B A`. It supplies exactly the local inequality `v_B(𝔇_{B/A}) ≤ e−1+v_B(e)`.
(Its equal-characteristic `p | e` case is vacuous, `(e)=⊥`, which matches `v(e)=∞`; irrelevant for T21.)

Required transport items for T21 (none provided by pinned Mathlib):
* **G1 instances at the completion**: `A := ℤ_[p]` (or `adicCompletionIntegers ℚ (p)`),
  `B := adicCompletionIntegers L P`; need `Algebra A B`, `Module.Finite A B`, `IsTorsionFree`,
  `IsDomain`, `Algebra.IsSeparable (FractionRing A) (FractionRing B)`, `PerfectField (ResidueField A)`
  (finite field), all at universe `Type` (OK: completions of `L : Type` stay in `Type`).
* **G2 ramification index**: `ramificationIdx 𝔪_B ℤ_[p] = P.ramificationIdx ℤ` (length over the
  completed DVR vs. length over `(𝓞_L)_P`; route: both equal `v_P(p)`).
* **G3 different**: multiplicity of `𝔪_B` in `differentIdeal ℤ_[p] B` = multiplicity of `P` in
  `differentIdeal ℤ (𝓞 L)`. This needs the dual/trace description to commute with localization at
  `p` and with completion (`𝓞_L ⊗ ℤ_p ≅ ∏_{Q|p} 𝓞_{L_Q}`, trace = sum of local traces), and the
  identification of the factor at `P`. This is the main missing mathematics-in-Lean.
* **G4 valuation of `e`**: `v_B((e : B)) = e · v_p(e) = e · padicValNat p e`.
* **G5 DVR arithmetic**: `𝔇_B ∣ 𝔪_B^(e−1)(e)` ⇔ `v_B(𝔇_B) ≤ e − 1 + e·v_p(e)`; then G3 ⇒
  `¬ P^(… + 1) ∣ differentIdeal ℤ (𝓞 L)` (Dedekind `dvd ↔ le` / factorization counts).
* **G6 coverage**: every `L : Type`, prime `p`, `P` with `LiesOver` — no Galois / tame / `f = 1` /
  totally-ramified / unique-prime-above-`p` restriction may survive in the final theorem. Cases that
  look special (L = ℚ; `e = 1` unramified, exponent `1`, discharged by `not_dvd_differentIdeal_iff`
  + `ramificationIdx_eq_one_iff` with finite residue fields; tame `p ∤ e`) must be covered by the
  same theorem, not by separate hypotheses.

Independent observation (alternative route, NOT an implementation request): T21 can also be reached
without completions. With `k = v_p(e)`, `a = k+1`: by `differentialIdeal_le_iff`, `P^{ea} ∣ 𝔇` iff
`Tr(P^{−ea}) ⊆ ℤ`; elements `z/p^a` with `z ∈ ∏_{Q≠P} Q^{e_Q a}` lie in `P^{−ea}`; reducing mod `p^a`
and splitting `𝓞_L/p^a ≅ 𝓞_L/P^{ea} × ∏` (trace of a product = sum) reduces T21 to: the trace
`𝓞_L/P^{ea} → ℤ/p^a` is nonzero. That follows from the unramified (Galois-ring) lift inside the finite
local ring `𝓞_L/P^{ea}`, `Tr_{R/W}(1) = e`, and surjectivity of the étale trace. Caution: using
`x = 1` gives `Tr = e·f`, which only suffices when `p ∤ f`; any proof covering only `p ∤ f`,
`f = 1`, Galois, or tame cases is incomplete for T21. Offered as a fallback if G3 stalls.
