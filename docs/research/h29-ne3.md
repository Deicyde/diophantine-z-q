## 1. The two new leaves, against the print

* **`TYZLemma29PrintedNe3`** is the display of Lemma 2.9 (L1062–1066) restricted to odd classes, `n > 1`, `n ≠ 3`:
  each restriction is a weakening of the print. At `n = 3` the print is false (h29-fix, VERIFIED: `Q(3) = ±3` on
  TYZ's 8-point double coset space for all 8 admissible `τ`, `𝓛(3)² = 1`). For squarefree `1 < n ≠ 3`,
  `μ(ℚ(√−n)) = {±1}` (STANDARD), so `w_K = 1` and TYZ's proof (L1068–1077) gives exactly the print; h29-fix's
  computation (`brandt2.py`) confirms it on 18 values `n ≠ 3`, two embeddings each. No `w_K` appears in the leaf.
* **`TYZThm21At31`** is one instance of Theorem 2.1's formula: `(d₁, d₂) = (3, 1)`, `χ_{3,1} = 1` by the convention
  for `d₂ = 1` (L510), so `P(3, 1) = Σ_{t ∈ Cl_3} f_3(t)` (definition L551–552); `k = 1`, `a = 1`, `2^{k−a} = 1`.
  `w_K` is stated as `NumberField.Units.torsionOrder (QNeg 3) / 2` (Mathlib: the order of the torsion of `𝓞_K^×`,
  i.e. the number of roots of unity), never as an evaluated number. The leaf does **not** state Theorem 2.1's first
  assertion (`P ≠ 0` only if `d₂ ≡ 1 (8)`), which is false for ordered pairs when `n ≡ 3 (8)`; at `(3, 1)` it is not
  needed. Numerically (h29-fix): `P(3, 1) = ±3`, `w_K = 3`, `𝓛(3)𝓛(1) = ±1` (VERIFIED).
