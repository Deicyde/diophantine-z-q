  G_t \ (G_t)⁰ is closed in G. The proof:
  * the component of e(t) is open in the fibre, since a scheme smooth over a field has open irreducible

## 3. The 𝓞_L use (`SemistableNeronBaseChangeNoSGA3.lean`, no leaf)

`SGA3Nbhd.semistableNeronBaseChange_noSGA3 (hB : BLR_1_2_4) (h7 : SGA7_IX_3_3) (hG : GeomConnOfRationalPoint) :
ZInQ.HeightSplit.SemistableNeronBaseChange` has exactly the field's type and is compiled.

SS2 only asks for *some* open subgroup model 𝒰 of 𝒱 = 𝒩 ×_{𝓞_L} 𝓞_{L′} mapping into 𝒩′ by an open immersion. It
does not need 𝒩⁰ to be open over 𝓞_L. The construction:

1. **Spreading** (`spread_openImm`). The Néron extension c₀ : 𝒱 → 𝒩′ is an isomorphism on generic fibres. By
   EGA IV₃ 8.10.5 for open immersions it is an open immersion over 𝓞_{L′}[1/n!], for some n.
   * EGA IV₃ 8.10.5 is already proved in the tree (`egaIV_8_10_5_openImm_proof`). It is applied to
     Spec L′ = lim Spec 𝓞_{L′}[1/n!] (`SpreadOut.NF.specConeIsLimit`).
2. **W₀** = {x ∈ 𝒩 | 𝒩.hom x ∈ T → x ∈ 𝒩⁰}, where T is the finite set of primes of 𝓞_L containing n!. Finiteness
   comes from `Ideal.finite_minimalPrimes_of_isNoetherianRing`, since such primes are minimal over (n!).
   * W₀ is open (`isClosed_fibre_diff`, finite union).
   * W₀ is a subgroup (`mul_mem`, `idCompSubgroup_proof`).
   * W₀ contains the generic fibre.
   * `openSubgroupModel_at` makes it a group model 𝒢₀ with range W₀. This is the construction of
     `identityComponentOLRange_of`, for any such W.
3. 𝒰 = 𝒢₀ ×_{𝓞_L} 𝓞_{L′}, and j : 𝒰 → 𝒩′ is given by the Néron property, as in the original proof. Openness of j
   is checked at each DVR O′ of L′ (`openImmersionLocalization`).
   * **n! a unit in O′.** The base change of 𝒰 → 𝒱 → 𝒩′ is an open immersion (step 1), and its generic fibre is
     an isomorphism. `isOpenImmersion_of_neron` then gives that the base change of j is one too.
   * **n! not a unit in O′.** The centre of O = O′ ∩ L lies in T. The original argument through SGA 7 IX 3.3 applies
     once range(𝒢₀ ×O) = (𝒩 ×O)⁰, that is, pr₁⁻¹(W₀) = (𝒩 ×_{𝓞_L} O)⁰. This is proved pointwise:
     * over the generic point of O, both sides are everything (`mem_idCompSet_groupModelO_generic`);
     * over the closed point, use **SGA 3 VI_B 3.3 at one point without openness of G⁰**. The inclusion
       `mem_idCompSet_of_bc` (pr₁ maps (G×S′)⁰ into G⁰) holds for any base change. The converse
       `mem_idCompSet_bc` uses the open V = G \ (G_s \ G_s⁰) in place of G⁰, one fibre of V → S being
       geometrically connected (`connected_fibre_V`, Stacks 04KV, proved), and the image argument of
       `idComp_baseChange` (`preconnected_P`).
