## 4. Replaying on a later head

`scratch/fold34-eichler/replay.sh` runs the fold on a head that has further folds, in these steps:
1. build Main and `R5fpCountLeHF`;
2. run `Taint.lean` on the head;
3. run `gen.py`, which writes the copy;
4. run `top.py`, which writes the next TailZ module and patches Main;
5. drop the kinds and claims rows;
6. build.

Then run `checks.sh TAG`, `render_open.py`, `frontier_crosswalk.py` and autoform.

  highest existing one.

  them, `top.py` reuses the `field := _root_.…_proof` line that autofold wrote for them.

  from the base Main and `taint_out.txt` (VERIFIED with cmp).
