### 2.3 Rating `EichlerOptEmbCount6` against its print (printed form: **yes**; numbers UNVERIFIED)

* **Display.** The trace formula for optimal embeddings:
  `Σ_{[I] ∈ Cls 𝒪} m(S, O_L(I); O_L(I)^×) = h(S) ∏_p m(S_p, 𝒪_p; 𝒪_p^×)`.
  * References: Voight, *Quaternion Algebras* (2021), Thm 30.4.7; Vignéras, LNM 800, Ch. III Thm 5.11; Eichler,
    Crelle 195 (1955).
  * For the indefinite `B = (2, −3 | ℚ)` with `𝒪` maximal, `#Cls 𝒪 = 1`. The kernel proves class number one
    (`RayClassCFT.classNumberOneB_proof`, `QMSplit.CNO.principal_of_lattice`), so the sum has one term.
  * `h(S) = #Pic(S)` (invertible ideals of the order), which is Mathlib's `CommRing.Pic R`.
* **Normalization.** The count is `m(S, 𝒪; 𝒪^×)`: **all** optimal embeddings `φ : k → B` with `φ⁻¹(𝒪) = R`
  (Lean's `OptEmb`), modulo conjugation by the **full unit group** `𝒪^×` (Lean's `ConjRel`).
  * This is not Vignéras Cor. 5.12's `𝒪^1`-count.
  * The two agree with González–Rotger's `CM(R)` (normalized embeddings modulo `Γ = 𝒪^1`). Conjugation by the
    norm `−1` unit `1 + i` (`GRCountX6.one_add_i_mem_units`) carries the normalized embeddings bijectively onto the
    others, and no `g ∈ 𝒪^×` of norm `−1` conjugates one normalized embedding to another, because it swaps `ℍ` and
    `ℍ⁻` (STANDARD).
  * Consistency, from the STANDARD formula: `h·∏ = 2, 2, 2, 4` at discriminants `−4, −3, −24, −19`. The value 4 at
    `−19` is the locator audit's example, and the others are the CM fibres of Elkies' model.
* **Local factors.** At `p ∣ D = 6` (`B_p` division, `𝒪_p` maximal): `m_p = 1 − (S | p)` with Eichler's symbol.
  * `(S | p) = (k | p)` (Kronecker) when `p ∤ f(S)`.
  * `eichlerLocal` is 2, 1 or 0 for `p` inert, ramified or split, read on the ideal `p𝒪_k` (`Ideal.span {p}` prime;
    `= P²`; otherwise). At `p = 2` this is the Kronecker symbol `(d | 2)`: inert iff `d ≡ 5 (8)`, split iff
    `d ≡ 1 (8)`, ramified iff `d` even.
  * At `p ∤ 6`, `𝒪_p ≅ M₂(ℤ_p)` and `m_p = 1` for every order of conductor prime to `p`.
* **Conductor hypothesis.** The print holds for every order (with `(S | p) = 1` at `p ∣ f`). The leaf assumes
  `Nat.Coprime (conductor R) 6`, so it is a specialization, never stronger. The hypothesis also forces finite index,
  because `Nat.Coprime 0 6` is false. When some `p ∣ 6` splits, both sides are 0: `k` does not embed in `B`.
* **Over genuine definitions.** Mathlib's `QuaternionAlgebra ℚ 2 0 (-3)`, the kernel's `LeafQM.O`, `CommRing.Pic`,
  prime ideals of `𝓞 k`, and `AlgHom`. No structure is invented for the purpose.


Reading: González–Rotger define `P = [z] ∈ Γ∖ℍ` to be in `CM(R)` iff `z` is fixed by `φ(k^×)` for an optimal
embedding `φ : R ↪ 𝒪`. Under the moduli interpretation `[z] ↦ ℂ²/ι(𝒪)(z, 1)ᵀ` (Shimura 1967), `x` is that point:

* the pair of `x`, base-changed along `GR56.σQ`, has an `ι`-compatible uniformization with kernel exactly `Λ_z`;
* `ShimuraCFT.IsCMPoint φ κ z` (RayClassShimura L405) says `ι(φ(a))(z, 1)ᵀ = κ(a)(z, 1)ᵀ`. For `z ∈ ℍ` this is
  equivalent to `φ(k^×)` fixing `z`, because a matrix fixing `z` has eigenvector `(z, 1)ᵀ` with eigenvalue
  `cz + d`, and `a ↦ c_a z + d_a` is an embedding.
