## 3. The remaining leaf: `KummerIndexBound`

```lean
def KummerIndexBound : Prop :=
  ∀ (F L : Type) [Field F] [NumberField F] [Field L] [NumberField L] [Algebra F L]
    [IsGalois F L] (p : ℕ) [Fact p.Prime] [HasEnoughRootsOfUnity F p],
    Module.finrank F L = p → (GlobalNumberFields.ideleClassNormMap F L).range.index ≤ p
```

`ideleClassNormMap F L : C_L →ₜ* C_F` is Tau Ceti's norm map
(`NumberField/Global/Ideles/Norm/Relative.lean:184`). It is induced by the idele norm on Mathlib's
`IdeleClassGroup`. This is the hypothesis `h` of Tau Ceti's
`subsingleton_h1_globalFormation_of_forall_index_le`, verbatim (VERIFIED by compiling the
application).

* It is a consequence of the published **second fundamental inequality**,
  `[C_F : N_{L/F} C_L] ≤ [L : F]` for every finite Galois extension of number fields (STANDARD:
  Milne, *Class Field Theory*, VII, Theorem 5.1(b); Neukirch, *Algebraic Number Theory*, VI §4;
  Cassels–Fröhlich, Ch. VII §9; theorem numbers UNVERIFIED).
* It is weaker than that inequality: it covers only prime degree with `μ_p ⊂ F`, and
  `Subgroup.index` is `0` when the index is infinite. So it is never stronger than the published
  statement. It is stated over Mathlib's ideles and Tau Ceti's norm map, which are genuine
  definitions.
* Proving it in Lean, from what is vendored (SPECULATIVE assessment from the docstrings and the
  statements, VERIFIED to be present): Tau Ceti oct16 vendors most of Milne's §6 pieces (the lemma numbers below are those cited in the Tau Ceti docstrings).
  * Present:
    * `relIndex_auxiliaryKummerIdeleSubgroup_eq_pow`, `[I_{S∪T} : E_{S,T}] = p^{2(#S+r₁+r₂)}`
      (Milne Lemmas 6.4, 6.6);
    * `exists_auxiliaryPlaces_unitLocalPowerClassMap_surjective`, the auxiliary places `T`
      (Lemma 6.9);
    * `index_range_ideleClassNormMap_dvd_index_auxiliaryKummerIdeleClassSubgroup`, which says that
      `E_{S,T}` consists of norms (Proposition 6.10);
    * `index_auxiliaryKummerIdeleClassSubgroup_dvd`.
  * Missing: the final count `[C_F : F^× E_{S,T}] = [I_{S∪T} : E_{S,T}] / [U_{S∪T} : U_{S∪T} ∩
    E_{S,T}] = p`, which needs the `S`-unit theorem and the Kummer degree `[F(U_S^{1/p}) : F] =
    p^{#S'}`. Also missing are the facts that a cyclic `L` sits inside `F(U_S^{1/p})` for large
    `S` and that `L` splits at `T`.
  * Alternative: backport Tau Ceti main's unconditional `brLocalization_injective` and
    `sumLocalInv_brLocalization_eq_zero` (`Global/Brauer/SumFormula.lean:71, :102` at main, per
    tc-survey; 45 new modules from Lean v4.36). With those, `brauerHasse2C_of_injective` and

## 4. Mathematics of the bridge

**Kummer bridge (`Kummer2.lean`).** Let `G = Gal(Kˢ/K)` and `M = (Kˢ)ˣ`, discrete, with
`char K ≠ 2`. The sign map `ℤ/2 → M`, `a ↦ (-1)^a`, is injective and `G`-equivariant.

* *Injectivity on classes.* Suppose `(-1)^ε = df` with `f : G → M` continuous. Then
  `d(f²) = 1`, so by Hilbert 90 `f² = dc` for some `c ∈ M`. Let `r ∈ Kˢ` with `r² = c`
  (separably closed, `2 ≠ 0`), and put `f' = f · (dr)⁻¹`. Then `f'² = 1`, so `f'` takes values
  in `±1`, and `ε = d(log f')`, where `log f'` is continuous because `M` is discrete.
* *Surjectivity onto `H²(G, M)[2]`.* Suppose `2[z] = 0`, that is `z² = dh` with `h` continuous.
  Let `s` be a pointwise square root of `h`; it is continuous because `M` is discrete. Then
  `z' = z (ds)⁻¹` is cohomologous to `z`, takes values in `±1`, and is `(-1)^ε` for a continuous
  `ℤ/2`-cocycle `ε`.

This is `H²(G_K, μ₂) ≅ Br(K)[2]` (STANDARD: Serre, *Corps locaux*, X §4-5), proved directly on the
explicit complex. Since `Br K = H²(G_K, (Kˢ)ˣ)` by definition in Tau Ceti, no comparison with a
CSA-defined Brauer group is involved.

**T15 at `ℚ_p`.** `invMap ℚ_p ∘ unitsRepH2Equiv : H²(Gal(ℚ_pˢ/ℚ_p), (ℚ_pˢ)ˣ) ≃+ ℚ/ℤ`, and
`(ℚ/ℤ)[2] = {0, 1/2}`. So there is exactly one nonzero 2-torsion class, which gives
`H2TwoClasses` for `Gal(ℚ_pˢ/ℚ_p)`. This is transported to Mathlib's `Field.absoluteGaloisGroup
ℚ_p` along `absoluteGaloisGroupRestrictEquiv`.

**T14.** `brClass ε` is the class of `(-1)^ε` in `Br ℚ`.
`brBaseChange_brClass_eq_zero_iff` identifies "`brClass ε` dies in `Br F`" with "`resC F ε` is a
coboundary". The proof uses Tau Ceti's `brBaseChange_apply`, under which base change can be
computed with any embedding of separable closures. With the embedding induced by Mathlib's
`IsAlgClosed.lift`, Tau Ceti's map of Galois groups is Mathlib's `Field.absoluteGaloisGroup.map`
(`square`).

* Hasse: all localizations of `brClass ε` vanish, so `brClass ε = 0`, so `ε` is a coboundary.
* Reciprocity: `brClass ε` is 2-torsion, so each nonzero local invariant is `1/2`. The sum formula
  gives `(n_fin + n_∞) · 1/2 = 0` in `ℚ/ℤ`, so the count is even. Finiteness comes from Tau Ceti's
  `brauerSupport`, transported through `primesEquiv`.

## 5. Lean pitfalls met (for the next user of vendored Tau Ceti)

* In a file importing Tau Ceti, `Algebra ℚ (SeparableClosure ℚ)` and `Algebra ℚ (v.adicCompletion ℚ)`
  synthesize `DivisionRing.toRatAlgebra`. Tau Ceti's generic statements instantiate to
  `IntermediateField.algebra'` and `HeightOneSpectrum.instAlgebraAdicCompletion`, and these are
  not defeq at instance transparency. Fixes used:
  * `attribute [-instance] DivisionRing.toRatAlgebra` (BaseChange2);
  * `{i : Algebra ℚ L}` implicit arguments in place of instance-implicit ones, together with
    `Subsingleton (ℚ →+* B)` to build `ℚ`-algebra maps (`ratAlgHomOfRingHom`);
  * `attribute [local instance 2000] HeightOneSpectrum.instAlgebraAdicCompletion` to elaborate
    `padicEquiv v |>.toAlgEquiv`.
* `TauCeti.ContCohomology.H2pi G M z` versus the coercion `(z : H2 G M)`: `rw [H2pi_eq_zero_iff]`
  fails, but `H2pi_eq_zero_iff.mp/.mpr` works by defeq. For `explicitMap2_mk`, first
  `rw [QuotientAddGroup.mk'_apply]`.
* `autoImplicit` is on in this project. A misspelled binder (`_hε` declared, `hε` used) silently
  became an auto-bound implicit in an `∃` statement. Every file here sets
  `autoImplicit false`.
* The Tau Ceti closure needed (Brauer/Invariant, Global/Brauer/SumFormula,
