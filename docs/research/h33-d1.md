## 2. Model uniqueness (`CurveModelUnique.lean`)

```lean
theorem ZInQ.CurveModel.exists_iso_of_functionField {X Y : Scheme} [IsIntegral X] [IsIntegral Y]
    (sX : X ⟶ Spec ℚ) (sY : Y ⟶ Spec ℚ) [IsProper sX] [IsProper sY]
    (hX : ∀ p : X, ValuationRing (X.presheaf.stalk p)) (hY : ∀ p : Y, ValuationRing (Y.presheaf.stalk p))
    (e : X.functionField ≃+* Y.functionField) :
    ∃ f : X ⟶ Y, IsIso f ∧ X.fromSpecFunctionField ≫ f = Spec.map (ofHom e.symm) ≫ Y.fromSpecFunctionField
```

The file has four parts:
- `exists_extension_of_generic`: valuative extension of `Spec K(X) ⟶ Y`.
- `isDominant_fromSpecFunctionField` and `ext_of_fromSpecFunctionField`: uniqueness.
- `exists_iso_of_functionField`: `f` from `e⁻¹` and `g` from `e`; `f ≫ g` and `g ≫ f` are the identity at the
  generic point, hence everywhere.
- `algebraMap_stalkMap`: if `h : X ⟶ Y` induces `c : K(Y) → K(X)`, then on local rings `h^♯` is `c` composed with
  the inclusions. The proof works through affine charts and `IsAffineOpen.SpecMap_appLE_fromSpec`.

The stalks of a model are valuation rings by hgz-steps' `valuationRing_stalk_of_normal`, which needs a normal
scheme of dimension 1 that is locally noetherian (proper over `ℚ`): `GZUnique.valuationRing_of_model`.

### 4.2 `ESch E` is normal (`TYZThm33Curve/Normal.lean`)

This is the inverse direction of D1.

```lean
theorem ZInQ.H33D1.valuationRing_stalk_ESch (E : WeierstrassCurve ℚ) [E.IsElliptic] (p : ESch E) :
    ValuationRing ((ESch E).presheaf.stalk p)
```

The proof treats the chart `D₊(Z)` and the point `O` separately.
- **On `D₊(Z)`.** The local ring is `Localization.AtPrime q` of `A_(Z) ≅ ℚ[x,y]/(W_E)`, carried over by
  `StructureSheaf.stalkIso` and the stalk isomorphism of the open immersion (`locEquivStalk`).
  - `ℚ[x,y]/(W_E)` is a Dedekind domain: Tau Ceti's `isIntegrallyClosed_coordinateRing` and
    `isDedekindDomain_coordinateRing_of_isIntegrallyClosed`.
  - Its localization at a prime is a field or a DVR (`valuationRing_localization_dedekind`).
- **At `O`**, in the chart `D₊(Y)`, with `u = X/Y` and `v = Z/Y`:
  - `away_mk_eq_aeval_Y`: `A_(Y)` is generated by `u` and `v`.
  - `gY_equation`: `v·w = u³` with `w = 1 + a₁u + a₃v − a₂u² − a₄uv − a₆v²`.
  - A prime containing `v` contains `u` and is contained in `(u, v)` (`le_span_uv`).
  - So the maximal ideal of the local ring is `(u)`, because `w` is a unit there.
  - The local ring is noetherian (`ESch E` is locally noetherian) and a domain, and its maximal ideal is principal,
    so it is a valuation ring (`valuationRing_of_maximalIdeal_principal`, via
    `exists_maximalIdeal_pow_eq_of_principal`).

**G4(b)** is `not_mem_chartZ_iff : p ∉ D₊(Z) ↔ p = ptO E`. Here `ptO E = chartY (ker χ_O)`, and
`χ_O : A_(Y) → ℚ` is evaluation at `[0 : 1 : 0]`. The kernel is `(u, v)` (`eq_ker_chiO`).

### 4.3 The leaf (`TYZThm33Curve.lean`)

```lean
def TYZ33Body (X : Scheme) [IsIntegral X] (sX : X ⟶ Spec ℚ) (ι : X.functionField ≃+* X0Field 32) : Prop :=
  ∀ i₀ : X ⟶ ESch curveA, IsIso i₀ → i₀ ≫ toSpecQ curveA = sX →
  (∀ p : X, IsCuspInfty 32 ι p → i₀ p = ptO curveA) →
  ∀ w : ℕ → PtA,
    (∀ n, ∀ hn : n % 8 = 5, Squarefree n → ∀ x : Spec ℂ ⟶ X,
      IsPointAt 32 ι (tyzForm n hn).tauH x → toC (w n) = GZSch.ptOf curveA (x ≫ i₀)) →
    (∀ n, ∀ hn : n % 8 = 7, Squarefree n → ∀ x : Spec ℂ ⟶ X,
      IsPointAt 32 ι (tyzForm7 n hn).tauH x → toC (w n) = GZSch.ptOf curveA (x ≫ i₀)) →
    TYZThm33EpsAfter (zOfLift w)

def TYZThm33CurveSome : Prop :=
  ∃ (X : Scheme) (_ : IsIntegral X) (sX : X ⟶ Spec ℚ), IsProper sX ∧ IsNormalScheme X ∧
    topologicalKrullDim X = 1 ∧ ∃ ι : X.functionField ≃+* X0Field 32, TYZ33Body X sX ι
```

The theorems about it (all VERIFIED):
- `tyzThm33CurveSome_of_all` and `tyzThm33Curve_of_some`: the one-model form is equivalent to the all-models form
  `TYZThm33Curve`.
- `exists_iso_of_phi`: D1 in both directions. For any model `(X, ι)` and any bijective `φ : ℚ(A) → ℚ(X₀(32))`,
  there is an isomorphism `i₀ : X ≅ ESch curveA` inducing `φ`. It uses model uniqueness with
  `e = ffEquiv⁻¹ ∘ φ⁻¹ ∘ ι` and `eOf_symm_kappaZ`.
- `modPt_eq_h33`: the plane-model value is h33-dict's `ptOf X Y τ`.
- `tyzThm33Alg_of_curveSome : TYZThm33CurveSome → H33Fix.TYZThm33Alg`. It uses `i₀(∞) = O`
  (`cusp_not_mem_chart` and G4(b)) and `i₀(P_n) = (X(τ_n), Y(τ_n))` (`ptOf_eq_modPt`).
- `tyzThm33_of_curveSome (hCM) : TYZThm33CurveSome → TYZSplit.TYZThm33`: the binder `h33`.
- `tyzThm33Curve_hyps_satisfiable (hCM)`: on every model there are an `i₀` and a `w` that satisfy the hypotheses,
  from the eta model of h33-fix. So the body is not vacuous. And since points `x` at `τ` exist on every model
  (hgz-steps' `exists_pointAt`), the point hypothesis on `w` is a real constraint.
