# Cassels–Tate pairing: the printed statement behind `CasselsTatePairing`

Literature check for the leaf that replaces Lemma 5.4's input in the #83 lane. Sources were read on 2026-11-18
from the authors' public PDFs (Poonen: math.mit.edu; Milne: jmilne.org); quotations are verbatim, with the
symbol `Ш` restored where the PDF text extraction dropped it.

## The Lean statement

```lean
/-- `ℚ/ℤ`. -/
abbrev QZ : Type := ℚ ⧸ AddSubgroup.zmultiples (1 : ℚ)

/-- The maximal divisible subgroup: the subgroup generated by the divisible subgroups. -/
def divisiblePart (A : Type*) [AddCommGroup A] : AddSubgroup A :=
  sSup {H : AddSubgroup A | ∀ h ∈ H, ∀ n : ℕ, n ≠ 0 → ∃ g ∈ H, n • g = h}

def CasselsTatePairing (E : WeierstrassCurve ℚ) : Prop :=
  ∃ b : sha E →+ sha E →+ QZ, (∀ x, b x x = 0) ∧
    ∀ x, (∀ y, b x y = 0) ↔ x ∈ divisiblePart (sha E)
```

`sha E` is main's `ZInQ.Manuscript.SelmerTwoPower.sha E`, unchanged: the classes of Tau Ceti's
`H1 (AbsoluteGaloisGroup ℚ) E.PointCoeff` (continuous cochains of `G_ℚ` with values in the discrete module
`E(ℚˢ)`; Tau Ceti identifies it with Mathlib's continuous cohomology, `explicitH1AddEquivContinuousCohomology`)
whose restriction to `ℚ_p` for every prime `p` (`embFin`) and to `ℝ` (`embInf`) vanishes, i.e. `Ш(E/ℚ)`.

## Clause by clause

| Lean | Print (Poonen–Stoll, Introduction, first paragraph, unless noted) |
| --- | --- |
| `E : WeierstrassCurve ℚ` with `E.IsElliptic` (in every consumer) | "E is an elliptic curve over a number field" |
| `sha E` | Ш(E): the kernel of `H¹(K, E) → ∏_v H¹(K_v, E)` over all places `v` |
| `b : sha E →+ sha E →+ QZ` | "a pairing Ш(E) × Ш(E) → Q/Z" (biadditive) |
| `∀ x, b x x = 0` | "this pairing is alternating; i.e., that ⟨x, x⟩ = 0 for all x" |
| `∀ x, (∀ y, b x y = 0) ↔ x ∈ divisiblePart (sha E)` | "becomes nondegenerate after one divides Ш(E) by its maximal divisible subgroup": the maximal divisible subgroup lies in the kernel and the induced pairing on the quotient has trivial kernel, so the left kernel is exactly the maximal divisible subgroup (the right kernel then too, by alternation); Milne 6.13 (a) and 6.26 (a) state the kernels in this form on each primary component |
| `divisiblePart (sha E)` | "its maximal divisible subgroup": `divisiblePart` contains every divisible subgroup (`le_divisiblePart`) and is itself divisible (`divisiblePart_divisible`), so it is the maximal divisible subgroup |
| `∃ b` | "there exists a pairing"; Cassels constructs a specific pairing, which the leaf does not name |

So `CasselsTatePairing E` is the printed theorem for `K = ℚ`, as an existence statement: every conjunct is in
the printed sentence, and it is weaker than the print (it does not name the pairing, and it is for `ℚ` only).
It is a printed leaf, not glue.

## What is derived from it in Lean, not assumed

`casselsTateSquare_of_pairing : CasselsTatePairing E → CasselsTateSquare E` is a theorem (a mathematical
reduction, proved, not a further hypothesis). Its steps:

1. `exists_nsmul_eq_zero_H1`: every class of `H¹(G_ℚ, E(ℚˢ))` has finite order (proved: Tau Ceti's
   `isAddTorsion_continuousCohomology` for a compact group with discrete coefficients, through
   `explicitH1AddEquivContinuousCohomology`).
2. Alternation gives skew-symmetry; a divisible subgroup lies in `divisiblePart`, hence in both kernels.
3. Given `Ш(E/ℚ)[2^∞] ≅ (ℚ₂/ℤ₂)^t × F` with `F` finite (the decomposition `CasselsTateSquare` quantifies over):
   the image of `(ℚ₂/ℤ₂)^t` is divisible, so the pairing restricted to `Ш[2^∞]` descends to `F`.
4. Non-degeneracy on `F`: if `f ∈ F` pairs to zero with `F`, it pairs to zero with `Ш[2^∞]` (step 3) and with
   the odd part of every class (step 1 and coprimality of orders), so it lies in `divisiblePart (sha E)`;
   a `2`-primary element of the maximal divisible subgroup is infinitely `2`-divisible inside `Ш[2^∞]`, and
   `F` is a finite `2`-group, so `f = 0`.
5. A finite abelian `2`-group with a non-degenerate alternating `ℚ/ℤ`-valued pairing splits as `B × B`
   (symplectic splitting), so `#F[2]` is a square: `isSquare_card_tors_two_of_alternating`.

Then `CasselsTateSquare` gives Lemma 5.4 (`b52a56b0`, `Lemma54FromCasselsTate.lean`) and Theorem 5.2.

All five steps are proved (`ZInQKernel/Contrib/OneProof/CasselsTatePairing.lean`, standard axioms):
`exists_nsmul_eq_zero_H1`, `divisiblePart_divisible`, `le_divisiblePart`, `casselsTateSquare_of_pairing`,
`isSquare_card_tors_two_of_alternating`. Consumers: `PoleS12.lemma54At_of_casselsTatePairing`,
`PoleS12.lemma54_of_casselsTatePairing`, `PoleS12.poleCompleteness_of_restrictedConverseGenuine_casselsTatePairing`.

## Flags

* **Secondary print.** The leaf is matched against Poonen–Stoll's refereed statement of Cassels' theorem and
  against Milne's Theorem 6.13 (a) and 6.26 (a), not against Cassels 1962, which was not read.
* **Polarization.** Poonen–Stoll show the pairing need not be alternating for principally polarized abelian
  varieties in general; for elliptic curves it is (Cassels; Poonen–Stoll, Remarks after Corollary 12; Milne
  p. 81 with the divisor `(O)`). The leaf is stated for elliptic curves only.
* **p = 2.** Nothing in the leaf is specific to `p = 2`; the restriction to `Ш[2^∞]` and its finite part is
  derived in Lean (steps 3–4).
* **Mazur–Rubin.** PR #90's `MazurRubinParityTwo` is not used on this route; its own flag (the display of
  Mazur–Rubin 2010 is stated for `p`, and the cited Mazur–Rubin 2007, Proposition 2.1, for odd `p`) is not
  reduced by this work.
* **Remaining inputs of Theorem 5.2 on this route:** Theorem 5.3 (`RestrictedConverseGenuine`; the
  manuscript's own theorem, proved in its Sections 6–7 and appendices; the RC53 lane), `CasselsTatePairing` for
  the curves `E_ℓ` (printed, above), `BCDTThmA` (printed, in a weaker form; locator unverified) and
  `KolyvaginThm1` (cited by the manuscript as the MPIM preprint MPI/90-69; only the rank statement is used).
  Mordell–Weil for `E_ℓ` is proved (`PoleRC.mordellWeil_curve`, PR #90).
