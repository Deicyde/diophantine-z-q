### 2.1 The definitions

All are over Mathlib's and the kernel's existing definitions. Nothing new is postulated.
* `cmVec Φ x = (φ₁(x), …, φ_g(x))` and `cmLat Φ 𝔞 = Φ(𝔞) ⊂ ℂ^g`.
* `latHat 𝔞` is `𝔞 ⊗ ℤ̂` inside `𝔸_f ⊗_ℚ E`, the subgroup generated by the `c ⊗ x` with `c ∈ ℤ̂` (the kernel's
  `ZhatQ`) and `x ∈ 𝔞`.
* `latAct t 𝔞 = {y ∈ E : t y ∈ 𝔞̂}` is Shimura's `t⁻¹𝔞`.
* **The reflex field** is the subfield of `ℂ` generated by the type traces `∑ᵢ φᵢ(e)`. It is entered as an abstract
  number field `Er` with an embedding `κr` onto it.
* **The reflex norm** is `reflexNorm ρ s = det(ρ_{𝔸_f}(s_f))`. Here `ρ : Er → M_n(E)` is the action of `Er` on a model
  `V = Eⁿ`, and it is extended to `𝔸_f ⊗ Er ≅ 𝔸_{Er,f}` (Tau Ceti's `finiteAdeleBaseChangeAlgEquiv`).
* `IsReflexModel Φ κr ρ j` says that `V ⊗_{Er,κr} ℂ ≅ ℂ^Φ` as `E ⊗ ℂ`-modules, through `j`. It asks for:
  * `j` is `E`-linear;
  * `j` is `κr`-semilinear for `ρ`;
  * `j` spans `ℂ^g`;
  * `n[E:ℚ] = g[Er:ℚ]`.

  With such a model the reflex norm is Milne's `N_{Φ*}(a) = det_E(a | V)`.
* `IsOfType Φ 𝔞 θ` says that every `e` with `e𝔞 ⊆ 𝔞` acts by an endomorphism `α` with `α(θ(w)) = θ(Φ(e)w)`. This is
  Shimura's "(A, i) is of type (E, Φ)".
* `ArtinCondC` (shimura-cft, unchanged) says `σ = [s, E*]` on `E*^ab`, through Tau Ceti's idele class Artin map
  (arithmetic normalization).
* `A'` with `h` is the base change `A^σ`, in the kernel's form of `IsBaseChangeOf`. The `σ`-conjugate of a point `p`
  is the point `p'` with `p' ≫ h = Spec σ ≫ p`.

## 3. The derivation (all proved; VERIFIED, compiled)

Fix the data of `QMReciprocityL3`: `K` imaginary quadratic, `q : K → B`, the CM point `z` with reflex embedding `κ`
(`δ = true`), `σ = [s, K]`, and `P` equal to `T(z, g)` through `Φ_u`.

**§A–§B: the CM field and its type.**
* `E = K(√2) = AdjoinRoot (X² − 2)` over `K`. It is a field because `√2 ∉ K` (`no_sqrt_two`), a number field of
  degree 4, and a CM field (`isCMField_EK`).
* `φ₁, φ₂` are the embeddings extending `κ` with `√2 ↦ ±√2`.
* `Φ = (φ₁, φ₂)` is a CM type (`type_inj`, using that `κ` is not real).
* The reflex field is `κ(K)` (`reflex_eq`): the trace `φ₁ + φ₂` is `2κ` on coordinates.
* The model is `V = E` with `ρ(a)` = multiplication by `a` (`model`). The reflex norm is then the inclusion
  `𝔸_{K,f} → 𝔸_f ⊗ E` (`reflexNorm_rhoK`).

**§C: `E` acting on `B`.**
* `β(a + b√2) = q(a) + i q(b)`, with `i = ⟨0,1,0,0⟩` and `i² = 2`.
* `ι(i) = diag(√2, −√2)` (the kernel's `qmMat_oI`). With `IsCMPoint` this gives the period identity
  `ι(β(e))(z, 1)ᵀ = (z φ₁(e), φ₂(e))` (`vec_beta`).
* Hence `β` is injective, so it is a `ℚ`-isomorphism `E ≅ B` (`betaE`).
* `β(k e) = β(e) q(k)`.
* With `D_z = diag(z, 1)`: `D_z Φ(β⁻¹ L_h) = ι(L_h)(z, 1)ᵀ` (`cmLat_map_Dz`).

**§D: lattices.**
* **`ℤ̂ L_h = 𝒪̂ h⁻¹`** (`lg`, the hard inclusion). Take `N h ∈ 𝒪̂` and `M h⁻¹ ∈ 𝒪̂` (`exists_den_B`), so that
  `M w ∈ 𝒪̂`. Approximate its `ℤ̂`-coordinates by integers modulo `MN` (`exists_int_approx`). This writes
  `w = β(y) + N·ofQ(b)` with `y ∈ L_h` and `N·ofQ(b) ∈ ℤ̂·N𝒪 ⊆ ℤ̂ L_h`.
* **Approximation** (`exists_approx`): for all `w, v ∈ B ⊗ 𝔸_f` some `y ∈ B` has `(y − w)v ∈ 𝒪̂`.
* **The map `β̂ : 𝔸_f ⊗ E → B ⊗ 𝔸_f`**, `a ⊗ e ↦ a·β(e)`.
  * It is injective, with an explicit left inverse built from the basis `1, i, j, k` (`betaHat_injective`).
  * `β̂(N(s)w) = β̂(w) q̂(s)`, where `q̂` is shimura-cft's (`betaHat_inclA_mul`, `betaHat_t`).
  * `𝔞̂ = β̂⁻¹(𝒪̂ g⁻¹)` for `𝔞 = β⁻¹(L_g)` (`mem_latHat_iff`).

**§F: the main step** (`qmReciprocityL3_of_printed`).
1. `θ = Φ_u ∘ D_z` uniformizes `P.A` by `Φ(𝔞)`.
2. It is of type `(E, Φ)`: `diag(Φ(e))` preserves `ι(L_g)(z,1)ᵀ` when `e𝔞 ⊆ 𝔞`, so `HomLatticeCorr` (clause 2)
   gives the endomorphism.
3. The identity sections correspond by `IsBaseChangeOf` at `a = 0`.
4. The main theorem then gives `θ'` with kernel `Φ(t⁻¹𝔞)`, together with the conjugation formula.
5. By §D, `t⁻¹𝔞 = β⁻¹(L_{q̂(s)^ε g})`. So `Φ_u' = θ' ∘ D_z⁻¹` has kernel `ι(L_{q̂(s)^ε g})(z,1)ᵀ`.
6. **`ι`-compatibility of `Φ_u'`.**
   * `ι_{P'}(a)` lifts to a linear map `T_a` (`HomLinearLift`).
   * On every torsion vector `v_y = ι(β y)(z,1)ᵀ`, the two points `Φ_u'(T_a v_y)` and `Φ_u'(ι(a) v_y)` have the same
     image in `P.A`: both equal `σ(Φ_u(ι(a) v_x))`. This uses the conjugation formula twice, `ι`-compatibility of
     `Φ_u`, and the commutation of `ι` with the base change. A point of a pullback is determined by its image
     (`pt_ext`), so the two points are equal.
   * So `(T_a − ι(a)) v_y` lies in the lattice for every `y`. Since `y ↦ v_y` is `ℚ`-linear and `∩_N N L_h = 0`
     (`eq_zero_of_forall_dvd`), `T_a − ι(a)` vanishes on `v_1` and `v_{√2}`, which span `ℂ²`.
   * The review's gap from shimura-split2's §3.1, step 8 (`θ'` is only `E`-linear), is closed this way. No second
     subfield `F` is needed.
7. **The level structure of `T(z, q̂(s)^ε g)`.**
   * `η_P(a) = Φ_u(ι(x₀)(z,1)ᵀ/3)` with `x₀ g ∈ a + 3𝒪̂`.
   * Approximation gives `y₁ ∈ B` with `(y₁ q̂(s)^ε − x₀/3) g ∈ 𝒪̂`.
   * The conjugation formula and `IsBaseChangeOf` on `η` give `Φ_u'(ι(y₁)(z,1)ᵀ) = η_{P'}(a)`.
   * So `3y₁` is a level representative: `3y₁ q̂(s)^ε g ∈ a + 3𝒪̂`.
