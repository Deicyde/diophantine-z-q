## 2. The leaves (task items 1 and 2)

**Reading-proof hypothesis.** Both Mumford leaves assume `IsAmple L` and `IsVeryAmple L`.

* If Mumford's "ample" means EGA's ampleness, that is `IsAmple` (Stacks 01PS, the definition in `TailZ24`).
* If it means "some power is very ample", then `L¹` is very ample.

Either way the leaf is an instance of the print: it has more hypotheses, so it is weaker. `IsAmple` is supplied
in the glue by `T09Pic.veryAmpleIsAmple` (TailZ24:564, a theorem).

**Effective divisor (item 2).** §6 Application 1 is stated over an effective Cartier divisor `D`, given by its
invertible ideal sheaf (`D : X.IdealSheafData`, `D.IsInvertible`: locally generated by a non-zerodivisor).
`L = 𝒪_X(D)` is `divisorClass D hD := Pic.mk (D.toModulesᵛ)`, the dual of `𝒪_X(−D)`. So "D effective, L = 𝒪(D)"
matches with no Weil-divisor step and no "nonzero section" restatement. The vendored lemmas named in pic-fix's
docstring are now used:

* `exists_divisor_of_veryAmple : IsVeryAmple X c → ∃ D hD, divisorClass D hD = c`. Take `D = Z(i^*X_m)` for a
  coordinate `X_m` with `i(x) ∈ D₊(X_m)`. Then:
  * `s := coordSection i m` is nonzero by `compl_support_zeroLocus_coordSection` and `zeroLocus_eq_bot_iff`;
  * `Z(s)` is invertible by `Hom.isInvertible_zeroLocus`, since `X` is integral;
  * `i^*𝒪(1) ≅ 𝒪(Z(s)) ⊗ 𝒪` by `Hom.nonempty_iso_dual_toModules_tensorObj`.

```lean
def MumfordKLFiniteDivisorAC : Prop :=
  ∀ (k : Type) [Field k] [IsAlgClosed k] (X : AbVar k) (D : X.X.left.IdealSheafData) (hD : D.IsInvertible),
    IsAmple X.X.left (divisorClass D hD) → IsVeryAmple X (divisorClass D hD) →
    {x : AC.Kpt X | AC.phi (divisorClass D hD) x = 1}.Finite
def MumfordPhiSurjectiveVAC : Prop :=
  ∀ (k : Type) [Field k] [IsAlgClosed k] (X : AbVar k) (c₀ : X.X.left.Pic), IsAmple X.X.left c₀ →
    IsVeryAmple X c₀ → ∀ c : X.X.left.Pic, AC.IsTI c → ∃ x : AC.Kpt X, c = AC.phi c₀ x
def AmplePowVeryAmple : Prop :=
  ∀ (k : Type) [Field k] (X : AbVar k) (c : X.X.left.Pic), IsAmple X.X.left c →
    ∃ d : ℕ, 0 < d ∧ IsVeryAmple X (c ^ d)
```

### Glue, proved

* **Very ample over `K` stays very ample over `K̄`** (`isVeryAmple_bcPic`). The base change
  `i_K̄ = liftBaseChange …` is a pullback of `i` (vendored `ProjectiveSpace.isPullback_liftBaseChange`), hence an
  immersion. `bcPic A L = i_K̄^*𝒪(1)` follows from `Pic.map_comp` and `ProjectiveSpace.pullbackMapTwistIso`.
  Fold B needs this; fold A does not.
* **Fold A, from every ample `L` to a very ample power:**
  * `L_K̄` is ample (`ampleBaseChangeAlgClosure`, proved in pic-dict);
  * some `L_K̄^d` is very ample (`amplePowVeryAmple` at `K̄`);
  * `K(L_K̄) ⊆ K(L_K̄^d)` by `φ_{L^d} = φ_L^d` (`phi_pow`, re-proved locally);
  * surjectivity: `y = φ_{L^d}(x) = φ_L(x)^d = λ_L(x)^d = λ_L(x^d)`. Here `λ_L` is a homomorphism (rigidity,
    `exists_hom_comp_eq_phiL`, and Mathlib's `MonObj.pow_comp`), so the theorem of the square is not a leaf.
* The rest is pic-dict's glue: `finiteOfFiniteKerPts`, `surjective_of_forall_pt`, `picClass_phiL`,

  proved inputs.
