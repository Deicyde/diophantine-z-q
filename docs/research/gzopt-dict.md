## 2. The leaves

### 2.1 `GrossZagierAlgOptAt E` (Gross–Zagier, printed form)

```lean
def GrossZagierAlgOptAt (E : WeierstrassCurve ℚ) : Prop :=
  ∀ (N : ℕ) [NeZero N] (f : Newform N 2), f.χ = 1 →
    (∀ n : ℕ, n ≠ 0 → coeff f n = (E.LFunction n : ℂ)) →
    ∀ φ : E.toAffine.FunctionField →ₐ[ℚ] X0Field N,
    ((φ (genX E) : LaurentSeries ℚ)).order < 0 →
    ∀ X Y : ℍ → ℂ, (∀ τ : ℍ, MeromorphicAt (X ∘ ofComplex) (τ : ℂ)) →
    (∀ τ : ℍ, MeromorphicAt (Y ∘ ofComplex) (τ : ℂ)) →
    HasQExp X (φ (genX E)) → HasQExp Y (φ (genY E)) →
    GZOptimal.IsOptimalParam N f E X Y →
    [Heegner data and conclusion exactly as GZOptimal.GrossZagierModuliOptAt]
```

**Rating: LEAF, printed form** (SPECULATIVE assessment; the print was not read on this host). Item by item:

* **`φ`.** A nonconstant morphism `X₀(N) → E` of smooth projective curves over `ℚ` is the same as a `ℚ`-embedding
  `ℚ(E) → ℚ(X₀(N))` (Hartshorne I.6.12; Silverman AEC II.2.5; UNVERIFIED numbers). `ℚ(X₀(N)) = ℚ(j, j_N)` is the
  function field of the canonical model (Shimura 1971 §6.7). Both fields are genuine definitions: Mathlib's
  function field of a Weierstrass curve, and the FLT project's `modularFunctionField`.
* **`φ(∞) = O`.** The function `x` has its only pole at `O`, and `q` is a local parameter at the cusp `∞`. So
  `φ(∞) = O` holds iff `φ^*x` has a pole at `∞`, i.e. `ord_q φ^*(x) < 0`.
* **Complex points.** `X, Y` are the meromorphic functions on `ℍ` with `q`-expansions `φ^*(x)` and `φ^*(y)`.
  `φ^*(x) = R(jq, jq(q^N))` for a rational function `R` over `ℚ`. The function `R(j(τ), j(Nτ))` has this
  `q`-expansion, and by the identity theorem it is the only meromorphic function on `ℍ` that does. So `X, Y` are
  determined by `φ`, up to junk values at poles, which `modPt` ignores. `modPt E X Y τ` is then `φ(Γ₀(N)τ)`, the
  image under `φ` of the complex point `τ` of `X₀(N)`. This is how Gross–Zagier describe Heegner points (Ch. II §1):
  as points of `Y₀(N)(ℂ) = Γ₀(N)\ℍ`, given by `τ`. `Γ₀(N)`-invariance of `X, Y` is not assumed: it follows from the
  description above. Leaving it out does not make the leaf stronger.
* **Optimality.** `IsOptimalParam` is gz-optimal's analytic characterization of the strong Weil parametrization:
  the lift of `φ` to `ℍ → ℂ` is `c φ_f` with `c ∈ ℚ`, and `L = c Λ_f`. The second clause says that `φ_*` maps
  `H₁(X₀(N), ℤ)` onto `H₁(E(ℂ), ℤ)`, which is equivalent to `J₀(N) → E` having connected kernel. It is unchanged
  from gz-optimal, which rated it printed form. Mathlib has no `J₀(N)`, so it stays analytic. It reads `φ` only
  through `X, Y`, which `φ` determines.
* **Heegner data and conclusion.** Unchanged from gz-optimal: `y ∈ E(K)` with `ι(y) = n · y_K` for `n ≠ 0`, and
  `L'(E/K, 1) = κ ĥ(y)` with `κ > 0`. The conclusion is weaker than the print, since the explicit constant is
  forgotten.

So the statement is the printed theorem (Gross–Zagier 1986, Thm I.6.3 and Ch. V Thm 2.1, strong Weil case) with
the constant forgotten. It is a consequence of the print, not stronger. The hypothesis list is satisfiable: the bridge
builds `φ^*` from the consumer's `X, Y`.

### 2.2 `Gamma0QExpansion` (the `q`-expansion principle, printed form read through `q`-expansions)

```lean
def Gamma0QExpansion : Prop :=
  ∀ (N : ℕ) [NeZero N] (g : ℍ → ℂ), ZInQ.GZHeegner.IsRatModFnMero N g →
    ∀ x : LaurentSeries ℚ, HasQExp g x → x ∈ X0Field N
```

**Rating: LEAF, printed form, read through `q`-expansions.**

* **Sources.** Shimura, *Introduction to the arithmetic theory of automorphic functions* (1971), Prop. 6.9 with
  Thm 6.6: the `Γ₀(N)`-functions with rational Fourier coefficients form `ℚ(j, j∘N)`. Diamond–Shurman, *A first
  course in modular forms*, §7.5 (`ℂ(X₀(N)) = ℂ(j, j_N)`) and §7.6 (the rational structure). All locators
  UNVERIFIED.
* **Hypotheses.** `IsRatModFnMero N g` is gz-heegner's definition, used unchanged. It requires:
  - `Γ₀(N)`-invariance;
  - meromorphy on `ℍ`;
  - moderate growth at every cusp, which makes `g` meromorphic at the cusps (moderate growth excludes poles
    accumulating at a cusp);
  - a rational `q`-expansion at `∞`.
* **Relation to the print.** The print says `g = R(j, j∘N)` with `R ∈ ℚ(X, Y)`. Taking `q`-expansions gives
  `x = R(jq, jq(q^N)) ∈ X0Field N`, because `q`-expansion is an injective ring map on functions meromorphic at `∞`.
  So the Lean statement is a consequence of the print. The converse also holds (the identity theorem), so the two
  say the same thing.
* **Not vacuous.** `g = j` satisfies the hypotheses.
* **Not formalized here.** The proof needs `ℂ(X₀(N)) = ℂ(j, j_N)` (degree `[ℂ(X₀(N)) : ℂ(j)] = ψ(N)`, compact
  Riemann surfaces) and a Galois descent of the coefficients from `ℂ` to `ℚ`. The vendored FLT theorem
  `mem_adjoin_jq_of_hasSum_of_slash_invariant` is the level-1 holomorphic case only.

## 3. The bridge (`grossZagierModuliOptAt_of_alg`)

Input: gz-optimal's data, which is `X, Y` with `IsModularParam N E X Y`, `IsOptimalParam N f E X Y`, and the
Heegner data.

1. `IsRatModFnMero N X` gives `k, a, T` with `Σ aₙ qⁿ = q^k X(τ)` for `Im τ > T`. Put `x := q^{−k} Σ aₙ qⁿ ∈ ℚ((q))`.
   Then `HasQExp X x` (`hasQExp_laurentOf`). Do the same for `Y`.
2. `Gamma0QExpansion` gives `x, y ∈ X0Field N`.
3. **Equation** (`wEq_of`). Let `G_x, G_y` be the power series in `q` (`le_radius`; radius `≥ e^{−2πT}`). Then
   `F(q) = q^{3k_x+2k_y}·(W_E(X, Y))`, written in `G_x, G_y, q`, is analytic at `0`. It vanishes on the punctured
   disc, at `τ = log q/(2πi)` where `X, Y` are regular (`regularAt_of`). So its Taylor series is `0`
   (`tay_eq_zero_of_punctured`). gz-heegner's `tay_mul`, `tay_add`, … expand that Taylor series
   (`tay_weq`, `tay_sum`). The identity descends from `ℂ⟦q⟧` to `ℚ⟦q⟧` (`PowerSeries.map_injective`), and dividing
   by `q^{3k_x+2k_y}` gives `W_E(x, y) = 0` in `ℚ((q))` (`wEq_laurent`).
4. **Pole** (`order_neg_of`). If `ord x ≥ 0`, then `X(τ) = Σ_{n ≥ 0} x_n qⁿ` is bounded as `Im τ → ∞`. This
   contradicts `‖X‖ → ∞` (`IsModularParam.pole`).
5. **`φ^*`** (`phiOf`). `x` is transcendental (`aeval_ne_zero_of_order_neg`), so
   `ℚ[x, y]/(W_E) → X0Field N` is injective (`psi0_injective`) and extends to `ℚ(E)`.
6. Apply `GrossZagierAlgOptAt` to `φ^*` and the same `X, Y`, which are meromorphic by `IsRatModFnMero`.
