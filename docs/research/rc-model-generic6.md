## New definitions and theorems

`Cyclicity.lean` (item 2a; any characteristic)
- `smulSubgroup m C := C.map (m • ·)` and `atkinSum Q C := A[Q] ⊔ C`. Here `A[Q]` is the actual `Submodule.torsionBy ℤ A Q`.
- `isAddCyclic_map_atkinSum`: let `Q = q^e` (`q` prime, `e > 0`), `N = Q * M ≠ 0` with `Q`, `M` coprime, and `#A[d] = d²` for every `d ∣ Q`. Let `C ≤ A` be cyclic of order `N`. Then for every group homomorphism `g` with `g.ker = M • C`, the image `g(A[Q] ⊔ C)` is cyclic of order `N`. The proof puts `ZMod Q × ZMod Q` coordinates on `A[Q]` (vendored `nonempty_zmod_prod_addEquiv_torsionBy_of_card_torsionBy_eq_sq`). An element of order `Q` has a unit coordinate, so it has a complement. The image is generated by `g(w + Q • c)`.
- `isAddCyclic_map_atkinSum_curve`: the same for `E(k)`, with `k` algebraically closed and `(N : k) ≠ 0`, `(2 : k) ≠ 0` (vendored `card_torsionBy_eq_sq_of_isAlgClosed`).
- `atkinImage`: the image as an element of `CyclicSubgroups _ N`.

`VariableChangeSeam.lean` (ON THE SPOT (c); any characteristic)
- `vcFunHom W C : W.FunctionField →ₐ (C • W).FunctionField`. This is the vendored explicit map behind `nonempty_functionField_algEquiv_of_variableChange`: `X ↦ u²X + r`, `Y ↦ u³Y + u²sX + t` (`vcFunHom_X`, `vcFunHom_Y`). Also `vcFunHomInv`, the inverse laws, integrality and finiteness.
- `restrictAlong_vcFunHom`: for all centred place gates on `W` and on `C • W`, `(place P).restrictAlong vcFunHom = place (Point.addEquivVariableChange W C P)`. Proof: the places transported along the map form a centred gate on `W` (`transportGate`, `transportGate_isCentred`), and centred gates are unique (vendored `GenusOnePlaceGate.ext_of_isCentred`). This is the point formula that generic4's Known issues asked for.

`SeamLift.lean` (characteristic 0)
- `isSeam_changePoints`, `isSeam_changePoints_symm`: the pair isomorphism `changePoints` of a variable change, and its inverse, are seams (`ModelGeneric4.IsSeam`).
- `isSeam_comp'`: seams compose (generic4's lemma is private).
- `exists_lift_of_seam`: every seam `f` between the period curves of `L₁` and `L₂` satisfies `f (toPoint z) = toPoint (α z)` for some `α`. The proof uses the vendored lift `exists_differentiable_toPoint_comp_eq_pointMapOfPushforward_toPoint`, the vendored linearity of lattice-periodic entire maps, and `pointMapOfPushforward_eq_of_seam`. It lifts the seam itself, not the seam followed by a variable change.

`ComplexStep.lean` (item 2b)
- `analyticCyclicPair_eq_of_scale'`: generic4's homothety lemma for an arbitrary period pair `P` with `IsScale P (ofTau τ') α`.
- `mem_span_iff_atkin`: `ℤτ + ℤ/Q = ω₂(ℤτ' + ℤ)` for `τ' = (Qaτ + b)/(QMcτ + Qd)`, `ω₂ = Mcτ + d`, `Q(ad) − M(bc) = 1`. The entries come from `TauCeti.IsAtkinLehnerMatrix.exists_entries`.
- `atkinPair_complex`: let `(E, C)` be a complex pair with class `analyticCyclicPair τ`, `Q = q^e ∥ N`, and `g` any seam from `E` to `E.cyclicQuotientCurve C_Q Q` with `g.ker = C_Q`. Then `[(E', g(E[Q] ⊔ C))] = analyticCyclicPair (AtkinPin.atkinGL hQ • τ)`. The image is computed with `ω₂/N = cτ/Q + d/N`, which generates `⟨τ/Q, 1/N⟩` modulo `ℤτ + ℤ/Q`: `τ/Q = −Mb·ω₂/N + adτ + bd/Q` and `1/N = Qa·ω₂/N − acτ − bc/Q`.
- `rationalPoints_atkinRat_complex_moduli` (the target theorem of item 2 for `k = ℂ`) and `atkinClass_independent` (the independence corollary).

`CharFreeSeam.lean`, `CharFreeSeamTwo.lean` (item 3a; any characteristic prime to the order)
- Copies of generic4's `gate`, `gate_isCentred`, `gate_abel`, `pointPlace`, `IsSeam`, `StepSeam`, `isSeam_comp`, `exists_oddStep`, `stepSeam_of_odd`, `exists_quotientSeam_of_steps`, `twoFFHom_seam`, `stepSeam_two` and `exists_quotientSeam`, without `[CharZero k]`. The gate uses the characteristic-free vendored `hasPrincipalDivisors_functionField_of_isElliptic`. Each prime step takes `(ℓ : k) ≠ 0`.
- `StepSeam` now also records `finrankAlong k ι = ℓ`. For odd steps this is the vendored degree. For the order-two step it is proved (`finrankAlong_twoFFHom_le` gives at most 2, because the function field is generated over the image by `x`, which is quadratic over it; `finrankAlong_ne_one_of_seam` excludes 1, because a seam with a nonzero kernel point is not an isomorphism of function fields). The degree of a composite is the product (`finrankAlong_comp'`).
- `exists_quotientSeam n hn hchar E H hH`: for every cyclic `H` of order `n` with `(ℓ : k) ≠ 0` for each prime `ℓ ∣ n`, there is a separable seam to `E.cyclicQuotientCurve H n`: `FiniteAlong k ι`, `finrankAlong k ι = n`, `g.ker = H`, `IsSeam ι hι g`.
- `isSeam_iff_modelGeneric4`: in characteristic 0 the two seam notions agree by `Iff.rfl` (`HasPrincipalDivisors` is a `Prop`).
