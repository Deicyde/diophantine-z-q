# cm-primitive: the main theorem of CM is needed only for primitive types (in fact only for CM elliptic curves)

Task cm-primitive (2026-11-16). Branch `wip/cm-primitive` (base 60a3fac7 + clean merge of `wip/mtcm-polar` 50dcdc48).
Contributor file: `ZInQKernel/Contrib/OneProof/CMPrimitive.lean` (~97 KB, namespace `CMPrimitive`, imports only
`ZInQKernel.Contrib.OneProof.MainCMPolar`). Log: `scratch/cm-primitive/log.md`.

## Result

The reading risk of mtcm-polar's leaf `MainTheoremCMPol` / `MainTheoremCMPolMax` (is Shimura 1998 Thm 18.6 /
1971 Thm 5.15 printed for non-primitive CM types?) is removed. All consumers are proved in Lean from the leaves
restricted to **primitive** CM types, and also from the even weaker restriction to **imaginary quadratic** `E`
(`g = 1`, CM elliptic curves). The steps:

* `IsPrimitiveType Φ` is a genuine definition: `Φ` is not induced from a proper subfield. Every type of an imaginary
  quadratic field is primitive (`isPrimitiveType_of_finrank_two`). The induced type `PhiE κ` of `E = K(√2)` that the
  consumers use is **not** primitive (`not_isPrimitiveType_PhiE`). So the risk was real: the primitive print does not
  apply to it directly.
* Reduction from induced to primitive types, for the type the consumers use (`E = K(√2)`, `Φ` induced from `(K, κ)`,
  `K` imaginary quadratic), in Lean:
  * `exists_isogeny_EK`: `A` of type `(E, Φ)` is isogenous to `B²`, with `B = ℂ/κ(N𝓞_K)` of type `(K, κ)`. There are
    `f₁, f₂ : B → A` with `θ(w₁Φ(1) + w₂Φ(√2)) = f₁(θ_B w₁) f₂(θ_B w₂)`. The map `(P, Q) ↦ f₁(P) f₂(Q)` is surjective,
    and its kernel is killed by some `m > 0`.
  * Reflex field: both are `κ(K)` (`QMRecPrinted.reflex_eq`, `reflex1`).
  * Reflex norm: `N_Φ = incl ∘ N_{κ}` (`reflexNorm_rhoK_eq`).
  * `mainTheoremCMEK_of_quad`: the main theorem for `(K, κ)` gives it for `(E, Φ)` on every lattice `𝔞`. With
    `θ'(w₁Φ(1) + w₂Φ(√2)) = f₁^σ(θ'_B(w₁)) · f₂^σ(θ'_B(w₂))`, analyticity comes from a lift through a uniformization
    of `A^σ`. The kernel and the torsion relation come from `𝔞̂ = 𝔞 + (𝔟 ⊕ 𝔟√2)^` and coordinates on
    `𝔸_f ⊗ E = (𝔸_f ⊗ K)²`.
* mtcm-polar's isogeny step works on any class of CM types (`mainTheoremCMSignOn_of_polar`, a copy with the class
  hypothesis threaded through). So the new polarized leaves give the every-lattice statements
  `MainTheoremCMSignPrim` / `MainTheoremCMSignQuad`.
* Consumers:
  * `hCM = T5Glue.ShimuraMainCM` (`shimuraMainCM_of_polMaxPrim`, `shimuraMainCM_of_polMaxQuad`);
  * `QMReciprocityL3` (`qmReciprocityL3_of_polPrim`, `_of_polQuad`);
  * the former field `rayClassCMAb` (`rayClassCMAb_of_polPrim`, `_of_polQuad`).
* `MainTheoremCM` / `MainTheoremCMArith`: re-derived on exactly the instances the consumers use:
  * the `g = 1` part (`MainTheoremCMSignQuad`, `MainTheoremCMSignPrim`);
  * the instance at `(K(√2), PhiE κ, rhoK)` (`MainTheoremCMEK`, proved implied by `MainTheoremCMSign`: `ek_of_sign`).

  The fully general `MainTheoremCM`, for every non-primitive type, is not re-derived (see "What remains").

No statement of the kernel or of a merged file was changed. All theorems use only `propext`, `Classical.choice` and
`Quot.sound` (VERIFIED, `scratch/cm-primitive/axioms.txt`).

### Leaf ratings

| leaf | rating | reason |
| --- | --- | --- |
| `MainTheoremCMPolPrim` | printed form | mtcm-polar's `MainTheoremCMPol` plus `IsPrimitiveType Φ`. It is printed under every reading of Shimura 1971 Thm 5.15 / §5.5 and Shimura 1998 Thm 18.6 / Shimura–Taniyama §§13–14 (UNVERIFIED locators): primitive types are covered whether the print is for all types or only for primitive ones. The definition of primitive is the standard one (not induced from a CM type of a proper CM subfield; such a subfield is automatically CM, see the docstring). It is weaker than mtcm-polar's leaf (`polPrim_of_pol`) and not vacuous (every imaginary quadratic type is primitive). |
| `MainTheoremCMPolMaxPrim` | printed form, with hcm-printed's flag | the same at `ε = 1`. It keeps the pending reading of the normalization of `[s, K]` against Tau Ceti's arithmetic Artin map, which is needed only on the `hCM` route. The primitivity flag is gone. |
| `MainTheoremCMPolQuad` | printed form | the same restricted to `[E : ℚ] = 2`: the main theorem for CM elliptic curves with `𝓞_E`-ideal lattices. Shimura 1971 Thm 5.4; Lang, *Elliptic functions* Ch. 10 Thm 3; Silverman, *Advanced topics* Thm II.8.2 (UNVERIFIED locators). In dimension 1 the reflex field is `κ(E)`, the reflex norm is the identity (`reflexNorm_rho1`) and every elliptic curve is polarized. It is weaker than the primitive leaf (`polQuad_of_polPrim`) and raises no question about dimension or primitivity. **Recommended**. |
| `MainTheoremCMPolMaxQuad` | printed form, with hcm-printed's `ε = 1` flag | the same at `ε = 1` (`polMaxQuad_of_polMaxPrim`). This is the leaf for the `hCM` route. |
| `CMAbVarExists` | unchanged (mtcm-polar, printed form) | the new proofs use it only at `g = 1`. |

## Method

* **§1 Primitivity.** For `[E:ℚ] = 2`, `IntermediateField.isSimpleOrder_of_finrank_prime` leaves `F = ℚ` or `F = E`.
  On `ℚ`, `φ` and `φ̄` agree, so saturation would put `φ̄` in `Φ`, which injectivity forbids. For `PhiE κ`, `F = K`
  is saturated: any `ψ` extending `κ` sends `√2 ↦ ±√2`, so `ψ ∈ {φ₁, φ₂}`. And `√2 ∉ K`.
* **§3 Generic isogeny step.** mtcm-polar's proof copied verbatim, for a class `P`, with `hprim : P E g Φ` passed to
  the leaf.
* **§4 Conjugation.** Three general lemmas:
  * `exists_liftHom`: `f^σ : B^σ → A'` through any pullback presentation of `A^σ`, a homomorphism by rigidity
    (mtcm-polar's `μ^σ`, for any `f`);
  * `exists_bcHom`: `dd(P f^σ) = dd(P) f` on `bcC`;
  * `exists_unif_of_bc`: a uniformization of `bcC A σ` transports to any `A'`.
* **§5–6 Algebra.**
  * The model `ρ = id` of `(K, {κ})` has reflex norm `𝔸_{K,f} ≅ 𝔸_f ⊗ K` (`reflexNorm_rho1`).
  * Coordinates `crd i` on `E = K ⊕ K√2` and their base change `crdHat i : 𝔸_f ⊗ E → 𝔸_f ⊗ K`. The base change is
    `𝔸_f ⊗ K`-linear (`crdHat_inclA_mul`) and maps `𝔠̂` into `𝔟̂` (`crdHat_latHat`).
  * The maps `Mv α : w ↦ wΦ(α)` and the coordinates `ell0`, `ell1` in the basis `Φ(1), Φ(√2)` of `ℂ²`.
  * A uniform denominator for `crd i` on `𝓞_E` (`exists_den_lin`, via an integral basis).
* **§7 Reduction (`mainTheoremCMEK_of_quad`).**
  * Take `𝔟 = N𝓞_K`, with `N𝓞_E ⊆ 𝔞` from `lattice_of_unif`. `B` comes from `CMAbVarExists`, with Riemann datum by
    `exists_zeta`. The quadratic theorem applied to `B` gives `θ'_B` on `B^σ`.
  * `f₁ = Mv 1` and `f₂ = Mv √2` are realized by `HomLatticeCorr`. Put
    `θ₀(z) = f₁^σ(θ'_B(ell0 z)) · f₂^σ(θ'_B(ell1 z))` on `bcC A σ`.
  * Analytic and a homomorphism: `θ₀ = ψ ∘ (M₁ + M₂)`, where `ψ` uniformizes `bcC A σ` and `M_i` lifts each factor
    (`analyticHomLiftC_of_leaf`).
  * Torsion relation: with `t = incl(t_K)`, `latHat_decomp` gives `t y − (x + a) ∈ 𝔠̂` for `𝔠 = 𝔟 + 𝔟√2` and some
    `a ∈ 𝔞`. Coordinatewise this is `t_K y_i − (x + a)_i ∈ 𝔟̂`. The `K`-relation for `B` then gives
    `dd θ₀(Φy) = θ(Φx)`.
  * Kernel `⊇`: from the relation at `x = 0`.
  * Kernel `⊆`: `θ₀(z) = 1` forces `ell_i z ∈ κ(K)` (a multiple lies in the kernel of `θ'_B`), so `z = Φ(y)`.
    Density (`exists_approx_latHat`) and the relation then give `t y ∈ 𝔞̂`.
  * Surjectivity: from that of `θ`, `θ'_B` and `dd`.
  * Finally `exists_unif_of_bc` moves `θ₀` to the given `A'`.
* **§8 Consumers.** Verbatim copies of `qmReciprocityL3_of_printed` and `shimuraMainCM_of_printed`, with only the
  call to the main theorem changed. The copied line ranges are stated in the file.
